### 形（実際の形に近く）
- 羽田の形は **OpenStreetMap のデータを加工して作成**（web/3d/hnd.json・**ODbL 1.0** で公開。ファイルの中に出典と条件を書いた）。圧縮して約34KB
  - ターミナル（第1・第2・第3）とまわりの建物 218棟（高さは OSM にあるものはその値、ないものは階数か種類でおおよそ）・駐機場・誘導路 753本（幅つき・黄色の中心線）・芝・空港の範囲・海岸線（羽田の島・D 滑走路の島・まわりの埋立地）・多摩川と運河・管制塔の位置
  - 作り方は tools/a3_shape.py（OSM の API で羽田のまわりを小分けに1回だけ取った。毎回は読まない）
- 滑走路は今までどおり **AIP JAPAN をもとにした HND_RWY を正**にして、標示を絵で貼った：番号（16R など。降りてくる側から読める向き）・末端の縞・ずらした末端の矢印・中心線・接地帯・目標点・縁の線
- 管制塔：高さ 115.7m（国土交通省）の細い塔＋ガラスの管制室＋アンテナ

### 機体
- 機種で5つの形（4発・大きな2発・細い胴の2発・小さなジェット・プロペラの高い翼）。胴・丸い機首・細くなる尾・後退した主翼・水平尾翼・垂直尾翼・発動機。大きさは機種の長さどおり
- **会社の色やロゴは使わない**（白と灰色だけ。特別塗装機の尾翼は今までどおり昼だけ金）。上昇は機首を少し上げ、降下は下げる。夜は前の灯り・左の赤・右の緑・尾の白

### 光と空
- 空は上ほど濃いグラデーション。太陽は**実際の太陽の向き**（夜は月明かりほどの弱い光）。昼は建物と機体に影
- 夕方：オレンジの地平と太陽の側の明るみ。夜：滑走路の縁（白）・末端（緑と赤）・進入灯（白）・誘導路の縁（青）・ターミナルの窓の明かり
- 夕方と判定する太陽の高さを 2° から 4° に（日の入り前の色づきに合わせた）

### 重さ
- 読み込みは押したときだけのまま。three.js（約166KB）＋形（約34KB）＝**圧縮して約0.2MB**（0.5MB の上限の内）。入口の「約0.2MB」は実際と合っていたので字は変えず、中の説明を直した
- 約30こま／秒まで（機体はゆっくり動くので）。続けて重い（平均 45ms より遅い）ときは**自動で質を下げる**：影をやめる → 細かさ（画素の密度）を下げる。電池20%以下の軽い表示は今までどおり
- 古い iPhone（SE 第2世代）で 30fps 出るかは、手元に実機がないので**未確認**（シミュレーターでは測れない）。本人の iPhone で見てもらいたい

### 出典
- 角の出典：「adsb.lol・© OpenStreetMap・AIP JAPAN ⓘ」（5秒で「出典 ⓘ」に畳むのは今までどおり）
- データの出典のシート：空港の形・建物・海岸線＝© OpenStreetMap の協力者（ODbL 1.0・加工して作成）／管制塔の高さ＝国土交通省／形のファイルは ODbL 1.0 で公開。形のファイルが読めないときは「仮の形」と出す
- 形の出典に使ってよいかは、データ担当の調べ（report-airport-3d-data.md の1。OSM は商用も可・切り出したファイルは ODbL で公開・出典を角に）のとおりにした。**国土地理院の基盤地図情報と PLATEAU は使っていない**
