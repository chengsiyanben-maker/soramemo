## 今の見にくい所（01）

2. 切り替えが2段：「一覧・年ごと・記録帳」と、9つの見方の帯（横に送らないと「月ごと」から右が見えない）

## 実物の道具から借りた工夫（特定の製品はまねしていない。一般的な形から）
- 操縦士の航空日誌：日付を左端の列に、1行1飛行、時間は「時:分」で右に寄せる → A の1行の並び（日付・区間・時間）
- 搭乗券の半券のアルバム：半券そのものは大きいので、一覧ではなく「共有の1枚」に残す → 07
- 鉄道の乗りつぶしの記録帳：乗った区間に線を引き、何度乗ったかを重ねる → D の糸の太さ
- 旅のしおり：月ごとの見出しの下に予定を並べる → A の月の見出し（何便・何km）
- 地図に引いた線：ピンと糸 → D。地震計や気圧計の記録紙（1本の紙に時間順） → B

## 迷った点
- 航空日誌の列に「機体」を入れると1行が詰まるので、2行目（小さい字）に便名と機種だけ。登録記号は A2 の詳しい所
