# 報告：フライトの改善案（design/flight-book）

PM の指示（11/10 2時15分、本人「フライトと修行も図鑑と同様に改善案を出して見せて。斬新なアイデアを見たい」）の、フライトの分。画面案だけで、アプリのコード（web/・src/・supabase/）は変えていない。

- 画面案：docs/design/flight-book/（12画面・index.html・png/ に 844（2倍）と 667）
- 作り方：docs/design/flight-book/make/（Python。空港の表と日本の輪郭は main の src/index.html の RAW・JP_OUTLINE を書き出して使う）
- 見本の記録：2026年の26便（JAL グループ20・ANA 6）。登録記号・座席は見本

## 今の見にくい所（01）
main の web/ をデモ（30便）で開き、幅390で撮った。

1. 667 では開いたときに1便も見えない（地図・凡例・数字の行・2段の切り替えで埋まる）
2. 切り替えが2段：「一覧・年ごと・記録帳」と、9つの見方の帯（横に送らないと「月ごと」から右が見えない）
3. 「記録帳」は見方ではなく過去の便を足す入力。右上の ＋ と同じ仕事が2か所
4. 1便のカード（搭乗券）が大きく、844 でも1便半。日付は右端の小さな字、月の区切りなし
5. 今年の様子（空の上の時間・月ごとの回数・よく乗った路線）が「年ごと」の中に隠れている

## 実物の道具から借りた工夫（特定の製品はまねしていない。一般的な形から）
- 操縦士の航空日誌：日付を左端の列に、1行1飛行、時間は「時:分」で右に寄せる → A の1行の並び（日付・区間・時間）
- 搭乗券の半券のアルバム：半券そのものは大きいので、一覧ではなく「共有の1枚」に残す → 07
- 鉄道の乗りつぶしの記録帳：乗った区間に線を引き、何度乗ったかを重ねる → D の糸の太さ
- 旅のしおり：月ごとの見出しの下に予定を並べる → A の月の見出し（何便・何km）
- 地図に引いた線：ピンと糸 → D。地震計や気圧計の記録紙（1本の紙に時間順） → B

## 4つの案
| 案 | 画面 | 良い点 | 困る点 | 外した決まり |
|---|---|---|---|---|
| A 正攻法「航空日誌」 | A1 日誌・A2 1便・A3 年のまとめ | 844 に5便・667 に2便。日付が左・月の見出し。見方が3つに | 新しさは少ない。搭乗券のカードは一覧から消える | なし |
| B「1本の長い紙の航跡」 | B1・B2 | 1年を送って眺める楽しさ。長い便ほど高い山 | 横に送る操作がタブの切り替えとぶつかりやすい。1便を探すのは遅い | 紙の地・方眼の細い線・ミシン目 |
| C「時計の文字盤」 | C1・C2 | 何時台に乗るかの癖が1枚で分かる | 時刻のない記録（記録帳）は描けない。一覧の代わりにならない | 図が主役・細い目盛り |
| D「糸の日本地図」 | D1・D2 | 乗るほど太い糸。路線の見方をまとめられる | 本番の地図と2枚になる。羽田のまわりで糸が重なる | 航空図風でない地図・生成りの地 |

- 07：今の 9つ＋3つを「日誌・地図・年のまとめ」の3つに。搭乗券・案内板・文字だけ→日誌、年ごと・月ごと・高度→年のまとめ、路線→1便の「この区間」、カレンダー→日誌の月の見出し、修行→修行のタブ、記録帳→右上の ＋。見方を選ぶシートは 11/9 の ON／OFF。斬新な案は OFF で始める見方として足せる
- 夜（N1）：A の夜。光るのは今年の便の数だけ（緑）。夜は会社の色の帯を出さない

## 測った値（幅390・844）
13px 未満の字 0（単位の 12px を除く）・押す所 44px 未満 0（スイッチは 34px の決まり）・横のはみ出し 0・日誌の行の字の切れ 0（12画面とも）。667 は A1 で2便が見える。

## 迷った点
- 航空日誌の列に「機体」を入れると1行が詰まるので、2行目（小さい字）に便名と機種だけ。登録記号は A2 の詳しい所
- カレンダーの見方を消すと、却下済みの「空のカレンダー」とは別物でも「カレンダーがなくなった」と感じる人がいるかもしれない。日誌の月の見出しで代わりにした
- C の時計は、到着が日をまたぐ便を描く形を決めていない（国内線ではまれ）

## 本人に決めてほしいこと
1. 基本は A（航空日誌）でよいか。斬新な B・C・D から入れたいものはあるか（入れるなら OFF で始める見方として）
2. 見方を「日誌・地図・年のまとめ」の3つにまとめてよいか（07 の移し方）
3. 修行の見方をフライトから外し、修行のタブ（1便ごと）へ移してよいか（修行担当の持ち場）
4. 搭乗券のカードを一覧から外し、共有の1枚として残す形でよいか
5. 「記録帳」の入力を右上の ＋ にまとめてよいか
