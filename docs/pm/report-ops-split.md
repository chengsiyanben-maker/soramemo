- おすすめの形
  - 運用タブの上に「空港｜機体」のピル（選んだ側は濃い紺。上の「スタンプラリー｜エアライン経営」と見分ける）。その下に、空港側は空港のピル（今のまま）、機体側は「登録記号か便名で探す」の欄
  - A1・A1b 空港側：見方は今の7つ（案内板・1日の山・滑走路・定時・空の道すじ・短冊・撮る人）。海外の空港のいま・門限・ゴーアラウンド・お知らせ・地図も空港側
  - A2 機体側のはじめ：「最近見た機体」（この端末で開いた順）＋「いま飛んでいる特別塗装機」。A2e は最近見た機体がない人（説明と「羽田に来る機体」「乗った機体」の入口）
  - A3 機体を選んだあと：今のシート（機体の1日）を運用タブの中に出す。中身は運用予想 案A（飛んだ便を1行にたたむ・「ここから予想」・「予想です。保証しません」・3つの点と回数・ODPT の出典）
  - A4 特別塗装機：いま／この先／羽田に来る のピル。各行に「この先（予想）」。運航情報の「これから飛ぶ予定」もここ
- 撮る人の置き場所（案2つ）
  - 案1（おすすめ）分ける：P1 空港側の「撮る人」は撮影地・見に行く場所・撮影条件だけ。P2 機体側に見方「次に来る機体」（空港と撮影地を選ぶ小さな欄つき）
  - 案2 空港側にまとめる：Q1 今のまま「撮る人」に次に来る機体も。Q2 機体側は「探す」「特別塗装機」の2つで、撮る人への入口だけ
- 見方の設定：V1・V1b 鉛筆のシートの中でも「空港｜機体」を切り替え、それぞれ ON／OFF（最後の1つは残す＝案A）。機体側には「『機体』を出す」の行（OFF で切り替えごと消え、運用は空港だけ）。V2 表示の編集は「運用（空港）」「運用（機体）」に分ける
- 測った値：13px 未満の字 0・44px 未満の押す所 0（スイッチ 36px・切り替えのピル 40px は今の部品の大きさ）・横のはみ出し 0（15枚）
- 作り方：make/capture_now.py（本番を撮る）→ make/make.py → make/shoot.py

## 迷った点
- 切り替えの置き場所：上の「スタンプラリー｜エアライン経営」と同じ形を2段重ねると似すぎるので、小さめのピルで選んだ側を紺にし、ⓘ・共有と同じ行に置いた
- 空港を選ぶ欄：空港側だけにした。機体側では「次に来る機体」（案1）のときだけ小さく出す
- 機体を選んだあとの見方の帯は「探す」のまま（戻るは「‹ 探す」のピル）。見方を4つ目「機体の1日」にする手もある
- 撮る人のペルソナ（はじめの見方が ops:photo）は、案1 なら機体側の「次に来る機体」をはじめにするか、空港側の「撮る人」にするか
- 見本の便・予想は架空。特別塗装機の名前はアプリの表（_shared/liveries.ts）から、キャラクターの名前でないものを選んだ

## 本人に決めてほしいこと

5. 「『機体』を出す」の ON／OFF（機体側ごと隠せる）を入れるか
