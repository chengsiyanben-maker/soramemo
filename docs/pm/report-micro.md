# 報告：小さな動き（マイクロインタラクション）の見本 1版（design/micro）

PM の指示 11/25 16時（本人が動きの見本集の画像を見せて「こういうやつも使えるなら使って」）。アプリのコードは変えていない。

## 作ったもの
- docs/design/micro/index.html：13 個の動きを1画面に並べた一覧。押すと動く。上で昼／夜と「動きを減らす」を切り替えられる
- 使う画面ごとの見本（390 幅・外部の読み込みなし）：s1-home（01・02・05・07・13）／s2-airport（04・05・10・11）／s3-ops（06・09・10・12）／s4-edit（03・05・09）／s5-shugyo（08）。上の斜線の帯は「見本の操作」でアプリには出ない
- png/：各画面 390×844（2倍）と -667（375 幅）、夜（-n）、操作のあと（-roll・-sheet・-pin・-skel・-sort・-retry・-lift・-toast）。動きは m01〜m13.png（昼）と -n.png（夜）に「前・途中・後」を止めて横に並べた。一覧は index-full.png
- 作り方：make/build.py（src/base.css・base.js を各ページに埋め込む）→ make/shoot.py（撮影・測定。measure.json）

| 番号 | 動き | 場所 | 長さ |
|---|---|---|---|
| 01 | 押すと少し縮む（0.97 倍） | ボタン・カード全部 | 0.12 秒 |

| 03 | ON／OFF のつまみ | 表示の編集・見方のシート | 0.25 秒 |

- 今あるもの（印のハンコ・半券を切る・運用の専用ページの広がり・パタパタ）は変えない
- 入れないもの：波紋・いいね／星・横にずらして消す（記録は消さない）・紙吹雪・数字のパタパタ・天気や季節の動き
- 動きを減らす設定（prefers-reduced-motion）では、状態は変わるが動きはすべてなし（骨組みは光らない灰色）。音と振動は入れていない

## 測った値
- 390／375 の各画面と一覧（昼・夜）：12px 未満の字 0・44px 未満の押す所 0・横のはみ出し 0・エラー 0
- 動きを減らす：骨組みの読み込み中に動いているもの 0

## 迷った点
- 07 の数字：案内板風（パタパタ）に寄らないよう、すっと上がるだけにした
- 08：毎回動くとうるさいので、その日はじめて開いたときだけにした。修行の画面は簡単な絵で、本物の形（決定事項【11/12】）は変えない
- 05：今の say()（#msg の字）を札に置き換える形。エラーの字は今までどおり画面に残すほうがよいと考え、札は「できた」だけに使う
- 夜は光る色を緑（✓・帯）だけにし、琥珀は使っていない（いま・次の札がないため）
