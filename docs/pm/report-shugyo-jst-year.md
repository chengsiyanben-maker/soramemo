## 作ったもの
1. **年と月の区切りを日本時間に**（12月より前に入れる直し）。今までは端末の時計の地域で年・月を分けていたので、海外にいる人や端末の地域が日本でない人は、12/31 夜〜1/1 の便が前の年に入ったり、日付や曜日が1日ずれたりした
   - 足した部品：`sgJstY`・`sgJstM`（記録の時刻から日本時間の年・月）、`sgNowY`・`sgNowM`（日本時間の今年・今月）、`sgMDj`（「1月2日」）。`sgJstDay` は前からあるものを上へ移しただけ
   - 変えた関数：`sgMD`・`sgWD`（日付の文字から直接。曜日も日本の暦）、`sgYear`（年の初めの値・年と月・日の分け方）、`sgReach`（予定の年）、`sgMoney`（今月の使った額。見ている年が今年のときだけ）、`sgRoadView`（次に乗る便の日付）、`renderShugyoCard`（ホームの修行のカードの次に乗る便の日付）、`sgMonthsView`（月の分け方を部品に替えただけ。動きは同じ）、`sgYearPage`・`renderSgSum`・`sgBudget`（「今月」の印。見ている年が今年のときだけ）、`sgRoad`（年末までの道のりの月の並び）
2. **JAL の乗り継ぎを公式の値に**：空港を移る乗り継ぎで、JAL の便で組むときだけ伊丹⇔関西を 175分に（ANA は 180分のまま）。変えた所：`SG_XFER_JAL`（新）・`sgXferOf`（新）・`sgXfer`（会社を受け取る）・`sgNextAps`・`sgBuild` の「決まり ○分以上」の字
3. **計算ルールの文書に足す・書き換える所**：docs/pm/shugyo-rules-1120.md。Project の文書への書き込みは止められたので、ここに書いた（年の区切り・端数・JAL の乗り継ぎの表）
4. **端数**：公式に書いていないので「今の計算のまま。合わないという声が出たらその便で見直す」に決めた（上の文書に書いた。コードは変えていない）
