ブランチ shugyo-view-sheet（`shugyo/…` は古い `shugyo` ブランチとぶつかるため）。main（見方の設定 #68 入り）から作った。画面案 design/view-settings の 02c-v2・02c2-v2 のとおり。

## 作ったもの
- 修行の見方の帯の鉛筆で、ほかの画面と同じ形の小さいシート「修行の見方」を開く（前の ✎ からのページ「見方を選ぶ」は消した）
  - 題・出している見方の数（3/3）・完了は上に固定。「見方」3行と「道のりに出すもの」4行を ON／OFF（行はチェックイン担当の loRowHTML なので図鑑・フライト・運用と同じ見た目）
  - 見方は案A：どれも OFF にでき、最後の1つは押せず「最後の1つ」の札と理由が出る
  - 道のりを OFF にしている間は「道のりに出すもの」は押せず、行がうすくなり、補足が「道のりを ON にすると出ます」に変わる（02c2）
  - 押すと下に「『○○』を隠しました　元に戻す」の帯。裏の修行の画面もその場で変わる。保存は今までどおり shugyo_prefs の data（表は変えていない）
  - 下の「表示の編集をすべて見る ›」で、表示の編集の1枚の修行のカードだけ開いて光る
- 表示の編集の1枚に修行のカードを出した（`LO_EXT.sg = { groups, toggle }`）。1枚で押しても修行の画面が変わる
- 説明の字を画面案に合わせた：月ごと「月末の残り・路線ごと」、JGC「JAL を選んだときだけ出ます」
