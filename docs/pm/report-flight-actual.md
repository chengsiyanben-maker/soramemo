## 作ったもの
1. **移行187（flights に3つの列）**
   - `act_dep_at`・`act_arr_at`（実際の出発・到着）、`act_src`（どこから取ったか）
     - `odpt`＝航空会社の運航情報（ODPT）の実際の時刻（出発・到着とも）
     - `adsb`＝片方か両方が機体の位置（adsb.lol・ODbL）からの推定の離陸・着陸（毎日の記録 flight_history）
     - `timetable`＝実績がなく、時刻表の定刻
   - 実績と定刻はまぜない（出発だけ実績・到着は定刻、にはしない）。取れない便は3つとも空
   - 3つはそろって入るか空（決まり flights_act_pair）。到着は出発より後・20時間まで
   - **未来の時刻は入らない**：関数の中で外し、さらに入れる前の守り（trigger flights_act_guard）で、1分より先の時刻なら3つとも空にする（atd-future と同じ考え）
   - RLS は今の flights のまま（本人だけ読める "own flights"、利用者は書けない）。書くのはサーバーの関数だけ
2. **関数 flights_fill_actual(p_days, p_limit)**（service_role だけ。statement_timeout 60s・lock_timeout 5s）
   - 取り先の順：毎日の記録（flight_history・400日）→ 時刻表（flight_schedule・14日。ODPT の実際の時刻つき）
   - 同じ便名（0を取ってくらべる・共同運航の便名も）・同じ区間・定刻が「出発のチェックインの2時間前〜到着のチェックイン」の便。欠航の便は使わない
   - 前より確かな取り先になったとき（時刻表 → 推定 → ODPT）と、同じ取り先で時刻が変わったときだけ書き直す。何度呼んでも同じ
   - 呼ぶ所：毎晩の照合（verify-flights／tools/verify_flights.ts。8日分）と、毎晩の記録（daily-archive。毎日の記録ができた後に3日分）
   - **さかのぼり**：移行の中で1回、400日分を入れる（時間がかかりすぎたら止めて移行は通す。残りは毎晩の分で入る）
3. **航跡（flights.track）**
   - 関数 flights_track_todo：航跡のないフライトに、毎晩の記録の便ごとの航跡（flight_tracks・adsb.lol・31日分）を渡す。daily-archive が間引いて書く（1晩300便まで）。今までは「その日」の便だけだったのを、31日前までさかのぼる

   - 31日より前の便の航跡は cold-archive のファイルにある。埋めるなら別の仕事（下の「決めてほしいこと」3）
