# 受信機の機材の案と置き場所（受信機担当・11/6）

自宅（千葉県船橋市）に ADS-B 受信機（1090MHz）を1台置くための、機材の比べと置き場所の比べ。
細かい住所・本当の座標はここに書かない。買うのも送り先の登録も本人が行う。

## 1. 受信機1台に要るもの

| 部品 | 役目 | 選ぶときの要点 |
|---|---|---|
| 受信用の USB の装置（ドングル） | 1090MHz の電波を受けてパソコンに渡す | 1090MHz だけを通すフィルターと増幅器（LNA）が入った ADS-B 専用品を選ぶ。都市部は携帯電話の電波が強く、フィルターなしだと取りこぼす |
| 1090MHz のアンテナ | 電波を受ける | 屋外用の縦長（約66cm、利得5〜7dBi）が基本。窓際なら短い磁石付きでも始められる |
| 同軸ケーブル | アンテナと装置をつなぐ | 1090MHz では細いケーブルほど損失が大きい。長くなるなら太いもの（下の表） |
| 小さいパソコン | 受信ソフト（readsb）を24時間動かし、送り先に送る | Raspberry Pi 4（2GB）で十分。技適のマーク付き |
| 電源・microSD・ケース | Pi を動かす | Pi 4 は 5V/3A の USB-C 電源。microSD は 16〜32GB |

受信用の装置は受けるだけで電波を出さないので、無線局の免許は要らない（電波を出すのは Pi の Wi-Fi だけで、Pi は技適付き）。

## 3. アンテナの置き場所

船橋の自宅から、羽田は南西、成田は東〜北東、どちらもおよそ25〜30km。

### 地球の丸みは問題にならない
アンテナの高さと、30km 先で見通せる最低の高さ（電波は光より少し遠くまで届く前提の目安）：

| アンテナの高さ | 羽田側（25km）で見える最低の高さ | 成田側（30km）で見える最低の高さ |
|---|---|---|
| 3m（1階の窓） | 約19m | 約31m |
| 10m（3〜4階・ベランダ） | 約8m | 約17m |
| 20m（屋上） | 約3m | 約8m |

計算は 距離(km) ≒ 4.12 ×（√アンテナの高さ(m) ＋ √機体の高さ(m)）で私が出したもの。
→ 理屈の上では着陸直前まで見えるが、実際に邪魔をするのは**周りの建物と木**。地上を走る機体（誘導路）は届かない前提にする。

### 置き場所ごとの比べ

| 置き場所 | 受かり方 | 低い高度（目的2） | 工事 | 向き不向き |
|---|---|---|---|---|
| 屋根の上・屋上 | いちばん良い。全方向 | 羽田・成田とも最終進入の数百mまで期待できる | 金具・防水・雷が要る。持ち家でないと難しい | 持ち家・戸建てなら最良 |
| ベランダ（手すりに縦に） | 建物の陰の方角が欠ける。開いている側は良い | ベランダの向いている側の空港はよく取れる | 金具で留めるだけ。窓のすき間を通す平たいケーブルが要ることがある | 集合住宅ならこれ。**南西か東向きのベランダ**が理想 |
| 窓際（室内） | 窓の向きだけ。ガラスで弱まる | 取りにくい | なし | 試しに置く・案A |

### ケーブルの長さと損失
1090MHz での損失の目安（メーカーの資料にある 900MHz の値から 1090MHz へ私が換算。https://www.koshow.jp/pdf/products/catalog/KTD_FB.pdf 、11/6 読む）

| ケーブル | 1m あたり | 10m | 20m |
|---|---|---|---|
| 5D-FB | 約0.23dB | 約2.3dB | 約4.5dB |
| 8D-FB | 約0.16dB | 約1.6dB | 約3.1dB |
| 細いケーブル（RG174 など、付属品に多い） | 1dB 近く | 損失が大きい | 使わない |

- 3dB で電波の強さは半分。**ケーブルは10m以内**を目安にし、長くなるなら太いものにするか、装置（または Pi ごと）をアンテナの近くに置いて、家の中へは LAN ケーブルか Wi-Fi で引く
- 増幅器付きの装置はアンテナの近くに置くほど効く

## 4. おすすめ

1. まず置き場所を決める：ベランダ（または屋根）がどちらを向いているかで決まる。南西向きなら羽田、東向きなら成田がよく取れる
2. 機材は**案B**（屋外アンテナ＋フィルター入りの装置＋Raspberry Pi 4 2GB）。窓際しか無理なら案A で始め、受かり方を見てから屋外へ
3. 外国のお店から買うときは、日本へ送れるかと送料を注文の画面で確かめる

## 5. 送り先の条件（確かめたこと）

- adsb.lol：送り方の手順は https://github.com/adsblol/feed （11/6 読む）。既定で ADS-B と MLAT を送る。MLAT のために受信機の位置（緯度・経度・高さ）を渡す → **少しずらした位置**を入れる手順にする（次の回）
- adsb.lol の API：将来 API の鍵が要るようになり、鍵は adsb.lol に送っている人がもらえる、と書かれている（https://github.com/adsblol/api 、11/6 読む）。送っている人には「re-api」があり、送っている家の IP からだけ使え、データは ODbL 1.0（https://www.adsb.lol/docs/feeders-only/re-api/ 、11/6 読む）→ そらメモのサーバーから使うときの形は、データ担当への依頼の回で考える
- Flightradar24：送る人は Business プラン（年 US$499.99 相当）が無料。1つのメールで3か所まで。ほかのネットワークにも送るなら Flightradar24 の MLAT を切るように、と書かれている（https://www.flightradar24.com/build-your-own 、11/6 読む）。設定は MLAT="no"・mlat-without-gps="no"（https://forum.flightradar24.com/forum/radar-forums/flightradar24-feeding-data-to-flightradar24/213550-disable-mlat-if-sharing-with-other-networks 、11/6 読む）
- Flightradar24 の Pi24 イメージは「Flightradar24 だけ」に送る形。adsb.lol にも送るので、ふつうの Raspberry Pi OS に readsb を入れ、Flightradar24 の送信ソフト（fr24feed）を足す形にする（次の回で手順）
