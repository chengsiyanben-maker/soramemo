# 報告：t49（見た機体）が日本時間の夜中に落ちる件（keiei/t49-time）

## 作ったもの
- 原因はテストの側。関数（co3_seen・co3_seen_list・co_rides）は正しい
  - テストは便の日付（svc_date）を全部「チェックインの日（T＝今の2時間前）」で入れていた。JL3 の出発は T の35分前なので、日本時間2時〜2時35分ごろ（T が0時台）は出発が前の日になり、本物のデータ（出発の日本時間の日付）と食い違っていた
  - co_rides は「乗った便の出発の日本時間の日付＝便の日付」で突き合わせるので、乗った JA731J が見つからず「乗った機体は一覧から外れる」だけが落ちていた（JL5・JL7 は乗った便に使っていないので落ちない）
- 直したこと（tests/sql/t49_co3_seen.mjs だけ。アプリ・移行は変えていない）
  - 便の日付を各便の出発時刻から出す形にした
  - どの時刻に流しても日付の境目を試す確かめを2つ足した（日本時間0時10分のチェックインと前の日23時40分の便：見える／乗ったら一覧から外れる）

## 確かめた結果
- 時計をずらして流す形で、直す前は 2時10分・2時30分で落ちるのを再現
- 直したあと、日本時間の1日を30分ごとに48回流して全部通過。今の時刻（2時47分）でも通過
