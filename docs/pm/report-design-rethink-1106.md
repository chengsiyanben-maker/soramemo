## デザイン担当のおすすめ
**B（帳面）を土台にし、A の「空港に入ったら半券が前に出て、乗る便を選ぶ」をチェックインの流れに入れる。C の空の窓は、撮る人の「空」タブの中身にする。**

理由
1. 86空港のどこでも中身がある（C は72空港で薄い、A は空港の外の時間が長い人には変化が少ない）
2. 今の図鑑・フライト・経営の画面を捨てずに「帳面のページ」として並べ直せるので、1月に間に合う見込みがいちばん高い
3. 「帳面のページから会社が育つ」で、スタンプラリーと経営のつながりがいちばん見える。今の大きな遠回り（2つのアプリに分かれている）を直せる
4. A のいちばん良いところ（空港に入った瞬間と、乗る便を選ぶ）は、B のまん中のボタンの流れにそのまま入る

## 迷った点
- 機内（A）は電波がない前提なので、出発前に読み込んだものと時刻だけで作る。判定が外れたときの戻し方（上のピルを押して戻す）は細かく決めていない
- 「乗る便を選ぶ」は ODPT の時刻表にある会社（今は JAL・ANA の国内線）だけ。ほかの会社の便は今までどおり2つの印でつなぐ
- B のタブが5つになる（まん中は大きな丸）。4つにするなら「空」をマイページの奥に戻すことになり、撮る人が遠くなる
- 「春の訪問」という札がチェックインの窓に出た。却下済みの「季節のスタンプ」に当たらないか確かめてほしい（案には入れていない）
