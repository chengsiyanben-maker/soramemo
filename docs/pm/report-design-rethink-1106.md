## デザイン担当のおすすめ
**B（帳面）を土台にし、A の「空港に入ったら半券が前に出て、乗る便を選ぶ」をチェックインの流れに入れる。C の空の窓は、撮る人の「空」タブの中身にする。**

理由
1. 86空港のどこでも中身がある（C は72空港で薄い、A は空港の外の時間が長い人には変化が少ない）
2. 今の図鑑・フライト・経営の画面を捨てずに「帳面のページ」として並べ直せるので、1月に間に合う見込みがいちばん高い
3. 「帳面のページから会社が育つ」で、スタンプラリーと経営のつながりがいちばん見える。今の大きな遠回り（2つのアプリに分かれている）を直せる
4. A のいちばん良いところ（空港に入った瞬間と、乗る便を選ぶ）は、B のまん中のボタンの流れにそのまま入る

## 迷った点
- 機内（A）は電波がない前提なので、出発前に読み込んだものと時刻だけで作る。判定が外れたときの戻し方（上のピルを押して戻す）は細かく決めていない
- 「乗る便を選ぶ」は ODPT の時刻表にある会社（今は JAL・ANA の国内線）だけ。ほかの会社の便は今までどおり2つの印でつなぐ
- B のタブが5つになる（まん中は大きな丸）。4つにするなら「空」をマイページの奥に戻すことになり、撮る人が遠くなる
- 「春の訪問」という札がチェックインの窓に出た。却下済みの「季節のスタンプ」に当たらないか確かめてほしい（案には入れていない）

## 2版目で直したこと（11/6・改善担当の指摘1回目と PM の指示）

画面：`docs/design/rethink-1106/` の `*-v2.html`。新しい B' は `B2/`。一覧 index.html に A・B・B'・C を並べた（1版は index-v1.html）。答えは answer-1.md。PNG は png/*-v2.png と、最後まで送った画面 png/full-*-v2.png。

### 必ず直す3つ
1. **予定と実績を分けた**：「乗る」で選んだ便は予定のまま。着いた空港で印をもらったあと（または2つの空港の印がそろったとき）「〜に乗りましたか？」と「〜でしたか？（機体）」に答えたものだけをフライト・路線・乗った機体にする。答えるまでは「答え待ち」。空で見た機体から乗った便にする入口（C2）は外した。着いたは印をもらったときだけ
2. **タブ帯へのもぐり**：最後まで送ってタブ帯と重なるものは 19画面とも 0。B1 の会社のカードを大きな数字のすぐ下へ上げ、最後まで送った画面の PNG を足した（1版も最後まで送れば 0 だったが、最初の画面で経営の入口が隠れていた）
3. **B と B'**：B は5つのタブのまま、まん中の丸を空港の外でも押せる（「あと12.4km」で近い空港の地図）形に直した。地図とシートを守る形 B' を足した（ホームは今の地図とシート・帳面はタブの1つ・タブ4つ・範囲に入るとシートの上に半券と予定の便）

### あわせて直したこと
- 予想の言葉：運用・機体・着く時刻は黄色の「予想」にそろえ、各画面に1回「予想です。保証しません」（指摘8）
- B1 の数字の重なりと「並び：気軽に」「押すと開く」（6）、B3 の見本の印（NRT・HND・IBR）と「2日目」の主語（7）、B4 の「‹ 表紙」「5/5」とピル・C4 の上に空港の使い方（10）
- A の道しるべは押せない見た目、自分で機内にしたときだけ「ちがう」の1行（5）。C3 は今日の便を上に（9）。A0 の字の重なり
- 季節の札（今の本番の「春の訪問」）は案に出さない

### おすすめ
決まりを変えずに進めるなら **B'**、帳面を主役にして決まり「ホームは地図とシート」を変えてよいなら **B**。どちらも C の空の窓は撮る人の「空」の中身（B' は「きょうの空港」カードから）。手間は B' が B より少ない見込み（今のホームを残す）。

### 迷った点
- B' には「空」タブがないので、撮る人には運用が B より1回遠い
- 「2つの印がそろったとき」に聞くのは、乗る便を選ばずに来た人のため。車で来た人は「乗らなかった」を押す手間が増える（ただし今の決まりどおり、2つの印の区間は印として残る）
- B' の画面は新しく作ったが、置き場とファイル名は指示どおり B2/ の *-v2 にした
