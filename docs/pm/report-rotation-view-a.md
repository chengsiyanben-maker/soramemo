## 作ったもの
- 時間の線（案A）：飛んだ便は「今日飛んだ 3便」の1行にたたむ（押すと開く）→ いまの便（橙・「14:18 発」「飛行中」・着く時刻は（推定））→ 紺の帯「ここから予想」と「予想です。保証しません」→ 予想（点線・白い丸・時刻の下に「ごろ」）。日が変わると「明日 11月16日（月）」の区切り
- 確からしさ：「高い・中くらい・低い」と3つの点、横に「12回見た」を小さく薄く。高い＝8割以上で5回以上、中くらい＝6割以上（8割以上でも5回より少ない＝3回中3回はここ）、低い＝4〜6割。割合の数字は「確からしさとは」のシート（A5）だけ
- 運航情報の便（特別塗装機の予定の便）は点でなく、白地に縁のピル「運航情報」。出るときは本番と同じ出典と断り書き（ODPT_CREDIT）を下に
- 予想に出さない決まり：① 出発の時刻が過ぎた便 ② いま飛んでいる便とそれより前の便（運航情報にあっても）。記録のいまの便が古いときは、記録の最後の便を「19:36 着いた・記録に入っている最後の便」と出し、「20:30 JL599 羽田 → 新千歳は、いま飛んでいるので予想に出しません」の1行と「いま飛んでいる JL599 が記録に入るまで、JL148 からの予想を出しています。」（A6）
- 3回より少ない・4割より少ない便とその先は出さない（時刻表のある JAL・ANA の予想 predict_rotation はしきい値がなかったので、画面で同じ決まりにそろえた）
- 予想が出ないとき：「今日この機体はまだ見えていません。見えたら、そのあとの便を予想します」／「この先の便は、まだ記録が足りず予想できません（同じ便を3回見ると出ます）」
- 場所ごと
  - 機体の1日（A1）：上の形。地図は予想の下の「今日の地図」へ（地図に描く予想も、出さない便を除いた分だけ）。「確からしさとは」「近づいたら知らせる」
  - 運用の特別塗装機（A2・A6）：ピル「この先の便（予想）⌄」、開くと紺。小さい時間の線で予想は2便まで、「あと○便の予想」と「機体の1日 ›」
  - 撮る人のくわしく（A3）：「この機体の運用（推定）」→「この機体の運用（予想）」。登録記号と★塗装名、押すと小さい時間の線と「機体の1日 ›」「確からしさとは」。いま飛んでいる便（撮る人の画面で分かっている便名）は予想に出さない
  - 特別塗装機のくわしく（A4）：今日の足あとを時間の線にし（飛んだ便は1行、いまの便）、下に「この先（予想）」を足した。予想は機体を開いたときに1回読み、1分は持つ
  - 確からしさとは（A5）：シート。3段の決め方・運航情報の便・予想に出さない便・出典
- 夜の画面・案内板の配色では、時間の線の色を暗い地の色に替える（いまの便は琥珀。会社の色は使わない）

## 本人に決めてほしいこと
1. 回数の書き方：画面案は「12回中11回」だが、学ぶ予想（v2）が返すのは「その便を見た回数」と割合（新しい日ほど重い・同じ曜日は2倍）だけで、「何回中」が出せない。今は「11回見た」と出している。「12回中11回」にするなら、データ担当に v2 の返す形へ回数の分母を足してもらう（依頼は data.md に書いた）
2. 時刻表のある JAL・ANA の予想（predict_rotation）は、回数が「同じ曜日を2回と数えた点数」なので回数を画面に出していない（確からしさの「5回以上」は点数の半分で少なめに見ている）。あわせて画面で「3回以上・4割以上」にそろえたので、前より出る便が少し減る。よいか（前からの「JAL・ANA でも v2 を先にするか」もまだ）
3. 撮る人のくわしくの予想は、今までどおり押してから開く（開くたびに通信が増えないように）。画面案は開いた形。はじめから開いておくか
4. 画面案 A6 の「1・2」の決まりの箱はカードには出さず、確からしさのシートに「予想に出さない便」として書いた。カードにも出すか
