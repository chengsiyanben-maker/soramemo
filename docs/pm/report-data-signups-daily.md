## 作ったもの（広告の担当からの依頼）
- `admin_signups_daily(日数)`：日本時間の日ごとに「登録・同意・使い方の答え（撮る・修行・気軽・未回答）」の数を返す。運営者（登録と2段階認証）だけ。数だけでメールや ID は返さない。日数は 1〜365（既定30）。0 の日も 0 で返す
- 表は変えない（関数だけ）ので RLS はいまのまま。チェックイン・経営には影響なし
- `docs/pm/signups-daily.sql`：SQL Editor に貼るだけで同じ数が見られる読むだけの SQL（移行の前でも使える）
- 退会した人は数えられない（あとでその日の数が減ることがある）
