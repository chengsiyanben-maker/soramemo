# 報告：案内板を時刻表に（画面案 1版）

担当：デザイン　ブランチ：design/board-timetable（下書きのプルリクエスト・アプリには入れない）
指示：PM 11/26 17時10分（本人「案内板を空港の時刻表のようにして」）

## 作ったもの
docs/design/board-timetable/ に、「いまの空港」の今日の便の一覧だけを空港の時刻表のようにした画面案。
- a1-dep・a2-arr：案A 濃い紺の地に白・黄の文字（出発／到着）
- b1-dep・b2-arr：案B 今の明るい角丸カードのまま列をそろえる（出発／到着）
- index.html：一覧（2案の比べ表・各画面へのリンク・夜／動きを減らすの切り替え）
- 列：定刻（変更後を下に）・便名（会社コードの上に番号）・行き先（経由を小さく）・機材・ゲート・状況（定刻・遅れ・搭乗中・出発済み／到着済み・欠航・推定）
- 「いま 14:22」の線で過ぎた便と分け、過ぎた便は薄く。時間の区切りは「15時台」の小さな字だけ（線は使わない）
- パタパタ：各画面の下の見本ボタンで状況を変えると、変わったセル（状況・変更後の時刻）の字だけが1字ずつ返る（約0.34秒＋1字0.045秒）。行は一度だけ淡く光る。動きを減らす設定では字が変わるだけ
- 時刻表にない便（スカイマークなど）は「推定」を点線の下線で（11/17 の決定に合わせた灰色）。出典の1行は 11/16 の決定の形（運航情報 ○時○分・時刻表 ○月○日時点）
- PNG：png/ に 390×844（2倍）・-667（375×667）・-n（夜）・-list（一覧まで送った位置）・-full（全体）・m-*（パタパタのコマ：0／0.12／0.24／0.8 秒）
- 測った値：12px 未満 0・44 未満のボタン 0・はみ出し 0・字の切れ 0・エラー 0・動きを減らす設定で動くもの 0（390／375・夜）
- 作り方：make/build.py → make/shoot.py → make/index.py（base.css は design/ia-ops から写し、地だけ #EEF1F5 にそろえた）

## 迷った点
- 決まりとの食い違い：「出発案内板風は近い空港のコードと最近の印だけ」「アプリ全体を案内板風にする案は却下」。案A でも紺は今日の便のカードの中だけにし、上の頭・ピル・タブは今のまま。案B は見た目の原則を変えない
- 6列を 375 幅に入れるため、便名は会社コードと番号を2段に、変更後の時刻は定刻の下に重ねた。行き先は 17px で「新千歳」まで切れない（これより長い名前は … で切る）
- ゲート：ia-ops では「搭乗口なし」にしていた。指示に合わせて列を置き、わからない便は「—」。ODPT で取れる空港・会社の範囲はデータ担当に確かめてもらう必要がある
- 夜の画面の案A：夜は光る色を緑だけ、の決まりに合わせて黄を緑にした（「白・黄」から外れる）
- 案B の欠航は線で消した（今の画面にない形）。読みにくければ薄くするだけに戻せる

## 本人に決めてほしいこと
1. 時刻表の形を入れてよいか（決まりの「案内板風は2か所だけ」を、今日の便の一覧に限って外すか）

3. ゲートの列を置くか（わからない空港・会社は「—」が並ぶ）
4. 案A にする場合、夜は黄を緑に変えてよいか
