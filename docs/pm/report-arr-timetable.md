# 案内板の「これから着く便」を時刻表に（checkin/arr-timetable）

11/26 20時45分の PM の積み（本人「案内板のこれから着く便を時刻表に置き換えて」）。画面案は design/board-timetable（#277）の案A・到着（a2-arr）。

## 作ったもの
- いまの空港の案内板で「到着」を選んだときの欄を、紺の地の時刻表にした（出発の欄・国内線／国際線の切り替え・時刻表にない便・今日の遅れ・欠航のグラフは今のまま）
  - 列：時刻（定刻／変更）・便名（会社の2字を小さく）・出発地（経由があれば小さく。国際線は「国際線」）・機材・ゲート（なければ —）・状況
  - 状況：定刻／遅れ（定刻より15分以上。黄色）／到着済み（実際の時刻。行を薄く）／欠航（黄の札）／推定（機体の位置からの見込みだけの便。点線の下線）
  - 変更の時刻：到着済みは実際の時刻、ほかは定刻と5分以上ちがうときだけ（遅いと黄、早いと白を少し薄く）
  - 「いま」の線（過ぎた便と次の便のあいだ）と「○時台」の区切り。頭に「今日の欠航 ○便」（今日の到着の欠航の数）
  - 状況か変更の時刻が変わったときだけ、その字をパタパタ（1字ずつ・行がうすく光る）。はじめて出したとき・変わらないときは動かさない。動きを減らす設定では字を置き換えるだけ
  - 欠航の便はサーバーの next_arr に入らないので、今日の遅れ・欠航（bad）から同じ幅（20分前〜3時間先）の欠航の到着を足して並べた（定刻の順）
  - 長い出発地（ロサンゼルス・サンフランシスコなど）は字を少し小さくして2行まで折る
- src/index.html で変えた関数：`boardHTML`。足した：`boardArrTT`・`ttRow`・`ttList`・`ttFlap`・`ttReduce`・`TT_PREV`。CSS は `#v-ops .bdtt` のかたまり（`.bdchart .ref` のすぐ後）
- web/ を組み立て直した

## 本人に決めてほしいこと
1. 「遅れ」の札は今のアプリにそろえて **15分以上**。5〜14分の遅れは状況「定刻」のまま変更の時刻だけ黄色で出している。空港の案内板のように少しでも遅れたら「遅れ」にするか
2. 頭の数は今は「今日の欠航 ○便」だけ。画面案の「今日 到着 ○便」はサーバーが数を返していないので出していない（データ担当に依頼。届いたら自動で出る）
3. ゲート・経由はサーバーが返していないので、今は全部「—」。データ担当に依頼した（届いたらそのまま出る）

## データ担当への依頼（表は変えない・airport_board の返す中身だけ）
- `airport_board` の `next_arr` の各便に `gate`（flight_schedule.arr_gate）と `via`（経由の空港。あれば）を足してほしい
- 同じく、今日の到着の便の数 `arr_today`（国内線／国際線の絞り込みに合わせる）を返してほしい
- （任意）欠航の到着も `next_arr` に `cancelled: true` で入れてくれれば、bad から足す処理はそのまま重ならずに動く（同じ便名・定刻は1つにまとめている）
