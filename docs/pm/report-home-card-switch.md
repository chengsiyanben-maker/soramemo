# ホームの撮影カードの切り替え（撮る人用担当・11/22）

PM の指示（11/22 22時5分、本人「離陸じゃなくて、他のやつを表示できるような機能にしてほしい」）。ブランチ satsuei/home-card-switch（main 1a87bfd から）。本番には入れていない。

## 作ったもの
- ホームの撮影カード（撮影の構成のときの羽田などのカード）の上に、ピル型の切り替え「着陸」「離陸」「特別塗装機」「遅れ」（横にすべる）
  - 選んだものは端末に覚える（localStorage `soramemo.home.spTab`）。はじめは、表示する機体のうち次に来るのが着陸か離陸かで近い方
  - 着陸：次に降りる注目の機体を大きく（何分後・何時ごろ）＋滑走路（推定）＋そのあと2機。離陸：今の形（出発の時刻と地上走行）＋滑走路（推定）
  - 特別塗装機：今日このあと来る・出る特別塗装機（いま着陸に向かっている・離陸したところ → 時刻表の便 → 航空会社の運航情報の予定。出発済み・欠航・あしたの分は出さない）。なければ「今日はありません」。このピルを選んだときだけ特別塗装機のデータを読む
  - 遅れ：今日の遅れ・欠航の数（大きな数字）と内訳、いちばん大きい遅れ1つ（便名・どこから／どこへ・何分）。データ担当の `bad`（PR #179 の案）が来たらそこから、ないあいだはこれからの便から選ぶ（その場合、機体の位置からの遅れは「（推定）」）
- 長い注意書き（表示する機体・推定・出典・問い合わせ）は「推定・出典 ⓘ」を押すと開く形にたたんだ。カードに出るのは1行だけ
- 「運用を見る ›」は選んだものの専用ページへ（着陸・離陸＝撮る人、特別塗装機＝特別塗装機、遅れ＝遅れ）。一覧の形でない人（soramemo.ops.hub=0）は前の見方の帯で開く
- ピルの並べ替え（11/23 追記・本人「いろんなやつの順序を入れ替えられるように」）：ピルの右の ≡ を押すと並べ替えの形（4行・つまみ ≡・「はじめの並びに戻す」・「完了」）。部品はチェックイン担当の roBind・roGrip・roOrder（#183）。並びは layout.order.hcard に覚える（端末とサーバーの user_view_prefs、「全部乗せに戻す」で戻る）
- ホームの枠（カードの外）は変えていない
