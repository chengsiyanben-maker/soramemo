# 報告：半券が指で切れない直し（11/19 定時の回）

PM から積んだ仕事（11/19 14時05分・本人の iPhone「指で右へ引いても切れない。押すと確かめてから切れるだけ」）。ブランチ checkin/tear-finger（main 3a71781 から）。本番には入れていない。画面の見た目は変えていない。

- 変えるファイル：src/index.html（半券を引く処理だけ）・tests/e2e/t147.py（新）・web/（組み立て）
- 手順：切れる長さを残りに合わせる → はじいたら切る → 縦と横を決める所を直す → 指の操作のテスト
- 確かめ方：CDP の Input.dispatchTouchEvent で、375・390・430 の幅で引く・はじく・縦に動かす・押す

## 作ったもの
1. 切れる長さ：つかんだ所から画面の右端までの残りの半分（28〜56px）。右端から20px（＝画面の端まで約35px）をつかんでも、端まで引けば切れる（必要は28px）。真ん中（残り66px）なら33px
2. はじく：指を離す前の100ms の右への速さが 0.5px/ms 以上で、20px 以上動いていれば、切れる長さに届かなくても切る。速さは指の動きの時刻（e.timeStamp）で数える
3. 縦と横：10px 動いてから決める（前は6px）。横が縦の 0.6 倍以上なら横（前は縦が少しでも大きいと縦）
4. 押すだけ（確かめてから切る）・押せなかったときに戻して理由を出す形は今のまま
- 変えた関数：半券を引く処理（`TEAR_AT` のすぐ下の無名の関数の pointerdown・pointermove・end）。足した：TEAR_MIN・TEAR_AXIS・TEAR_XY・TEAR_FLICK_V・TEAR_FLICK_D・tearAt

## 確かめた結果
- t147（新・3つの幅で28項目）成功：右寄りをつかんで端まで→切れる／左寄りを速くはじく（48px・切れる長さ53px）→切れる／同じ48pxをゆっくり→切れない／縦に動かす→切れず確かめのシートも出ない／先に縦へ6px揺れてから右へ→切れる／ゆっくり少し→戻る／押す→確かめのシート→「はい」で切れる
- 半券に触る今のテスト（t7・t74・t144 ほか t11*・t13〜t56 の40本）：39／40 → t74 の「真ん中から右へ40pxでは切れない」は新しい決まり（真ん中なら33pxで切れる）とぶつかるので「右へ18pxでは切れない」に直して成功。40／40
- ヘッドレスの指の操作は1回の動きが約30ms ごとにしか届かないので、はじくテストは速さ約0.75px/ms で確かめた。本物の iPhone のはじきはもっと速い見込み
- 本人の iPhone で確かめてほしいこと：右寄り・真ん中をつかんで引く／軽くはじく／縦にシートを送ろうとして切れてしまわないか

## 本人に決めてほしいこと
- はじきで切れる速さ（0.5px/ms）と、縦と横の割合（0.6）はこのままでよいか（切れすぎるなら上げる）
