# 新規登録の画面案：報告（2026-11-04）

## 作ったもの
`docs/design/signup/` に、スマホ幅の画面案を8枚と一覧ページを置きました。外部の読み込みはなく、ファイルをそのまま開けば見られます。明るい表示と暗い表示の両方に対応しています。

| ファイル | 画面 |
|---|---|
| index.html | 一覧（8画面を横に並べたもの） |
| 01-login.html | ログイン（「はじめての方は新規登録」のピル） |
| 02-email.html | 1. メールアドレス |
| 03-code.html | 2. 届いたコード（6けた・送り直しまでの秒数） |
| 04-name.html | 3. 表示名（ほかの人からの見え方の確認つき） |
| 05-survey.html | 4. 使い方のアンケート（ピル4つ・飛ばせる） |
| 06-terms.html | 5. 利用規約とプライバシーへの同意（「非公式アプリです」） |

| 08-home.html | ホーム（地図とシート＋登録直後だけの「ようこそ」カード） |

- 色と文字は今の web/index.html の値（ゴシック体、濃いグレーの本文、カードの影、ANA青・JAL赤、航空図の色）に合わせました
- 本番のコード（web/・src/・supabase/）は変えていません
- 画面ごとの黄色いメモは案の説明で、本番には出しません

## 迷った点
- **進み具合の出し方**：上に短い棒を6本並べ、今いる所だけANA青にしました。数字（2/6）より軽く見えるためです
- **アンケートの飛ばし方**：右上の「あとで」と下の「答えずに進む」の2か所に置きました。選ばずに「次へ」を押しても進めます
- **アンケートの絵**：今は端末の絵文字です。本番では線の絵に差し替える想定です
- **コードのけた数**：Supabase の初期設定に合わせて6けたにしました。今のログインの欄は10文字まで入るので、けた数が変わったら箱の数を変えます
- **「非公式」の見せ方**：同意画面のいちばん上に小さな赤いピルを置きました。JAL赤はここだけです。文言は今の terms.html から取りました
- **位置情報の文言**：今の privacy.html の「押したときだけ受け取る」に合わせました
- **ホームのようこそカード**：今のホームに1枚足すだけにしました。出発案内板風は「近い空港のコード」だけです

## 本人に決めてほしいこと
1. **アンケートの答えを何に使うか**：今の案では「ホームで最初に見せる機能を変える」と書いています。本当にそうするか、答えを貯めるだけにするか
2. **表示名の初めの値**：空にしておくか、メールの@より前を入れておくか（今のマイページは@より前を名前にしています）
3. **同意の取り方**：チェックを入れてからボタンを押す今の案でよいか、ボタンを押すだけで同意したことにするか
4. **順番**：同意をメールアドレスより前にするか（先に同意をもらう方が安全という考え方もあります）
5. **ログイン画面の「デモで試す」**：今あるデモモードへの入口を、この画面に残すか
6. **アンケートの答えの保存先**：使う場合は新しい列が要ります。そのときは移行と RLS をセットで出します
