# 報告：フライトの「空の上」を実際の飛行時間に・地図に実際の飛行ルート（checkin/flight-actual）

PM の指示（11/20 2時45分）。ブランチ checkin/flight-actual（main 863fb3d から）。データ担当の data/flight-actual（PR #136・移行187）の列を読む。表は変えていない。本番には入れていない。

## 作ったもの
- **読み込み**：flights の select に act_dep_at・act_arr_at・act_src を足した。列がまだないサーバー（移行187の前）では、前の列で読み直す（記録が読めなくならない）
- **空の上**：act_src（odpt・adsb・timetable）があれば act_arr_at − act_dep_at、なければ今までどおりチェックインの時刻の差。おかしな値（知らない取り先・到着が前）は使わない
  - 日誌の1行：実際の時刻がない便の時間の下に小さく「目安」
  - 年の帯と年のまとめ：推定（adsb・timetable）か目安の便を含むとき、空の上の下に小さく「（推定を含む）」
  - 便のくわしく：「航空会社の運航情報から」「機体の位置から（推定）」「時刻表の定刻から（推定）」「目安・チェックインの時刻から」
  - 区間の合計（地図で区間を選んだとき）・搭乗券の共有の画像の「空の上」も同じ数え方
- **地図**：航跡（track）がある区間は、その区間でいちばん新しい航跡の線を描く（太さは今までどおり回数）。ない区間は今の弧。航跡を描いたときは出典に「航跡：adsb.lol（ODbL）」。動かせる地図・SVG の地図の両方
- 呼び名は「空の上」のまま。見た目は数字と小さな札が増えただけ
