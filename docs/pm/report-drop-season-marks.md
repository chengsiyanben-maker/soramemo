# 季節の印と四季の実績を外す（checkin/drop-season-marks）

PM の 11/24 12時25分の指示（本人の指示・却下済み「季節のスタンプ」とそろえる）。

## 作ったもの
- 搭乗券（チェックインの直後の画面）：「○の訪問」（春・夏・秋・冬）の印と「四季がそろった」を外した。朝・夜・元日の印は残す。時間の印がない日は空の印の行を出さない
- 空港の詳しい画面：春夏秋冬の4つの札と「四季がそろった」を外した（押した回数・階級・押した記録はそのまま）
- 実績：「四季の空港」（season1）と「四季めぐり」（season10）と、その数え（fourSeason・achState の seasons）を外した。実績の数は ACH から数えるので、達成の数・全体の数・％・一覧は自動で合う（分母は 2 つ減る）
- 前に「四季の空港」を称号に選んでいた人：ACH にないので称号は出ない（localStorage の値は残るが表示されない）。記録（チェックイン）は消していない
- 実績の見出し「時間と季節」は、季節の実績がなくなったので「時間と日付」にした（朝・夜・元日の5つ）← PM のおすすめで決めてよい細かい所として変えた
- 残したもの：振り返りの「春夏秋冬それぞれの訪問回数」（SEASONS・seasonOf はそのため残す）。経営の季節（co3 の season）には触っていない

src/index.html で変えた関数：showStamp・openAirport・achState。定数 ACH の2行を消し、見出しの名前を変えた。
