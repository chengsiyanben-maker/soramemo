## 良い点（直さなくてよい所）
- 運用の一覧→専用ページの広がる動きは軽く、戻るも迷わない。タブの切り替えは 70〜110ms で、運用のほかは通信なし

- ピン止めは押すとすぐ「羽田をピン止めしました」のシートで何を知らせるかを選べる。デモでは「届きません」と正直に書いてある
- チェックインを押したときの「印をもらいますか」の確認は短く、押し間違いを防げる
- 空港の3D は「押すと読み込みます（約0.2MB）」で重さが先に分かる。開いたあとの「全体・管制塔・機体」のピルと近くの機体の一覧は分かりやすい
- JS のエラー（pageerror）は0件。Supabase の失敗は下の1件（odpt_feed_at）だけ

## 指摘（効き目の大きい順）

### 1. 運用の「遅れ」の専用ページが空っぽ【大・チェックイン（運用の一覧）】
- 画面・場所：運用タブの一覧の「遅れ 9便」のカード → 専用ページ（01-ops-late-blank-844.png・01b-ops-late-blank-667.png）
- 何が良くないか：カードは「9便」と言うのに、開くと「‹ 運用」と i だけで中身が何もない（15秒待っても同じ。デモ・ログインしない人、844・667 とも）
- なぜ：専用ページ late は案内板（#opsBoard）を隠して、遅れの欄（#opsAlerts）だけを出す作り。遅れの欄は「今の知らせ」がないと hidden のままなので、ページ全体が白紙になる。カードの数（1日の時間ごとの遅れ＋欠航の合計）とページの中身（今の知らせ）が別のものを数えている。はじめての人は壊れていると思う
- どう直す：①カードの数とページの中身を同じものにする（今日の遅れ・欠航の便の一覧を出す）②中身がないときの1枚（「いまの遅れ・欠航の知らせはありません。今日の遅れ 9便は『1日の山』『定時』で見られます」など）③テストに「カードの数が1以上なら専用ページに1行以上」を足す
- 効き目：大

### 2. ODPT のデータの時刻（odpt_feed_at）がまだサーバーにない【大・データ】
- 画面・場所：運用・空港の今・乗る便など、ODPT の出典が出るすべての所
- 何が良くないか：開くたびに `rpc/odpt_feed_at` が **404**。出典に「（運航情報 ○時○分・時刻表 ○月○日時点）」が出ない
- なぜ：決定（11/16）と ODPT の約束（dc:date を出典の近くに出す）で要る表示。画面の側（PR #107）は11/16から待っているが、データ担当の関数がまだない。外部データの規約の確認表でも「dc:date の表示がまだ」のまま。ストアの前に要る
- どう直す：データ担当が `odpt_feed_at()`（移行と RLS をセット・anon と authenticated が呼べる・返す形 `{status_at, timetable_at}`）を出す。移行179 の odpt_feed_dates はあるので、読む関数だけ
- 効き目：大（規約）

### 3. 上の段の「マイページ」がホームで2行に折れる【中・チェックイン】
- 画面・場所：ホームの右上（03-home-mypage-wrap.png）。390 でも 375 でも「マイペー／ジ」
- 何が良くないか：人の絵＋「マイページ」の幅が足りず、最後の1字だけ下の行に落ちる。ほかのタブ（図鑑・運用など）の「マイページ」は1行
- なぜ：入口の名前が読みにくく、壊れて見える。ホームはいちばん最初に見る画面
- どう直す：`white-space:nowrap` にして、幅が足りなければ人の絵をやめるか「スタンプラリー｜エアライン経営」の幅を少し詰める。375 で1行になるかを確かめる
- 効き目：中

### 4. 地図のカードが読み込み中に「0機」と言い切り、開くと「2機」と「この範囲に 0機」が並ぶ【中・チェックイン】
- 画面・場所：運用の一覧の「地図」カード（04-ops-hub-loading.png）と地図の専用ページ（04b-ops-map.png）
- 何が良くないか：開いて約4秒は「0機」（ほかのカードは「—」）。そのあと 2機→8機と変わる。専用ページは「着陸に向かう 2機」の下に「この範囲に 0機」、地図の上に機体の印は見えない
- なぜ：読み込み中を「0」と言うと、はじめての人は「今は飛んでいない」と受け取る（前の見回り 11/13 の8番と同じ形）。ページの中で数が2つあり、どちらを信じればよいか分からない
- どう直す：①機体の通信が届くまでは「—」（`TRAFFIC_TIMER != null || n` の条件を「一度届いたか」にする）②専用ページの数は1つに（「着陸・離陸 2機（この地図の外）」など、地図の外にいるならそう書く）
- 効き目：中

### 5. 特別塗装機のページで「見つかっていません」の下に3時間以内の予定が出る【中・撮る人（土台はチェックイン）】

- なぜ：「来る」が「羽田に着く」だけを数えているので、羽田から出る便が「ない」に入らない。言葉と中身が食い違い、1機・0・予定ありの3つが同じ画面に出る
