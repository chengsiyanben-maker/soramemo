# t30 が main で落ちる件（checkin/t30-fix）

## 原因（アプリの不具合。テストの作りではない）
- ダイアログの「閉じた」知らせ（close）はブラウザの決まりで**あとから**届く。マイページ案B（#213）で「閉じたら目次に戻す」（mpPage(null)）を close に付けたため、
  「閉じてすぐ別のページで開き直す」と、開き直したあとに知らせが届いて目次に戻り、「詳しい設定」の中身（デモの「開始」）が隠れていた
- 同じ知らせで、戻る操作の積み（CX_STACK）からも外れ、開き直したマイページが戻る操作で閉じなくなっていた
- t30 は `close()` のすぐあとに `openMyPage("adv")` を呼ぶので、画面の処理が少し重くなった #218 から毎回この順で起きるようになった。ふつうの指の操作では起きにくいが、閉じてすぐ開き直す流れ（画面同士の行き来）なら使う人にも起きうる

## 直したもの（src/index.html。変えた関数・場所）
- dSettings の close の受け手：まだ開いている（開き直した）ときは目次に戻さない
- showModal の包み（閉じるはいつでも押せる）の close の受け手：開き直していれば cxPop しない（積みに残す）
- web/ を作り直した（tools/build.mjs）

## 確かめた結果
- 直す前の main：t30・新しい t193 とも落ちる（デモの「開始」が見えない）
- 直したあと：t30 を4回・t193 を4回すべて成功。t189・t183・t163・t120・t123・t118・t119・t124・t145・t184・t73・t47・t54・t57 も成功
- t193（足した）：閉じてすぐ「詳しい設定」で開き直す → そのページのまま・デモを始められる・積みに残る・戻るで閉じる・ふつうに閉じれば目次に戻る
