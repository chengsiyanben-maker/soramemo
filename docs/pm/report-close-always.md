# 報告：閉じるはいつでも押せるように（PM 11/21 22時・checkin/close-always）

本人「閉じるの機能は、いつでも触れるように」。見た目はほぼ今のまま。

## 作ったもの
1. **読み込み中・失敗した時の 3D**：左上の × が「読み込み中」の幕の下に隠れて押せなかった（幕の重なりが上だった）。× の段を幕より上にした。読み込み中と失敗の幕の上では、× だけを出す（題と「…」は幕が消えてから）
2. **上に固定・44px以上**
   - 全画面（機体のくわしく・特別塗装機・撮影地・管制・データの使い方・あの日の空・傾向・ピン止め など .spctop／.pintop の頭）：中身を送っても頭の段（‹ 戻る と題）が上に残る。iPhone のノッチを避ける（safe-area）。‹ の押せる高さを 38px → 44px
   - マイページ（設定）の頭も同じ
   - シート（.spsheet）：上まで引いて中身を送っても、つまみと × の段が上に残る。× は見た目の丸 32px のまま、押せる所を 44px に
   - 空港のページ：今は下の「閉じる」だけで、中身が長いと下まで送らないと閉じられなかった。右上に × を足し、送っても残す
   - 運用の専用ページ：下へ送ると「‹ 運用」が画面の外に出ていた。上に止める（白い丸のボタンがそのまま浮く。段の背景は付けない）
3. **戻る操作で閉じる**：ブラウザの戻る・iPhone の左の端から引く戻る（Safari／ホーム画面のアプリ）で、いちばん上に開いている画面を1枚閉じる（ダイアログ全部と運用の専用ページ）。重なっていれば上から1枚ずつ（3D → 空港のページ）。× で閉じたときは足した履歴を戻すので、戻るが空回りしない。閉じさせない画面（登録の途中など cancel を止めている所）は戻るでも閉じない
   - **3D は左の端（24px）から右へ引いても閉じる**（指に付いて動き、幅の3割か速くはらうと閉じる。短いと戻る。端から始めた指は 3D を回さない）
   - 運用の専用ページは「開く動き」の途中でも戻れる（前は動きの0.46秒のあいだ戻るが効かなかった）
4. **読み込みに失敗した時も × が残る**（1 と同じ）

### src/index.html で変えた関数（下の担当も触るので）

- CSS：ファイルの style の最後に「閉じるはいつでも押せる」のまとまり（.spctop／.pintop／.mp-top／.spsheet .sph の sticky、.cxbar／.cx、.a3top の重なり、運用の専用ページの .opsbar の sticky）
