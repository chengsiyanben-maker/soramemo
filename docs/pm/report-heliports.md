## 5. 本人に決めてほしいこと
1. **ヘリポートで印を押せるようにするか**（いちばん大事）。今の checkin 関数は extra_kind が空でない行を全部「番外編の印」にするので、この移行を反映すると、そのまま印が押せるようになる
   - 案A（おすすめ）：押せる（滑空場・飛行場と同じ番外編の印。図鑑は「ほかの図鑑・実績」の飛行場・滑空場の図鑑に入れるか、別の図鑑にする）
   - 案B：並びに出すだけで押せない → 反映の前に、チェックイン担当が checkin 関数の読み出しに `extra_kind <> 'heli'` を足す
2. 非公共用ヘリポート83か所は入れない案でよいか（県警・病院・庁舎・ビルの屋上が大半で、近づく所ではない。入れるとしても地上の数か所だけ）
3. 名前：国の一覧の名前（「豊富」など）に「ヘリポート」を付けた。東京は一覧では「東京都東京」だが、ふだんの呼び名「東京ヘリポート」にした
4. 「反映して」（画面がヘリポートを出せるようになってから。下の依頼と同じ時に）
