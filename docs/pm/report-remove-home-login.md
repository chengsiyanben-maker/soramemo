# 報告：ホームのメールのログイン欄を消す（チェックイン担当・11/6）

ブランチ fix/remove-home-login（main 14916e9 から）、下書きのプルリクエスト。main には入れていない

## 作ったもの
- ログインしていないときのホームから、前からあるメールのログイン欄（メールアドレス・コードを送る・コード欄・「はじめての方は新規登録」・「登録しないでデモで試す」）を消した（本人の決定 11/6）
- ログインの入口は、右上の「ログイン」と、シートの「ログイン・登録」の2つだけ。どちらもログインの画面（dAuth）を開く。ログインの画面の中の「新規登録」「デモで試す」は今のまま
- いっしょに消したもの：欄のためだけにあったコード（送る・確かめるの処理、欄用のロボット除けの部品、.login の見た目）。ログインの画面が使う回数の制限（LOGIN_GUARD）とロボット除けのあるなし（captchaOn）は残した
  - 副産物：ログインしていないホームを開いただけでは、ロボット除けの部品（Cloudflare Turnstile）を読み込まなくなった。ログインの画面を開いたときだけ読み込む
- テストを、ログインの画面を開いてから入る形に直した
  - t7：ホームに欄がないこと・右上の「ログイン」でログインの画面が開くこと・そこからコードを送れること
  - t43：ホームでは部品を読み込まないこと・ログインの画面でロボット除けの合図つきで送り、合図が1回で使い捨てになること
  - t44：右上からログインの画面に入り、違うコード・正しいコードでログインし、ログイン前の記録の引き継ぎの案内が出ること
  - t114：ホームに欄がないこと／右上の「ログイン」・シートの「ログイン・登録」でログインの画面が開くこと／登録していないメールなら新規登録へ案内／ログインの画面の「はじめての方は新規登録」でメールの段へ進むこと
- 写真 docs/pm/shots-remove-home-login/：compare-sheet-390・375（左が前・右が後。シートを引き上げていちばん下まで送った位置）、after-390・375（開いたときの位置。前と変わらない）

- 全体の流し（86本。運営コンソールの4本は飛ばす）：78/86 成功。落ちたのは前から落ちている4本（t99・t105 は経営の画面・t48 は pdf417gen がない・t57）と、読み込み直しで揺れる4本（t27・t34・t61・t62）
