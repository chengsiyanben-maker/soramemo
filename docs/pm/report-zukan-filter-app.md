# 報告：飛行場・滑空場・ヘリポートの図鑑に種類の絞り込みと県名（checkin/zukan-filter）

PM の指示（11/20 2時45分）・画面案 design/zukan-filter 1版（PR #135）の F1・F2・F3。ブランチ checkin/zukan-filter（main 863fb3d から）。表は変えていない。本番には入れていない。

## 作ったもの
- **見方の帯「地方別・地図」**（F3）：図鑑と同じ下線の帯。押す所 44px
- **種類のピル**「すべて 75・飛行場 30・滑空場 33・ヘリポート 12」（F1）：ピルの溝に4つ、名前の下に小さな数。基地は今のまま別の図鑑
- 絞ると黒いカードの数・地方の数・扉・枠・ツメがその種類だけになる。黒いカードの頭は「● ヘリポート 1 / 12」、中身のない地方は扉を出さずツメは押せない
- 1つの種類に絞ったときは、枠の種類の札と扉の「飛行場・滑空場・ヘリポート」の札を外す（F2）
- **県名**：全部の枠の名前のすぐ下に 13px の薄いグレー（取っていない所も）。データは XA の pref のまま
- **地図**（F3）：絞った種類の点だけ。行った所は色の丸と名前、まだは灰の輪。黒いカードは数の1行だけ、ツメは出さない。地図の下に「まだ ○」の一覧（県名つき・押すと空港のページ）。夜は滑空場を四角、色は使わない
- ピルと見方は端末に覚える（localStorage soramemo.zkx.kind・soramemo.zkx.view）。知らない値は「すべて」「地方別」に戻す。デモの間に変えた分はデモを終えると戻す（DEMO_LO_KEYS に足した）
