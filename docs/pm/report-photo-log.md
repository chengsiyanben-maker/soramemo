# 撮影記録の画面案（photo-log・2026-11-06・デザイン担当）

PM の指示（11/6 22時45分）。撮る人用担当の依頼 9-1。仕様は satsuei/photo-log-spec（PR #24）の docs/pm/spec-photo-log.md の 3・4。アプリのコードは変えていない。明るい表示だけ。

- 変えたファイル：docs/design/photo-log/（index.html・11画面・png/）とこの報告
- 手順：仕様と、本番の撮る人の見方（フライトストリップ：帯の色 着陸＝--hero・離陸＝#8C9AAE、標識の書体 --sign）・図鑑の札（乗った・見た）を src/index.html から拾い、ストアの画面案と同じ色と字で作った
- 確かめ方：幅390×844で撮った。13px 未満は単位12px（km・分差）だけ・押せる所で44px 未満 0・はみ出し 0。一覧（04a・04c）は長いので、開いたときに最後の1行がタブ帯の後ろへ入る（下へ送れば見える）

## 迷った点
- ホームに入口を置くか：置かなかった（ホームの枠はチェックイン担当、選べるホーム D が決まったら「撮影地と光」のカードに小さな入口を足すのがよい）
- 時刻が読めない写真に時計のずれを足すか：足さない形にした（ファイルの時刻はカメラの時計ではないため）。仕様にないので撮る人用担当に確かめたい
- 「撮った」の印の色：ほかの2つ（灰色の地）より少し目立つ薄い金にした。図鑑の札が派手になりすぎないかは改善担当に見てほしい
- 帯の画像に「非公式アプリ」のピルを入れるか（共有画像の決まりに合わせるか）は本人に聞く
- 塗装名・航空会社名・登録記号はすべて見本（実在の塗装の絵や名前は使っていない）

## 本人に決めてほしいこと
1. 撮った機体の一覧の置き場所：案1（フライトタブの「乗った便／撮った機体」）か案2（マイページのタイルから開く）か。運用タブの「撮る人」の中に置く案は、運用の土台を変えることになるので描いていない
2. 帯を入れた画像を最初の版に入れるか（入れるなら 06 の形でよいか、「非公式アプリ」を入れるか）
3. 図鑑の「撮った」の印を、乗った・見たと同じ並びに足してよいか

## 改善担当に見てほしい点
1. 02 候補を選ぶ：初めからいちばん上を選んだ状態にしている。違う機体を選びやすいか、選んだのが分かるか（紺の枠と丸だけで、黒い札は使っていない）
2. 02 の右の大きな数字（分の差）が「時刻」に見えないか。単位「分差」が12pxで小さい
3. 02b：確かめるまで候補を薄くし、ボタンを押せなくした流れが分かるか
4. 03：ずれの向き（遅れていたら足す）が一度で分かるか。「写真の時刻＋ずれ＝本当の時刻」の1行で足りるか
5. 04a と 04c：どちらのほうが撮る人に見つけやすいか。04a の「フライト」の名前が撮るだけの人に合うか
6. 05：「撮った」の薄い金の札が、図鑑の中で目立ちすぎないか
7. 写真を送らないことを書いた場所（01・02・03・06）が多すぎないか、足りないか
