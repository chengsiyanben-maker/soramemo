# 全部乗せ・タブから選ぶの細かい版（all-in-tabs・2026-11-08・デザイン担当）

11/8 21時半の本人の決定「見せ方は案3（タブから選ぶ）」を受け、PM の指示がない回として帳面の「次にやること（選ばれた案を細かくする）」を進めた。C1〜C4（design/all-in-filter-alt）に足りない状態を描いた。アプリのコードは変えていない。

- 変えたファイル：docs/design/all-in-tabs/（8画面・png/・index.html）とこの報告。ブランチ design/all-in-tabs（design/all-in-filter-alt から分けた）
- 確かめ方：幅390で高さ844と667を撮った。13px 未満は単位だけ・押す所で44px 未満 0・4.5:1 未満 0・はみ出し 0（T1 のはらう途中の行は、わざと左へずらしているので除いた）

## 作ったもの
| 画面 | 中身 |
|---|---|
| T1 左へはらって外す | 行が左へずれ、濃い紺の「外す」が出る（赤は使わない）。ログインしていない人には「この端末に保存します（ログインすると…）」の1行を足す |
| T2 並べ替え中 | 持った行は白く浮いて金の縁、入る所は線の枠。下のタブ帯もその場で並びが変わる |
| T3 5つでいっぱい | 「出す」を押すと、もう1枚のシートで「どのタブと入れ替えますか？」。選ぶと結果を1行で見せる |
| T4 見方の帯から外す | 見方の帯を長押しすると、金の縁の1枚に全部の見方が折り返して並び × で外す。外した見方は ＋ のピル。最後の1つは × が消える |
| T5 ホームに出すもの：全部外した | 見本に半券だけ残り「ホームは地図と半券だけになります」。止めない |
| T5b そのあとのホーム | 半券とシートのいちばん下の「ホームに出すものを選ぶ ›」だけ |
| T6 マイページの入口 | 「表示を選ぶ」（タブを選ぶ・ホームに出すもの・見方）と「タブにない画面」と「全部乗せに戻す」 |
| T7 全部の機能を出しています | 提案を見なかった人に1回だけ出すカード。長押しの1行・タブ帯を金の縁で光らせる。濃いボタンは「このままでよい」 |

## 迷った点
- **はらう側の色**：消すのではなくタブから下ろすだけなので、赤でなく濃い紺にした
- **見方の入口**：PM の仕様どおり見方の帯から。長押しは「タブ帯の長押し」と同じ動きにそろえた（帯の右端に「編集」を置く案もあるが、帯の幅を取るのでやめた）
- **1版の「表示の編集」の1枚**：T6 では3つの入口に分け、1枚の画面は置いていない。残すなら「見方」の行の先にする
- **高さ667**：タブを選ぶのシートは画面より高くなるので、シートの中を送る形にした（T1・T2）。T7 のボタンは667では送ると見える
