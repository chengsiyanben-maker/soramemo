## 作ったもの
| 画面案 | 作ったもの |
|---|---|
| C1 タブを選ぶ | 下のタブ帯（スタンプラリーのとき）を約0.55秒長押しすると開くシート。タブ帯は金の縁。ホームは1番目で「いつも」。≡ を持って上下に並べ替え（矢印のキーでも）、行を左へはらうとタブから外れる（「元に戻す」つき）。「タブにないもの」の「＋ 出す」で戻す。5つあるときに6つ目を出すと「どれと入れ替えますか？」と聞く。2つより減らせない。いちばん下に今のタブ帯の見本 |
| C2 ホームに出すもの | 見本の上で × で外し、「外したもの N」の ＋ で戻す。半券と今日の数字は「いつも」。下の黒い帯で「元に戻す」。入口はホームのシートのいちばん下の1行「ホームに出すものを選ぶ ›」・タブを選ぶのシート・マイページ |
| C3 全部乗せに戻す | タブを選ぶ・ホームに出すものの「全部乗せに戻す」から。戻したあとのタブ帯（5つ）を小さく見せ、タブ・見方・かたまりで何が戻るかを1行ずつ見せてから「全部出す」 |
| C4 提案 | アンケートの答えから1回だけ。「いま」と「こうなります」の2本のタブ帯（外れるタブに取り消し線）。気軽に＝「タブを3つにしますか？」（運用・修行と見方など、あわせて15こ）、撮る＝4つ（修行）、修行＝4つ（運用）。ボタンは同じ白・同じ大きさ（「5つのまま使う」「3つにする」）。下に「どちらでも、あとからタブを長押しして変えられます」で長押しをここで1回だけ教える。前の版の、1つずつ残すピルはなくした |
| 見方 | 今までどおり各画面の見方の帯の右の鉛筆から（今の「表示の編集」のその画面の見方の所が開く） |

## 本人に決めてほしいこと
1. 1版の「表示の編集」の1枚の画面（40このピル）を、マイページの「全部を見直す」として残してよいか（今は残した。見方を全部まとめて見る所がほかにないため）
2. 「今日の数字」はホームに出すものの見本では「いつも」（外せない）にした。画面案は × で外せる形だが、今は隠せるかたまりに入っていない。外せるようにするなら数（40こ）が1つ増える
3. 長押しで開いたシートはタブ帯の上に重ねて出すため、本物のタブ帯は暗くなる。代わりにシートのいちばん下に金の縁の見本のタブ帯を置いた（画面案では本物のタブ帯が金の縁で見えている）
4. 図鑑・フライト・運用・成績の「○○に出すもの」（画面ごとの見本）は今回作っていない。運用・成績のかたまりは今の鉛筆からの画面で隠せる
