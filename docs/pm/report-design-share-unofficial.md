# 共有画像に「非公式アプリ」を入れる案：報告（2026-11-05）

広告担当の依頼（report-ads-early-access.md の「アプリ側に頼みたいこと」4）への画面案です。チェックイン担当が作る前に見てもらうためのもので、アプリのコードは変えていません。

## 作ったもの
`docs/design/share-unofficial/` に、スマホ幅の画面案7枚と一覧（index.html）、PNG（png/）を置きました。外部の読み込みはありません。共有画像は今の src/index.html の描き方（cardBase・drawStamp・tallyLine・photoStamp）を写して描いているので、本番とほぼ同じ見た目です。各画面で「いま／案A」と色（白黒・赤白・空）を切り替えられます。

| ファイル | 中身 |
|---|---|
| 01-stamp.html | 印の共有画像 |
| 02-stamp-rank.html | 記章と称号つきの印（称号とピルが重ならないかの確認） |
| 03-map.html | 地図の共有画像 |
| 04-photo.html | 写真に押した印 |
| 05-year.html | 1年のまとめ（パスポート・昨日の空港・空の道・その日の空も同じ下の端） |
| 06-sheet.html | 共有の画面と、一緒に送る文 |
| 07-compare.html | 置き場所の比べ（案A と案B） |
| png/image-*.png | 画像そのもの（1080×1350）。now＝いま、a＝案A、b＝案B |

**案A（おすすめ）**
- 見出しの「そらメモ」の右に、細い枠のピル「非公式アプリ」（薄いグレー・24px）
- 印と地図の画像は、いちばん下に「soramemo.jp」。「#そらメモ」がある画像は「#そらメモ　soramemo.jp」
- 写真に押した印は、左上を半透明の黒いピル「そらメモ　非公式アプリ」に
- 一緒に送る文を「#そらメモ」から「#そらメモ（非公式アプリ）」＋ URL に
- 変えるのは cardBase・photoStamp と、下の端の文字・共有の文だけ。全部の共有画像が cardBase を通るので、直す所は少ない

## 迷った点
- **置き場所**：アプリ名のすぐ横（案A）か、下の端の断り書き（案B）か。画像が切り取られても名前と一緒に残る A を推しました
- **称号との重なり**：称号は右上に右寄せ。ピルとの間が狭いときだけ称号の字を 32→最小22 まで小さくする決まりにしました
- **ピルの色**：JAL赤・ANA青は使わず、どの色（白黒・赤白・空）でも目立ちすぎない薄いグレーにしました
- **写真の見本**：他人の写真は使えないので、夕方の空を描いた見本です
- 地図の点は見本で、本当の記録ではありません

## 本人に決めてほしいこと

2. 画像に「soramemo.jp」を入れてよいか

4. 決まったら、作るのはチェックイン担当（src/index.html の共有画像の部分）でよいか
