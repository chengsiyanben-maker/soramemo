# 報告：海外の航空会社の便も遅れの通知の対象に（データ担当・11/16）

PM の指示（11/16 10時50分、本人「進める」）：ODPT の空港ビル会社の発着情報を取り込み、BA5・LH716 など海外の航空会社の便も flight_schedule・odpt-status に入れる。まず利用の範囲を原文で確かめ、使えないものは使わない。

## 結論（先に）
**ODPT の空港ビル会社のデータは、そらメモの本番には使えない。取り込みは作っていない（コード・表・移行は変えていない）。**
- ODPT にある空港のデータは「東京国際空港ターミナル（TIAT、羽田の国際線）」の3件（フライト時刻表・リアルタイム出発・リアルタイム到着）だけ。成田（成田国際空港株式会社）・羽田の国内線（日本空港ビルデング）・関西などは ODPT にない
- TIAT の3件のライセンスは「公共交通オープンデータチャレンジ限定ライセンス」で、データの頁に「【チャレンジ2026限定】」と書かれている。JAL・ANA の7件（基本ライセンス）とは別のライセンス
- チャレンジ限定ライセンスは「チャレンジ限定でデータ公開をするためのライセンス」「目的外の利用は禁止」（協議会事務局の説明資料）。チャレンジ2026の分は 2027年3月12日に許諾が終わり、終わったらただちに使うのをやめて消す（第13条。ほかの開発者の記録でも同じ読み）
- そらメモは常設のアプリなので「チャレンジへの応募」という目的に当たらず、仮に応募しても 2027年3月で使えなくなる。→ 決まり「外部データは規約の範囲を確かめてから使う」に従い、使わない

## 確かめたこと（原文・2026年11月16日）

## 乗る便に選べるか（アプリを読んだ結果）
- ホームの「便名を入れる」：JAL・ANA の時刻表にない便（BA5 など）は、**いま飛んでいるときだけ** adsb.lol の位置から見つかり、選べる（index.html の rideAdd。「そのほかの航空会社は、いま飛んでいる便だけ探せます」と出る）
- 空港の案内板の「この便に乗る」：ALBY にある会社の便だけ（案内板の元は JAL・ANA）
- push-subscribe は BA5@2026-11-16 の形も受け取る。けれど通知の仕組み（odpt-status・alert_merge・flight-watch）は flight_schedule の行から始まるので、**選べても通知は1つも出ない**（今の困りごとの原因はこれ）
- 画面の直しは、データの元が決まるまで要らない（チェックインへの依頼はなし）

## 代わりの案（本人に決めてほしい）
1. **案A（おすすめ）乗る便に選んだ海外の便だけ、機体の位置で見張る（推定）**：外の新しいデータは使わない（今の adsb.lol と adsb.im の経路だけ）。飛んでいる間に、成田の門限（24時）の10分前より遅く着く見込み・ダイバート・引き返しを「推定」で知らせる。**定刻がないので「○分遅れ」・0時前後（定刻と比べる決まり）・欠航・出発前の遅れは出せない**。flight_schedule に「推定・定刻なし」の行を入れるか別の小さな表にするかで、移行（RLS つき）が要る。羽田は門限がないので、羽田着の便はダイバート・引き返しだけになる
2. **案B 空港会社に直接聞く**：旅そら（ryoairtrip@gmail.com）から、東京国際空港ターミナル（羽田国際線）と成田国際空港に、発着情報を個人開発の無料アプリで使ってよいか・条件を問い合わせる。返事しだいで取り込みを作る（時間がかかる・断られることもある）。文の下書きは下に
3. **案C ODPT 事務局に聞く**：TIAT のデータをチャレンジのあとも常設のアプリで使える形（基本ライセンス）にする予定があるかを聞く。案B と一緒に出してよい
4. **しない**：ODPT のチャレンジに応募して TIAT のデータを使う案は、2027年3月に消すことになり、本番の機能にできないので勧めない

案A と案B・C は一緒に進められる（案A で今すぐ一部を出し、正式なデータが来たら定刻つきに切り替える）。

## 本人に流してほしい読むだけの SQL（任意・軽い）
乗る便に選ばれている便のうち、時刻表（flight_schedule）にない便がどのくらいあるか（＝案A・B の効き目）。push_subs の便の数だけ索引で引く形。

```sql
set statement_timeout = '15s';
with k as (
  select distinct unnest(flights) as k from push_subs where flights <> '{}'
)
select left(split_part(k.k, '@', 1), 2) as 会社, count(*) as 選ばれた便,
       count(*) filter (where not exists (
         select 1 from flight_schedule f
         where f.svc_date = split_part(k.k, '@', 2)::date and f.flight = split_part(k.k, '@', 1)
       )) as 時刻表にない
from k where k.k ~ '^[A-Z0-9]{2}\d{1,4}[A-Z]?@\d{4}-\d{2}-\d{2}$'
group by 1 order by 3 desc, 2 desc limit 20;
```
