# 羽田の3D をもっとリアルに・動きの推測（checkin/3d-real）

PM 11/26 17時05分・本人の指示「3Dモデルをもっとリアルに、動きも推測を加えて」。大きな3Dの見た目の変更なので、**出す前に PM が写真と短い動画を本人に見せて OK をもらう**。

## 作ったもの
- **動きの推測（新しい計算のかたまり `A3K`。three.js も画面も使わない）**
  - ④ 答えのあいだ：両端の速さと向きを使った3次の曲線（エルミート）でつなぐ。旋回の途中も角が立たない。高さも上昇率で曲線に。速さ×時間が距離と合わない（地上でゆっくり・データの乱れ）は前と同じ直線
  - ④ 先を読む所は、いまの曲がり方のまま（90度まで）。跳んだ所（先を読んだ位置に次の答えが来て食い違った・誘導路に寄せた）は差を約1.5秒で0にして、瞬間移動させない
  - ⑤ 姿勢：傾き＝曲がり方からの釣り合った旋回の角度（30度まで）、機首＝上昇の角度＋迎え角。離陸の引き起こし（約125ノットから8度）・着陸の引き起こし（300ft より下）・接地のあと遅くなると前輪を下ろす。少しずつ目標へ
  - 高さ300ft までの空（引き起こし・離陸の直後）は、これまで地面に貼り付いていたのを地面から浮かせた
  - ⑥ 脚（前と同じ決まりを A3K へ）・**フラップ**（新しく形を足した。前の形・細かい形とも、後ろの縁の板がちょうつがいの線のまわりに下がる。着陸の前は高さで 0.25→0.6→1、離陸のはじめは少し）・着陸灯（脚を出した空に加えて、**滑走路を走るあいだ**も）
  - ⑦ 地上：後ろ向きに動く機体（プッシュバック）は機首の向きのまま、名札は「後ろへ」。走っている機体（3〜35ノット）は**誘導路の中心線（形のファイルの twy）に35m 以内なら寄せて**、向きを線にそろえる
  - ⑧ 途切れた着陸機：向きが合う滑走路の延長線に寄せながら、その速さ・3度の道すじで降ろし、10秒を過ぎたら薄くして60秒か滑走路の端で消す。合う滑走路がなければまっすぐ先へ20秒
- **「推定」の見せ方**：途切れた機体と誘導路に寄せた機体の名札に点線の小さな札「推定」。機体のカードに「この機体の位置は推定です…」「地上の道すじは推定です…」と「傾き・機首の上げ下げ・脚・フラップ・着陸灯は…推定です（実際の操作の記録ではありません）」。出典のシートに「機体の動き：推定」の行
- ② 動きを減らす設定では、機体と滑走路の灯りを点滅させない（灯したまま）
- 重さ：フラップは機種ごとの形と一緒に1回作って使い回す。3Dを開くまで読まない・裏で止める・自動の質下げは今のまま
