# ほかのアプリと比べた、そらメモのデザインを良くする案：報告（2026-11-06）

PM の指示（ほかのアプリと比べて、見た目と使いやすさを上げる案を出す）への報告です。アプリのコードは変えていません。ほかのアプリの画面はリポジトリに入れていません。学んだのは考え方だけで、見た目・配色・アイコン・言い回しはまねしていません。

## 1. 今のそらメモ（main の web/ を手元で開き、スマホ幅390で撮影）
`docs/design/improve-1106/png/now-*.png`（デモモード）：ホーム・図鑑・フライト・運用・修行・成績・マイページ・登録。経営の画面は対象外。

目立ったこと
- ホームの上に3段（ロゴとマイページ／スタンプラリーとエアライン経営／デモの帯）があり、縦に約180pxを使う。地図の＋−がデモの帯に半分隠れる。シートの下の文が下のタブ帯にもぐる
- 地図は国土地理院の普通の地図のままで、原則の「航空図風」になっていない
- マイページは原則の「タイル」ではなく、説明文つきの縦の段。左上の「ホーム」に黒い太い枠が出たまま
- 運用は、値がまだないカード（風「ー」、遅れ・欠航「読み込み中」）が1枚ずつ場所を取る。上の切り替え（滑走路・定時・空の道すじ・短冊・撮る）が右で切れていて、続きがあると分かりにくい
- 端末を暗い表示にしても、アプリは明るいまま（暗い表示の色は経営の帯だけ）
- 修行・運用の注意書きが長く、小さい薄い字が何段も続く
- 見出しの「そらメモ」の字の間が広く、「そ ら メ モ」と離れて読める
- よい所：フライトの数字（30フライト・15路線・24,088km）、図鑑の地方タイル、近い空港のパタパタ、成績のパスポートは、数字が大きく太く、原則どおり

## 迷った点
- **切り替えの言い方**：ホームの上を1段に収めるため「スタンプラリー／エアライン経営」を「印／経営」と短くしました。言い方は本人に確認したい
- **航空図風の地図**：色だけの見本です。地図の元（国土地理院）は変えず、色を重ねる形を考えています。実際にどこまで色を変えられるかはチェックイン担当と相談が要ります
- **運用の「今日の定時 87%」**：今の「定時」の画面にある数字を1枚目に出す想定の見本です。新しいデータは使いません
- **暗い表示**：今ある案内板の色（黒地に琥珀色）を暗い表示に使うと「アプリ全体を出発案内板風にする案」（却下済み）に近づくので、濃い紺を土台にしました
- ホームの「最近の印」と近い空港のパタパタは、原則で案内板風が許されている2か所だけです

## 本人に決めてほしいこと
1. 上位3つ（ホーム・マイページ・運用）の向きでよいか。1月のストアの前にどれから作るか
2. ホームの切り替えを「印／経営」と短くしてよいか
3. 暗い表示（案7）を1月の前に入れるか、あとにするか
4. 作るのは、ホーム・マイページ・運用ともチェックイン担当でよいか（経営のタブは今回は触れていません）
