# 報告：運用タブを「全部が一つに並ぶ一覧＋押すと専用ページ」に（design/ops-hub 1版）

PM の指示 11/19 14時10分と本人の追記 14時07分（シンプルに）から作った。画面案だけで、アプリには入れていない。
置き場所：docs/design/ops-hub/（一覧ページ index.html、PNG は png/、作り方 make/make.py → make/shoot.py）

## 作ったもの
- 一覧：H1 案A（機体の検索窓を上に残す）・H1b 案B（機体を一覧の1枚のカードに）。昼と夜（H1n・H1bn）
- 広がる途中：H2 滑走路・H2m 地図（昼夜）、H2d 左端から引いて戻る途中
- 専用ページ：H3 滑走路・H4 地図（昼夜）
- H5 空港を切り替えるシート（ピン止めの空港が先頭、ピン v4 の形）・H6 i の中（出典と注意をまとめる）
- 動き：png/motion.mp4（昼）・motion-n.mp4（夜）、約5秒。滑走路を開く→左端から引いて戻る→地図を開く→戻る。連番は motion-strip(-n).png。M1・M1n は触って試せる（カードを押す・戻る・左端から引く）
- 決めた形
  - 「空港｜機体」の切り替えと見方のタブをなくし、頭は「空港のピル（ピン）＋i」だけ
  - カードは見出し1語＋大きな数字か小さな絵：滑走路（紺・北風＋使う滑走路）・地図（航空図風・23機）・案内板 15:18 着・特別塗装機 2機・遅れ 8分・短冊 2分後・1日の山（棒）・定時 86%（輪）・空の道すじ（線）・撮る人 4か所。下に「並べ替え・隠す」
  - 広がる動き：押したカードがそのまま専用ページの頭の箱になる（共有要素）。地図は地図ごと広がる。ほかの中身は後から下からふわっと出る。開く約0.46秒・戻る約0.38秒
  - 左端から引くと、ページが指に付いて右へ動き少し小さくなり、離すとカードの位置へ縮んで戻る
  - 専用ページの説明は1行だけ。出典（adsb.lol（ODbL）・ODPT・気象通報）と「推定と予想は保証しません」は i の中
- 測った値（393×852 と 393×667）：13px 未満の字 0・はみ出し 0・字の切れ 0。44px 未満の押す所は 0（H2d の引いている途中で小さく見えるものだけ）

## 迷った点
- 本番に夜の画面がまだないので、夜の色は design/ios-app の夜と同じにした
- カードの数字（遅れ 8分 など）が何の数か一覧では分からない。本人の「文字を減らす」を優先し、意味は専用ページで出す
- 案A と案B で 1日の山の大きさが違う（カードの数を偶数にそろえるため）
- 滑走路と地図以外の専用ページはまだ描いていない（今の見方の中身をそのまま入れる想定）

## 本人に決めてほしいこと
1. 機体を探すのは 案A（上に検索窓）か 案B（一覧の1枚）か
2. カードの並び順と、はじめに出すカード（今は10枚全部）
3. 広がる動きの速さ（0.46秒）でよいか、動きを減らす設定の人には動きなしでよいか
4. 頭の空港のピルを押したときのシート（H5）：ピン止めの空港を先頭に、近くの空港を次に
