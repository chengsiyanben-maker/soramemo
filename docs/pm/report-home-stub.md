# 報告：空港にいるときのホームの半券（checkin/home-stub・11/26）

PM の指示（11/26 13時45分）の ② です。手本は design/home-airport の案B（B1・B1b・B2・B3）。checkin/tabs-b（PR #271）の上に作ったので、#271 が先に入る前提です。

## 作ったもの
- 判定範囲の中にいるとき、ホームの黒いカードの下に横長の半券を出す。左の丸いつまみ（→）を右へ引くと印。字は「右へ引いて印をもらう／半券を切るとチェックイン」
- 黒いカードの上の行は「いま空港にいます」（ターミナルが分かるときは「いま第1ターミナルにいます」、飛行場などは「いま滑空場にいます」）。コードのパタパタの右に名前と「○回目の訪問・前回 ○月○日」。はじめての所は緑の札「はじめての空港」
  - 訪問の回数は、その空港で印を押した日の数（日本時間）。今日はじめて来たなら「今日を入れた回数」、今日もう押したなら今日を入れた回数のまま
- 引いている間は、つまみだけが指に合わせて右へ動き、字は薄くなる（半券ごと傾けない）。切れる所までの距離は今までの縦の半券と同じ（つまみの位置から画面の右端までの半分。28〜56px）
- 押すだけでも印にできる道は残した：半券を押すと「印をもらいますか」の画面→「はい」で印。キーボードの Enter でも押せる（読み上げ・片手のため）
- 動きを減らす設定では、つまみも半券も動かさない。切れる所まで引くと字が「離すとチェックイン」に変わり、離すと印。切れたあとの飛ぶ動きもなし
- 印を押してから30分（同じ場所で押せない間）は、半券の代わりに「✓ 本日チェックイン済み 14:13」の行（role=status）。30分たつと自動で半券に戻る。電波がなく端末に保存しただけの印は「チェックインを保存しました／電波が戻ったら送ります」（済みと言い切らない）。デモは時刻を進めて押すので済みの行は出さない
- 「ほか○つ ›」（近くの一覧）は、空港にいるときはシートを引き上げた位置だけに出す（最初の位置で半券の高さを増やさないため。地図の高さ 450px と今日の数字の帯が見える決まりを守る）
- 電波がないとき：半券の色を落とし、下の字を「電波が戻ったら、あとで送ります」に（上の「電波がありません」のカードは今のまま）
- 判定範囲の外・ログインの前・一時停止・位置がまだ分からないときは、今までの縦の半券のまま（ふだんの画面 N1〜N5 は今回の範囲の外）
- 変えた関数（src/index.html）：homeState（最後に bpRow を呼ぶ）・半券を引く操作の即時関数（set・reset・pointermove の幅・tear の動き）。足した関数：bpRow・bpVisits・bpDay・bpMD・bpHM、online／offline の受け手。HTML：#checkin の中に .kn と .rt、#bpass の中に #bpDone。CSS：#v-home .bpass[data-lay="row"] のかたまり

## 本人（PM）に決めてほしいこと
1. 済みの行の字は画面案どおり「本日チェックイン済み」にした。ただし決まりは「同じ場所は30分あけば押せる」なので、30分後に半券が戻る。「本日」を外して「チェックイン済み」にするか
2. 訪問の回数は「印を押した日の数」で数えた（同じ日に2回押しても1回）。印の数で数えるなら直す
3. 上の3つ（判定範囲のピル・羽田のいま・今日の便を記録）を、次にいまの空港の仕事と一緒に作るか
4. 空港にいるときの「ほか○つ ›」を引き上げた位置だけにした。最初の位置にも要るなら、ピン止めの札と同じ行に小さく置く案を考える
