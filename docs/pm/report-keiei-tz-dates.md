# 報告：経営の画面のテスト t99・t105 が落ちていた件（11/6 経営ゲーム担当）

## 原因
- テストを動かす環境の時間帯が UTC だと落ち、日本時間だと通っていた。コードの不具合で、テストの問題ではない
- 日本時間の日付（例 2026-09-11）を「日本時間の0時」として読み、それを端末の時間帯で月・日に戻していたため、日本より西の時間帯の端末では1日前に出ていた
  - 台風の計画欠航のカード：9月11日が「9月10日」と出る
  - 発着枠の「来月の申し込み（〇月〇日まで）」：10月31日が「10月30日まで」と出る
- 海外にいる利用者や、端末の時間帯を変えている人には、実際に間違った日付が出ていた

## 作ったもの（ブランチ keiei/fix-t99-t105、下書きのプルリクエスト）
- src/index.html：上の2か所を、日付の文字をそのまま読む／UTC で月末を計算する書き方に直した（経営のコードだけ）
- web/index.html・web/sw.js：build で作り直した（main のままビルドすると差分が出ないことを確かめてから）
- tests/e2e/t117.py：日本・UTC・ロサンゼルス・キリティマティの4つの時間帯で、台風の日付と「3月の申し込み（2月28日まで）」を確かめる

## 確かめた結果
- t99・t105・t117 は UTC・ロサンゼルス・日本時間のどれでも通る。直す前のコードでは t117 が4項目落ちる
- 全体：87件中79件が通過。落ちた8件（t17 t19 t31 t47 t48 t57 t61 t62）は経営と関係なく、main のままでも落ちるか、何度か流すと通ったり落ちたりする（t48 は pdf417gen がない、t57・t61 は main でも落ちる、t17・t62 などは不安定）

## 本人に決めてほしいこと
- なし（不具合の修正だけ）。反映してよければ「反映して」と言ってください

## ほかの担当への依頼
- チェックイン担当（空港のページ）：src/index.html の空港の定時の表示（`md = t => new Date(t + "T00:00:00+09:00")`）と `artLabel` も同じ書き方で、日本より西の時間帯では1日ずれる。同じ直し方を勧める
- 改善担当かチェックイン担当：t48 は pdf417gen がない環境で落ちる。t62・t17 は流すたびに結果が変わる
