# 報告：小さな動き13個をアプリに入れる（checkin/micro）

PM の指示 11/25 17時25分（本人 OK「全部」）。見本はブランチ design/micro の docs/design/micro/（index.html・s1〜s5）。

## 作ったもの
src/index.html の style の最後に「小さな動き」の CSS、script の最後に「小さな動き」の JS をまとめた。長さは 0.12〜0.4 秒、曲がり方は行き過ぎないもの（cubic-bezier(.2,.8,.2,1)）。

| 番号 | 動き | 入れた所 |
|---|---|---|
| 01 | 押すと 0.97 倍（0.12 秒） | ボタン・カード全部（scale を使い、transform を使う部品とぶつけない）。半券・タブ帯・スイッチ・並べ替えのつまみ・3D・地図は除く |
| 02 | タブの点がすべる（0.25 秒） | 下のタブ帯。点は1つにして、押したタブの下へ動く。はじめと画面の幅が変わったときは動かさず置く。今の点（::before）は隠す |
| 03 | つまみ（0.25 秒・押している間は少し伸びる） | ON／OFF のスイッチ（.losw）すべて |
| 04 | ピンが刺さる（0.4 秒・付けるときだけ） | ピン止めした直後、その空港のピンの印（近くの空港・空港のページ・運用の1行） |
| 05 | 下から出る札（2 秒） | say() と運用の uiSay で「できた」（最初の文が「〜ました」）だけを札に。エラー・「…」の途中の知らせは今までどおり字。字は読み上げ用に残す（見た目だけ隠す）。シートが開いていればシートの中に出す。ピン止めの帯も下から出す |
| 06 | 骨組み（0.3 秒より早ければ出さない・光 1.4 秒） | 運用の「今日の遅れ・欠航」の読み込み中 |
| 07 | 数字の繰り上がり＋「＋1」 | ホームの今日の数字（今日の印・空港・フライト）。印が増えたときだけ（はじめの表示・見本の入れ直し・絞り込みでは動かさない） |
| 09 | 並べ替えで持ち上がる | ホーム・運用などの並べ替え（roBind）とタブを選ぶシート。持った行は 1.02 倍・深い影、ほかの行はすっと場所をあける。離すと「並びを保存しました」の札 |
| 10 | コピーが ✓（1.5 秒で戻る） | 部品（mxCopyHTML）を作り、フライトの「この便の記録」の登録記号に付けた。写せないときは字を出す |
| 11 | 鈴が揺れる（ON のときだけ） | 部品（mxBell）。ピン止めの「通知を許可する」で鈴が揺れる。撮る人用の知らせの鈴（.spbell）は撮る人用の持ち場なので依頼にした |
| 12 | 「もう一度」の矢印が1回まわる | 運用の「読み込めませんでした・もう一度」。押すとその場で「読み込んでいます…」に |
| 13 | シートが上がる（0.3 秒・行き過ぎない） | 下から出るシート（psheet・spsheet）と後ろの幕。ホームのシートは 0.3 秒に |

- 08（修行の道のりの帯）は修行担当が PR #224（shugyo-micro-bar）で作り済み。こちらでは触っていない。#224 と src/index.html は別の所なので、あとから入る方で web/ を作り直す
- 振動と音は入れていない。印のハンコ・半券・運用の広がり・パタパタは変えていない
- 動きを減らす設定：ここで足した動きはすべて止まる（状態は変わる）。タブ帯の色と絵の動きも止めた。骨組みは光らない灰色

変えた関数：say・uiSay・render（今日の数字の所）・pinAdd・showFacts・opsFailHTML・roBind・タブを選ぶシートの並べ替え（≡ を持って動かす所）・「もう一度」の押したときの処理・遅れのページの読み込み中（opsLate の中身を作る所）・ピン止めの「通知を許可する」の処理
足した関数：mxRM・mxDone・mxToast・mxDot・mxPinGo・mxSkel・mxNums・mxFlip・mxCopyHTML・mxBell・mxRetrySvg・mxSpin・mxRetryBox

## 本人に決めてほしいこと
1. 札にする「できた」の決め方：最初の文が「〜ました」のときだけにした（チェックインした・記録を消した・書き出した など）。ほかにも札にしたい知らせがあれば
2. コピーの部品は、今は「この便の記録」の登録記号だけ。空港のページの特別塗装機の一覧など、ほかにも付けるか（付ける所の画面案はデザイン担当）
3. ホームの札は半券のカードの下の端に少しかかる（2秒で消える）。もっと上に出すか
