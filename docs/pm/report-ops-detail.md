## なぜ今これを作ったか
本人の決定（11/6）で、作る順は「ホーム → 運用 → マイページ」になった。ホームはチェックイン担当が作り中（PR #16）なので、次に作る運用を、改善案 v4（03-ops-v4・03b-ops-wind-v4）の続きとして、作る人が迷う状態まで細かくした。暗い表示は1月の公開のあとと決まったので、明るい表示だけ。

## 作ったもの（5画面）
1. 01-ops-mode-sheet：推定のピルを押したあと。向きを選ぶシート（今の本番の「ほかの向き」と同じ6つ。右は着陸の滑走路）。選んだ向きはこの画面だけで使い、記録には残さない
2. 02-ops-spot-sheet：見に行く場所を押したあと。航空図風の小さい地図（場所・自分・着陸の線だけ）、数字3つ（ここから・着陸機の線まで・開いている時間）、「閉じる」「地図アプリで道順」
3. 03-ops-error：読み込めないとき。v4 の「読み込み中」の札と同じ場所で「読み込めなかった」＋「もう一度読み込む」。大きいカードは時間帯からの推定のまま
4. 04-ops-closed：運用時間の外（伊丹 22:41）。大きいカードは「運用時間外」と次に開く時刻 7:00。推定のピルと「推定です」は出さない。見に行く場所は残し、おすすめは付けない
5. 05-ops-few：見に行く場所をまだ調べていない空港（岡山）。今の本番で見に行く場所があるのは14空港だけで、ほかはこの形。理由1行＋「空の道すじを見る」

測った値（5画面・幅390）：13px 未満の字は単位の12pxだけ・44px 未満の押せる所 0・横のはみ出し 0・タブ帯と重なる中身 0

## 迷った点
- 01：自分で向きを選んだとき、ホームの地図やおすすめにまで効かせるか。今回は運用の画面の中だけにした（予想を実績と分ける決まりに近いほうへ）
- 02：「地図アプリで道順」は端末の地図アプリを開くだけ。そらメモの中に道順は作らない。展望デッキの開いている時間（6:30〜22:00）は見本の値で、本番の値はチェックイン担当が持っている時間を使う
- 04：運用時間外の空港で定時率のカードを出すか。今日の分は確定しているので出した
- 05：滑走路が1本の空港は「北風運用」のような名前がないので、大見出しを風の向き（「西寄りの風」）にした。運用時間がまだない空港はそのカードを出さない
- 却下済み（運用を集める印・天気の実績・機体と運航の実績）に当たるものは入れていない

## 本人に決めてほしいこと
1. 自分で選んだ向きは、運用の画面の中だけで使う（ホームや記録には効かせない）でよいか
2. 見に行く場所のシートに「地図アプリで道順」を置いてよいか
3. 運用時間外は滑走路の数字を出さず、次に開く時刻を大きく出す形でよいか
4. 見に行く場所がまだない空港は、空の状態のまま公開してよいか（1月までに足す空港があれば教えてほしい）
5. 作るのはチェックイン担当（ホームの次）でよいか
