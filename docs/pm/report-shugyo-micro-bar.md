# 修行の道のりの帯の小さな動き（11/25・修行担当）

ブランチ shugyo-micro-bar（古い `shugyo` ブランチと ref がぶつかるので `shugyo/micro-bar` ではなくこの名前）。画面案は design/micro の 08。

## 作ったもの
- 修行タブの道のりの1枚で、その日（日本時間）はじめて道のりを見たときだけ、太い帯（ポイント）が 0 から今の所まで 0.4 秒で伸び、大きな数字が 0 から数え上がる（曲がり方は画面案と同じ cubic-bezier(.2,.8,.2,1)・数字は 3 乗のゆるめ）
- 2回目からは動かさない。日付をこの端末に覚える（`soramemo.sgbar`）。覚えられない端末でも、開いている間は1回だけ
- 動きを減らす設定の人は動きなし（数字と帯は最初から今の所）
- 1年の細い帯と JGC の帯は動かさない（画面案の 08 は帯1本のため）。記録0の形・1便ごと・月ごとには帯がないので何もしない（その日まだ道のりを見ていなければ、道のりに切り替えたときに1回）
- 窓（dShugyo）で開いたときも、見えてから動かす（描いたあとに開くため、次の描画で見えているかを確かめる）
- 読み上げは数え上げの途中の数字ではなく今の数字（aria-label）
- 確定した修行の形（11/12）は変えていない。見た目（CSS）も変えていない

src/index.html で変えた関数：renderShugyo（道のりのときに sgMicroBar を呼ぶ1行）。足した関数：sgMicroBar・変数 SG_BAR_DAY。web/ は組み立て直し。

## 確かめた結果
- 新しいテスト t198：1回目は帯（太い1本だけ）と数字が動く・終わると今の数字・今日を覚える／同じ日は開き直し・見方の切り替え・覚える所が消えても動かない／日本時間の翌日（世界時ではまだ同じ日）にまた1回／動きを減らす設定では動かない／1便ごとでは覚えず、道のりへ戻ったときに1回／記録0の形では何もしない。すべて成功
- 修行まわりのテスト（t64・t73・t75・t76・t77・t78・t80・t125・t153・t188・t189）：すべて成功。t77 は main の道のりの数字を 0.3 秒で読んでいたので、数え上げ（0.4 秒）を待つよう 0.7 秒にした（t77 で変えたのは待つ時間だけ）
- 写真（スマホ幅）：docs/pm/shugyo-micro-bar/ の 1-mid-390（動きの途中）・2-done-390（動いたあと）・3-done-667
