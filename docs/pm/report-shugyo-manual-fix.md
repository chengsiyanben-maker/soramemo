# 修行：ポイントを自分で直せる欄・確定と予約済みの見込みの2色の帯（shugyo-manual-fix）

PM の指示（11/25 23時05分・Gemini の案の10番）。ブランチは古い `shugyo` と ref がぶつかるので `shugyo-manual-fix`。

## 作ったもの
- **1便の内訳の下に「数を自分で直す」**：運賃の種類（その便の表の運賃から選ぶ）・搭乗ボーナス（運賃どおり／0／200／400、ANA の新運賃は 100 も）・確定のポイント（空けると自動で数えた数）。保存するまで修行の数には入れない。「やめる」で何も変わらない。20,000 を超える数は保存しない
- 直した便には「自分で直した」の札（内訳の見出し・式の答え・1便ごとの行）。内訳の下に「直した数」と「自動で数えた数」を並べ、「元に戻す」で直しを消す
- 運賃を選んだ便・数を直した便は「運賃を推定した便」に数えない（ボーナスだけ直した便は推定のまま）
- 直しは修行の保存（shugyo_prefs の data.fix、キーは便の番号）に入れる。**表は変えていない。便の記録（flights・manual_flights）は書き換えない**
- **道のりの太い帯を2色に**：確定（実績・濃い色）と予約済みの見込み（これから乗る予定の便・うすい金色、夜はうすい緑）。帯の下に「確定 ○」「予約済みの見込み（予定）＋○」の札。足した数は出さない。計画は入れない（実績・予定・計画は分けるまま）。予定がない・届いているときは1色のまま
- 前からある「運賃を選び直す」（便の記録の編集を開く）は「便の記録を開く」に字だけ変えた（運賃の直しと2か所になって紛らわしいため）
- 計算のルール（2026年10月）と確定した修行の形（11/12）は変えていない
