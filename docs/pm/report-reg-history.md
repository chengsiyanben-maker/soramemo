## 作ったもの（docs/design/reg-history/）
- index.html：一覧と案A／案B の比べ表。png は 390×844（2倍）・-667（375×667）・夜 -n・全体 -full
- w1-week 案A 日ごとの一覧（おすすめ）：今の「機体の1日」の上に「今日｜1週間」。7日のまとめ（便の数・飛んだ時間・15分以上の遅れ・推定の便）→ 紺の地図の小窓 → 日ごとのカード。今日と前の2日は開き、ほかは「羽田→福岡→羽田…」の1行にたたむ。行は 定刻（下に実際）・便名・区間（着の時刻）・遅れのピル
- w2-band 案B 1週間の帯：7日を 6〜24時の帯に。押した日の便が下に出る
- m1-map 地図：紺の地（#0E1E36、夜 #0B1626。いまの空港の時刻表の案A と同じ紺）。同じ区間はずらして重ねて「航路の跡」に。今日は黄（夜は緑）、前の日ほど薄く、推定は点線。日のピルでその日だけ明るく。空港ごとの回数
- w3-est 推定だけの機体（ODPT にない会社）：すべて推定。定刻と遅れは出さず「いつもより ○分」（11/16 の決定の形）
- s1-est「推定」とはのシート
- 入口：e1-now いまの空港の「機体」（1週間の小さな帯つきの札）／e2-spot 撮る人の機体のくわしく に「この機体の1週間」／e3-zukan 特別塗装機の図鑑のシートに「この機体の1週間」（図鑑は特別塗装機だけのまま）
- 作り方：make/build.py → make/shoot.py → make/index.py。日本の輪郭は src/index.html の JP_OUTLINE をそのまま使った
- 測った値（390／375・夜）：12px 未満 0・44 未満のボタン 0・はみ出し 0・字の切れ 0・エラー 0・動きを減らす設定で動くもの 0

## 迷った点
- 今の記録 reg_history は p_days が最大30日まで取れるので、表を変えずに出せそう。ただし定刻・実際の時刻は ODPT の便と突き合わせる処理が要る（データ担当）
- 「推定」を2つに分けた：ODPT の会社で時刻表の便に結びつかなかった便（時刻は「ごろ」）と、ODPT にない会社の機体（全部が推定・「いつもより」）
- 案B は短い便（2時間弱より短い）だと空港コードが箱に入らず、字なしの箱になる
- 何も飛ばなかった日は「飛んだ記録なし」とだけ書き、整備などとは推しはからない
- 地図の線は空港と空港を結んだ線（実際の経路ではない）と書いた。実際の航跡で描くかは本人に聞きたい
