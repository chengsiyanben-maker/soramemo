## 2. 迷った点
- 今の乗る便のカード（renderRideIntl）は、時刻表にない便でも ODPT の出典を出している（00b の 2）。adsb.lol の出典と断り書きに入れ替える案にした
- 案内板の欄の題：ODPT にない日本の会社も入るので「海外の航空会社」から「時刻表にない便」に変えた。今の題のまま日本の会社を足すか、欄を分けるか
- 「いつもどおり」の幅を前後14分にした（JAL・ANA の案内板が15分から「遅れ」なのに合わせた）。早いのは色をつけない
- いつもの時刻がない便は札を出さず「いつもの時刻はまだありません」の字だけ（何も出さないと JAL・ANA の定刻ごろと紛れる）
- 見本の便（BA5・BC13・BC106・QR812）と時刻は作りもの。夜の画面は描いていない（U5 に「点線の縁を琥珀」とだけ書いた）
