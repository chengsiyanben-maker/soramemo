## 2. 迷った点
- 今の乗る便のカード（renderRideIntl）は、時刻表にない便でも ODPT の出典を出している（00b の 2）。adsb.lol の出典と断り書きに入れ替える案にした
- 案内板の欄の題：ODPT にない日本の会社も入るので「海外の航空会社」から「時刻表にない便」に変えた。今の題のまま日本の会社を足すか、欄を分けるか
- 「いつもどおり」の幅を前後14分にした（JAL・ANA の案内板が15分から「遅れ」なのに合わせた）。早いのは色をつけない
- いつもの時刻がない便は札を出さず「いつもの時刻はまだありません」の字だけ（何も出さないと JAL・ANA の定刻ごろと紛れる）
- 見本の便（BA5・BC13・BC106・QR812）と時刻は作りもの。夜の画面は描いていない（U5 に「点線の縁を琥珀」とだけ書いた）

## 5. main に入ったデータの形との照らし合わせ（11/16 2回目の回・#109 で main に入った移行171・182）
| 画面の中身 | データ | 合うか |
|---|---|---|
| いつもは 19:35 ごろ（U1・U3・U4） | foreign_late の legs[].usual（"HH:MM"）／foreign_watch.usual_arr | 合う |
| 7回から（U1・U4 の数えた回数） | legs[].usual_n／foreign_watch.usual_n | 合う |
| 「月曜日」（曜日ごとか曜日を問わないか） | foreign_usual.dow はあるが foreign_late は返さない | **足りない**（返さないなら「前の8週の7回から」とだけ書く） |
| ばらつき 19:28〜19:44（U4） | foreign_usual.spread（四分位の幅・分）はあるが返さない | **足りない**（返さないなら U4 の行ごと外す） |
| 着いたあとの「32分遅い」（U3・U4） | legs[].late_min（離陸・着陸のあとだけ。event があると出ない） | 合う |
| 飛んでいる間の「20:07 ごろ・32分遅い」（U1・U2b） | foreign_watch.eta・late | **画面から読めない**（foreign_watch_rows は service_role だけ。しかも「この便に乗る」の通知を申し込んだ便だけ） |
| 門限に近い見込み（U2b） | foreign_watch.state（見張りの関数の中身。まだつないでいない） | 形はまだ決まっていない |
| ダイバート・引き返し（U2c） | legs[].event／foreign_watch.event（'divert'・'return'） | 合う（「いつもは 羽田」は usual のある空港から） |
| 断り書き・出典 | foreign_late の note（「推定です…定刻や航空会社の発表ではありません」） | 合う（画面はこの文をそのまま使ってよい） |

- データ担当への依頼（4 を置き換える）：①乗る便のカード用に、誰でも呼べる読むだけの関数（例 foreign_watch_get(便名, 日)：usual_arr・usual_n・eta・late・event・門限に近いか だけを返す。誰が選んだかは返さない）。通知を申し込んでいない人にも出すなら、foreign_watch_sync の入口を「乗る便に選んだ便」に広げるか、ride の画面から flight-live の eta_pred と foreign_late の usual で手元で比べるかを決める ②foreign_late に dow（曜日ごとか）と spread を足す（なくても画面は字を減らして出せる）
