## 作ったもの
### ⑦ 375幅の崩れ
- 「もっと見る」が縦書き（30×110px）になっていた → 出典の横で縮まないように（73×44px の1行）
- 天気の枠の「変わりやすい」が切れていた → 「変わり／やすい」で2行に折れる。見通しは「10」を大きく、「km以上」を小さく薄く（数字は大きく、単位は小さく。「km」「m」も同じ）
- 12px より小さい字をなくした（ターミナルの「まだ」・3D の絵の「滑走路：AIP JAPAN」・「推定」の札・「○時○分 更新」・出典・天気の見出し）。空港ページの中で 12px 未満は 0
- ターミナルの絞り込み（すべて・T1〜T3）とピン止めのピル：見た目は 36px のまま、押せる所を上下 4px ずつ広げて 44px に
- 送ったあと × が中身にかぶる → 送ったときだけ × の後ろを紙の色でぼかす（上に戻ると消える）。× は今までどおりいつでも押せる
### ⑥ 外部データが止まったとき
- airport-now が読めないとき、「空港の今」を見出しごと消していた → 空港ごとに最後の答えをこの端末に残し（新しい8空港・24時間まで）、前の天気・予報・滑走路・便を出し、上に「○時○分 に読んだ情報です。いまは読み込めませんでした」「もう一度」。前の値もないときは見出しと「いまは読み込めませんでした」「もう一度」だけ
- 運用の一覧のカード（滑走路・案内板・特別塗装機・遅れ・短冊・1日の山・定時）：読めていないあいだ（電波なしで開き直したときなど）は前の数を灰色で出し、札に「約○分前」（同じ日・6時間まで）。時刻は前の答えの中から今より先のものを選ぶ（過ぎた時刻は出さない）。前の数もなければ今までどおり「—」
### ⑶ 特別塗装機の行のずれ
- 「この3時間」の行のうち、登録記号が分かる機体の行（ボタン）だけ、撮影地の一覧の CSS（.splist li button の all:unset と display:block）に負けて時刻と名前が縦に落ちていた → CSS だけで直した（ul.spin li>button）。2行とも名前の左がそろう
- 時刻の欄の「—」を「着陸まで約○分」などにする・「着陸に向かっている」に（推定）を付ける・羽田の地上の機体を上の箱に出す、は spInboundHTML（撮る人用の持ち場・PR #251 でも触っている）の文なので、こちらでは変えていない。撮る人用への依頼に書いた
