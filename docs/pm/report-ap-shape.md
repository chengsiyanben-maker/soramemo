## 2. 印のカード用の滑走路の線（data/ap_shape/runway_lines.json・約42KB）
- 194 か所（86空港＋番外編）。出どころ：AIP 13・AIP＋OurAirports 1（仙台：AIP の線は A 滑走路だけなので、12/30 を足した）・OurAirports の両端 98・OurAirports の長さと向きからの推定 16・なし 66
- **86空港はすべてに線がある**。推定は新島・神津島・静岡・粟国・調布（OurAirports に両端の座標がない。向きは長さと真方位、なければ番号×10 から西偏）
- 線がないのは番外編の 66 か所（滑空場 33・飛行場の多く・基地の一部・ヘリポート 12）。OurAirports に滑走路の行がない。要るなら overrides.json で手で足す
- 形：空港ごとに線をまとめて 0.15〜0.85 の四角に収めた `[u1,v1,u2,v2]`（北が上・v は下向き・縦横の比は実物どおり・横は緯度で縮める補正）。羽田・成田など AIP の線がある14空港はそれを優先
- AIP と OurAirports の向きの突き合わせは、仙台の本数のほかはずれなし（3°以内）
- 確かめ用のページ data/ap_shape/preview.html（昼夜の色・出どころの札・本数・四角の1辺の実際の長さ）
- 画面（design/stamp-card の 160 の箱）では `x = u×160`・`y = v×160` で描ける。画面に入れる形（画面の中に持つか、表にするか）は印のカードの画面案が決まってから

## 3. 今の判定と国土数値情報の面の比べ（くわしくは docs/pm/ap-shape-compare.md）
- 今の判定は**円**（空港の点から radius_m、または terminals の14か所から 800m）。民間空港を先に見て、外なら番外編の円
- **範囲から外れる所が2つあった**：
  - **三沢空港**：国土数値情報のターミナルビルの点が空港の点から 1,821m（半径 1,500m）
  - **岩国空港**：ターミナルビルの点が 1,779m（半径 1,500m）
  - どちらも共用空港で、空港の点が基地の側にあり、民間のターミナルが円の外。ターミナルで押すと「範囲の外」になるおそれがある（本人の実地か ap-shape-check.sql の 1 で確かめたい）
- ほかの84空港は、ターミナルビルの点が範囲の中。展望デッキ・地下駅は国土数値情報に点がないが、ターミナルビルの上か下なので外れるおそれは小さい
- 区域のうち円に入る割合がいちばん低いのは下地島 56%（滑走路が長い。ターミナルは中）
- 近い空港の重なりは3組だけ（長崎と大村航空基地・新千歳と千歳基地・新千歳と千歳空港）。どれも民間空港を先に見るので、重なる所は民間空港の印。羽田と調布・伊丹と神戸は重ならない
- 直し方の案（**案だけ。判定は変えていない**）：三沢・岩国だけ terminals に1行足す（ビルから800m が範囲に加わる。stamp_m を 1 にすればターミナルの印は出ない）。**radius_m を広げる形はすすめない**（経営の空港の大きさ airport_size・co_size にも使われていて、経営の数字が動く）。画面の TERMS（src/index.html）にも同じ行が要るので、チェックイン担当と一緒に。面での判定に変える案は、困る所が増えてから
- 気づいたこと：airports に ICAO が RJCJ の行が2つある（91 千歳空港・1001 千歳基地。どちらも86空港ではない）。重なりの表に2回出るだけで害はないが、片方は古い行かもしれない
