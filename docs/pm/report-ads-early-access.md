## アプリ側に頼みたいこと
1. **どこから来た人かを数える仕組み**：プロフィールのリンクを `https://soramemo.jp/?from=ig` にして、登録のときにその値を残す（例：`user_profiles` に列を足す。足すなら移行と RLS をセットで。チェックインの会話で）。今はインサイトの「リンクのタップ」と登録数を並べて見るしかない
2. **登録が混み合ったときの文言**：コードのメールが送れないとき「いま登録が混み合っています。1時間ほどあとで試してください」と出す（新規登録の準備のメモと同じ依頼）
3. **毎日の登録数を運営コンソールで見られるように**：今は SQL Editor で数える（`docs/marketing/metrics.md` の SQL）
4. **共有画像に「非公式アプリ」の文字を足す案**：利用者が共有した画像が告知の代わりにもなる。今の `src/index.html` を見たかぎり、共有画像には「非公式」の文字がない（画面の作りが絡むので、作る前にデザイン案を）
