PM の 11/26 3時20分（perf-ios）と 6時40分（小さな2つ）の積み。main（96a52fff）から。見た目（色・形・並び）は変えていない。

## 作ったもの
### ① iPhone の画面の高さ・セーフエリア・引っ張って更新（CSS だけ）
- まるごとの画面（spfull・修行の sgd・3D）の高さを 100vh → **100dvh**（見えている高さ）に。古い端末は 100vh のまま。Safari の下のバーが出ているとき、画面の最後がバーの裏に入っていた
- 下から出るシート（spsheet）とまるごとの画面・マイページの下に**ホームバーの分（safe-area-inset-bottom）**の余白。今までシートの中身の下の余白は 24px で、ホームバー（34px）より狭く、最後のボタンが 10px かかっていた。下のタブ帯と psheet は前から入っていた
- シートやダイアログを開いているあいだは `html` を overscroll-behavior: none、ダイアログは contain → 下に引いてもページの「引っ張って更新」が起きない（閉じると元に戻る。ホームは前から none）
- ホームの地図の右上のボタンの位置も 100dvh で計算
### ② 3D（three.js）
- 読み込み：前から「3Dを開いたときだけ」 import していた（開く前は 0 バイト・開くと約0.7MB）。変えていない
- **裏に回ったら描かない・取りに行かない**：visibilitychange で描画を止め（A3.paused）、a3Poll は裏では取りに行かない。戻るとすぐ描き直し、1回だけ新しい位置を取る
- **閉じたらメモリを返す**：closeAp3d で後処理の描き先（a3PostOff）・形・材質・絵（a3Free）を捨ててから描き手を捨てる。羽田の街で1回あたり約77個を返した。形のファイル（約0.4MB の JSON）は開き直しを速くするため残した
### ③ 定期取得（adsb.lol の機体・遅れのお知らせ）
- 運用の地図の機体（loadTraffic・30秒ごと）・3D の機体（a3Poll・20秒ごと）・遅れのお知らせの描き直し（60秒ごと）は、**見ていないあいだ（別のタブ・画面が消えた・アプリが裏）は取りに行かない**。地図の機体は戻ったら間隔を待たずに1回
- 数の違い（裏に10分置いたとき）：運用の地図の機体 20回 → 0回、3D の機体 30回 → 0回、遅れのお知らせ 10回 → 0回。乗る便（1分ごと）・管制の音声の一覧は前から見ているときだけ。経営の画面の60秒ごと（renderV3）は経営の持ち分なので触っていない
### 小さな2つ（6時40分）
- 「ホーム画面に追加」の帯（renderInstall）は、**初めて開いた瞬間には出さない**。最初の印を押したあと（showStamp）か、3回目に開いたとき（soramemo.install.opens）から。マイページの「ホーム画面に追加」の行はいつも出す
- 範囲の外で断られた保留の印の文（ckWhyText の queued・out_of_range）のあとに「**乗った便は、フライトの ＋ から記録帳に足せます。**」。送り直しの文（flushQueue）では、かっこの中でなく最後に1回だけ出す
- 30分の決まりの文（CK_TXT.already）と振動は、本人の返事待ちなので変えていない
