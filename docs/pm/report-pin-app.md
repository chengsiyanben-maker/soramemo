## iPhone で本人に確かめてほしいこと（作る前の確認の代わり・K0i の文を決めるため）
iPhone は Safari と「ホーム画面に追加したそらメモ」で保存場所が分かれると言われている。ピン止めは今この端末（localStorage）に保存するので、移るかどうかを実機で見たい。
1. iPhone の Safari で https://soramemo.jp/ を開く（このブランチが本番に出たあと。出る前は確かめられない）。ログインしないまま、ホームの黒いカードか空港のページで「ピン止め」を押す
2. Safari の共有ボタン →「ホーム画面に追加」
3. ホーム画面のそらメモを開き、ホームに「ピン止めした空港 1」のカードが出るか、マイページ →「知らせ」に同じ空港があるかを見る
4. 出なければ「移らない」。K0i の今の文（先にログイン → ホーム画面に追加。ログインしない人はホーム画面でもう一度ピン止め）のままにする。出れば K0i のログインの箱を消す
