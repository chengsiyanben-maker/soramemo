- W6 案B：札だけ。断り書きと note は案内板のいちばん下の出典の文に足す（軽いが、断り書きが遠い）
- W2 くわしく（FAA がある空港・ロサンゼルス）：大きく「地上待機中」＋「FAA の発表」の札、意味の一文、わけ（日本語＋FAA の発表の言葉）、いつから・終わる見込み（日本時間、下に現地）、発表の時刻、今日の JAL・ANA の便（便・欠航・遅れ）、断り書きと note
- W3 くわしく（FAA がない空港・仁川）：「欠航 3便」と「JAL・ANA の便から」の札、空港の発表は「ありません」と書く
- W4 乗る便のカードに1行（FAA）：「到着地ロサンゼルスで地上待機中（FAA・15時30分まで見込み）」（通知の文と同じ言い方）＋「いまの発表です。着くころには変わっていることがあります」。出典の文に FAA と断り書きを足す
- W4b 乗る便のカードに1行（便の数）：「到着地ソウル（仁川）：今日の欠航 3便（JAL・ANA）」＋「空港全体の数です。この便のことではありません」
- W5 札の一覧：3つの重さ（重い＝濃い色：閉鎖・地上待機／注意＝うすい黄：間引き・遅れ・除氷／便の数＝グレー）、言葉、出す決まり
- png/：390×844 の2倍。W1・W6・W5・00a・00b は -full、W1〜W4 は -667 も。作り方は make/make.py → make/shoot.py

決めた形：
- 札には必ずピンの印をつけ、「空港全体のようす（この便のことではありません）」の1行を案内板に添える。この便の欠航・遅れ（今の「欠航」「○分遅れ」）と取り違えないため
- FAA の札には小さく「FAA」を入れる。便の数の札は FAA の印なし・グレー
- 1つの空港に2つ以上あるときは、いちばん重いものを1つだけ札に（閉鎖 → 地上待機 → 間引き → 遅れ → 除氷 → 便の数。データの通知の順に合わせた）。ほかはくわしくに
- 札をつけるのは出る便は出発前、着く便は到着前だけ（過ぎた便にはつけない）
- 時刻は日本時間、くわしくに現地を添える。案内板風は使わない。会社の色・金は使わない

測った値：13px 未満の字 0・44px 未満の押す所 0・横のはみ出し 0（10枚）

## 2. 迷った点
- 便の数の札を便の列にもつけるか：「欠航3便」がその便の欠航に見えるおそれ。ピンの印と説明の1行で分けたが、本人が紛らわしいと思えば、便の数は「海外の空港のいま」の欄だけにする
- データの note は FAA と ODPT の両方を1文に書いているので、仁川（FAA なし）でも「出典：FAA NAS Status」が出る。W3 はそのまま出した。空港ごとに分けた文（FAA がある空港用・便の数だけの空港用）をデータ担当に頼むと読みやすい
- gdp の言葉：データでは「出発の間引き」だが、日本で見る人には「その空港に着く便を減らしている」のが分かる「到着の間引き中」にした（W5）。どちらにするか
- FAA の reason（英語）を日本語にする表が要る（例 WEATHER / LOW CEILINGS → 天候（低い雲））。W2 は日本語＋元の言葉を小さく出した
- 夜の画面はまだ main にないので描いていない（W5 に「重いは琥珀の縁、注意は琥珀の字」とだけ書いた）
