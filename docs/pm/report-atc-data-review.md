## 2. 足りているか

### 7日で消す
- **おおむね足りている。** ただし2点
  1. 掃除は1日1回なので、実際には**最長でおよそ8日**残る。プライバシーポリシーは「7日で消します」。文を「7日を過ぎたものは、その日のうちに消します」にするか、掃除を1時間ごとにする（下の案 B1）
  2. 掃除が止まっても気づく仕組みがない（pg_cron の記録は今の設定では1日で消える）。週の点検に「7日を過ぎた交信の数」を足す（下の SQL に入れた）
- Supabase の毎日のバックアップ（プランによる）と Edge Function の記録（要求の時刻・IP など。本文は書いていない）は、こちらでは消せない。ポリシーに「バックアップの中には、さらに最長◯日残ることがあります」と書くかを本人に決めてほしい（日数は今のプランの画面で確かめる）

### 同意の記録
- **ストアの前に足りない所がある。**
  1. **どの文に同意したかが残らない。** consent_at（時刻）だけで、同意の文や版がない。見直しの結果で同意の文（電波法59条の書き方など）を変えても、前の文で同意した人の合言葉はそのまま使える。PC の合言葉・スマホの端末に保存した合言葉には期限もない
  2. **やめたあと、退会したあとに同意の跡が消える。** 行ごと消すので「いつ同意し、いつやめたか」が残らない。いたずらや問い合わせがあったときに、7日のあいだの交信がだれの同意のもとで出たか分からない（いまは feeder が空になる）
  3. **やめても、送った交信が7日まで画面に出つづける。** 同意をやめた人の分を残すかは、決定事項「退会したときは本人の記録を消し、全機の航跡と機体の記録は残す」に照らすと、消すほうが筋が通る（交信は協力者が送ったもの＝本人の記録に近い）
  4. **地域の人数が1人でも出る。** atc_coverage は地域（市区町村まで）ごとの人数をだれでも見られる形で返す。「◯◯区 1人」と「いま羽田タワーを受信中 1人」を並べると、協力者の住む所と、公開された交信を結び付けやすい。59条で問われるのは「漏らす」人なので、協力者を特定しにくくしておくほうがよい
- 同意のチェックはアプリから true を送るだけで、サーバーは「同意した」という事実しか確かめられない。これは今の作りで仕方がない（ほかの同意 agree_terms も同じ）

## 3. 直す案（効き目の大きい順。どれも移行と RLS をセットで出す。チェックイン・経営には影響しない。撮る人用担当の画面に少し関わる）

- **A1 同意の版を残し、版が変わったら受け付けを止める**（ストアの前に入れたい）
  atc_feeders に consent_ver（版＝改定日 YYYY-MM-DD）を足す。同意の文の版は terms_versions に kind 'atc' として1行足す（本人の決定「terms_versions に1行足す → アプリの定数を変える」と同じ順）。atc_new_feeder に版を渡し、atc-ingest は版が古い合言葉に 403 "reconsent" を返す → 画面で同意を取り直す。今いる登録は版が空なので、入れた日から取り直しになる
- **A2 同意とやめた記録を、交信が消えるまで残す**
  行を消さずに revoked_at を付け、合言葉のハッシュは消す（合言葉は使えなくなる）。行は「やめてから8日」で毎晩の掃除が消す。退会のときは auth.users の cascade で今どおりすぐ消す（本人の記録なので残さない）
- **A3 やめた人・退会した人の交信を画面から外す**
  やめたとき・退会したときに、その人が1人だけで受けた交信（heard = 1）を消す。ほかの協力者も受けた交信（heard ≥ 2）は人数を1減らして残す（どの協力者が重なったかは今は記録がないので、送った人を feeder に1人しか持てない。厳密にするなら交信と協力者の対応表が要る → そこまでするかは本人が決める）
- **A4 地域の人数は3人以上のときだけ出す**（atc_coverage の areas に having count(*) >= 3。1〜2人の地域は「ほか」にまとめる）
- **B1 掃除を1時間ごとに**（'17 * * * *'。7日を過ぎて最長1時間。BRIN があるので軽い）。または文だけ直す
- **B2 持つものを減らす**：画面に出さなかった交信（verified = false）は1日で消す。英語の文字 text_en は、重なりの判定に使う10分を過ぎたら空にする（日本語と項目だけ残す）。読み取りの改善（atc-parse2）に英語の文字を使いたいなら、何日分を残すか本人が決める
- **C 管制だけを止めるスイッチ**：ops.flags に atc_enabled（既定 true）を足し、false なら atc-ingest は受け付けず（503）、atc_recent は空を返す。総務省や審査で指摘があったとき、アプリ全体の非常停止（emergency_stop）を使わずに管制だけ止められる。止めたときに残りの交信をすぐ消すかも決めておく

A1・A2・A3・A4・C をまとめて1本の移行（154 以降）とテスト（t94 以降）にできる。画面は「同意を取り直す」案内が1つ増えるだけ（撮る人用担当とデザイン担当）。
