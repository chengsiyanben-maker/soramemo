## 本人に決めてほしいこと
1. JGC の札は「推定」ではなく「記録分」にした（review-3 の4）。数える範囲は今のアプリと同じ「記録した JAL の便ぜんぶ（前の年も）×5」。これでよいか
2. 今の数を入れる形にした。入れた数と日は shugyo_prefs の中に持つ（表の変更なし）。これでよいか
3. 見方を選ぶは、シートではなく ✎ から開く1枚のページにした（ON／OFF の部品は修行の中だけのもの）。チェックイン担当の見方のシート（#dViews）にそろえるなら、チェックイン担当に頼む
4. 道のりから「修行の路線の運航」と「今年の記録」の入口を外した（ページは残っている。運航は次に乗る便の「この路線の今日」に、年末までの道のりは月ごとの下に入口がある）。今年の記録（ANA と JAL を並べる画面）は入口がなくなったので、消すか、月ごとに入口を足すか
5. フライトの見方「修行」と成績の「修行のまとめ」は今のまま（修行のタブに集めるかは決まっていないので触っていない）
6. 667 の高さでは、上の段が画面案より高いぶん、2つの道の箱は上の端だけ見える
7. 年の区切りを日本時間にそろえる（候補1）はまだ。1月1日の朝の便の年がずれることがある。12月の前に直すか
