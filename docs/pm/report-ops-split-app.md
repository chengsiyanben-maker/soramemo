## 作ったもの
- 上の1行（A1・A3）：空港の側は「空港｜機体」＋空港のピル＋ⓘ＋共有。機体の側は「空港｜機体」＋探す欄（登録記号・便名）＋ⓘ。機体を選んだあとは「空港｜機体」＋「‹ 戻る」＋登録記号のピル＋共有。空港のピルの「近く」の字は外した（読み上げの名前には残す）。選んだ側は紺地に白い字（ON のスイッチと同じ色の変数）
- 空港の側（案2）：見方は今の7つのまま（撮る人も空港の側）。特別塗装機のかたまりは「滑走路の下」から外し、撮る人の見方の「羽田に来る特別塗装機」はそのまま
- 機体の側：見方は「最近見た」（はじめ）と「特別塗装機」の2つ
  - 最近見た（A2・Q2）：この端末で開いた機体（8機まで・端末だけに保存。表は使わない）、撮る人への入口の1枚（押すと空港の側の「撮る人」）、いま飛んでいる特別塗装機（地上の機体・アライアンス塗装は入れない）2機と「特別塗装機をすべて見る ›」。開いた機体がない人には説明（A2e）
  - 特別塗装機：運用予想担当の specialHTML をそのまま出す（いま／この先／羽田に来る のピルはまだ。下の依頼）
  - 機体を選ぶと、シートを開かずタブの中に機体の1日（planeHTML をそのまま使い、上のカードと「今日」の行は CSS で隠して1行の見出しに。「ここから予想」と「予想です。保証しません」はタブの中だけ1行に）。選んでいる間は見方の帯の下線を外し、帯を押すとその見方に戻る
  - 探す：JA で始まる・便名の形でないものは登録記号として、便名（JL323 など）は inbound_aircraft で今の機体を調べてから開く
- 機体の側では空港の物（気象通報・案内板・機体の位置）を読まない。読むのは特別塗装機（special_now・livery_board）と、選んだ機体の reg_history・予想だけ
- 鉛筆のシート（V1・V1b・V1c）：題は「運用の見方」、中に「空港｜機体」のピル。機体の側の下に「機体の側ごと隠す ／『機体』を出す」。OFF のときはピルに「隠し中」と戻し方の一文
- 「機体」を出す OFF（V3）：上の「空港｜機体」が消え、運用は空港だけ。機体の1日は今までどおりのシートで開く。保存は表示の設定（layout.opsPlane = 0）なので、ログインしていればアカウントに残る。全部乗せに戻すと ON に戻る
- 表示の編集（V2）：「運用（空港）」と「運用（機体）」のカードに分けた。機体のカードの1行目が「『機体』を出す」（数には入れない。OFF のときは見出しに「『機体』を隠しています」、「隠しているもの」にも出る）。全部の数は 39→41（機体の見方2つ＋「機体」を足し、特別塗装機のかたまり1つを引いた）
