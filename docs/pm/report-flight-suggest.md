# 報告：乗る便の候補から1回で記録（checkin/flight-suggest）

PM の 11/25 23時05分の積み（本人が貼った Gemini の案の7番）。main（dfc945cc）から。checkin/stamp-edge には触っていない。

## 作ったもの
1. **今日の便の候補**：フライトの「＋」と、印の画面の「今日の便を記録」（便ができなかったとき）で、いまいる空港（今日チェックインした空港。なければ判定範囲の中の空港）の今日の運航情報（空港の今と同じ airport-now・ODPT）から候補を並べる
   - 「これから出る便」（欠航・出発済みを除く。6便まで）と「いま着いた便」（90分前〜10分後。4便まで）。国際線は出さない
   - 1行は航空会社の小さな札（JAL 系は薄い赤、ANA は薄い青、ほかは灰色。彩度を落とした色で、ロゴは使わない）＋大きな便の数字＋区間＋時刻（変わったら →見込み）＋機材
2. **確認の1回で記録**：押すと確認の1枚（便名・区間・時刻・日付・機材）。「記録する」1つで記録する
   - これから出る便 → 乗る便として覚える（今の「この便に乗る」と同じ。着いた空港でチェックインしてできたフライトに便名が付く）。二重に数えないため、ここでは便を作らない
   - いま着いた便で、今日のその区間のフライト（チェックインの記録）がある → そのフライトに便名を付ける（set_flight_airline）
   - いま着いた便で、フライトがなく、この空港でもうチェックインしている → 日誌（manual_flights）に今日の便として残す。まだチェックインしていなければ乗る便として覚える
3. **過去の便**：日誌の欄に「便名（数字だけでも）」を足した。日付と便名で、JAL・ANA の時刻表（plan_timetable）から区間・時刻・機材と航空会社を補う。同じ番号の便がいくつかあれば選ぶ。日付が前日より前なら「今の時刻表から。その日の時刻と違うことがあります」と書く。出発が分かったら、その日の毎日の記録（flight_facts）の実際の時刻と機体も添える
4. **電波がないとき**：候補は出さず「電波がないため、候補は出せません。下の欄に手で入れてください。」。出発に今の空港を入れておく。便名の補いも「電波がないため補えませんでした」
