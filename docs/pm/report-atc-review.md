## 2. 電波法59条の考え方（一般的な整理）
- 59条：法律に別の定めがある場合を除き、**特定の相手方に対して行われる無線通信**を傍受して、その**存在や内容を漏らし**、または**窃用**してはならない。罰則は109条（1年以下の拘禁刑または50万円以下の罰金。無線の業務に就く人はもっと重い）
- **受信すること（聞くこと）自体は違法ではない**、というのが一般的な説明。問われるのは「漏らす」と「窃用」
  - 漏らす：内容や、その通信があったことを他人に知らせること。不特定多数に見せる（ネットに出す）のは典型
  - 窃用：通信の内容を、送った人の意思に反して自分や第三者の利益のために使うこと
- 管制と航空機の交信は、特定の相手（その便・その管制）に向けた通信と見るのが一般的。ATIS（空港の情報の放送）は不特定多数に向けた放送なので、59条の対象外とする考え方が多い
- **今の文「解釈が分かれています」は、実際より弱く見える**おそれがある。「内容をネットで公開するのは59条に触れるおそれがある」という説明のほうが一般的で、日本の空港の交信を日本の事業者が文字にして公開しているサービスは、私が調べた範囲では見当たらない
- そらメモで問われそうな点
  1. **「管制の交信」の画面そのものが「漏らす」に当たるおそれ**：協力者の端末で文字にし、運営が日本語にしてだれでも見られる形で出している。音でなく文字・日本語訳でも、内容を知らせることには変わらない。「漏らした」のは協力者か運営か、両方か、という問題になり、運営（本人）が当事者になりうる
  2. **窃用**：交信を便名と合わせ、ゴーアラウンドのタグなどアプリの機能に使っている。アプリが有料機能や広告で稼ぐと「利益のために使う」に近づく（今は管制の交信は無料・広告なし）
  3. 「いま聞く周波数」（AIP に載っている周波数の案内）と、本人が自分の受信機で聞くことは、漏らす・窃用に当たらない、というのが一般的な見方
- ほかの法律：受信の協力で音を録らないこと、端末の位置を受け取らないことはできている。LiveATC の音は使わない（11/6 に問い合わせ済み、返事待ち）

## 3. 協力者の同意の取り方
- 同意は「59条に触れるおそれ」を協力者に背負わせる形になっている。協力者に同意を取っても、運営が公開する責任は消えない（同意で違法でなくなるものではない）
- 今の文の直し案（出し続ける場合）：「航空無線の交信の内容を他人に知らせることは、電波法59条で禁じられているおそれがあります。そらメモは交信を読み解いて公開します。この点を理解したうえで協力してください。」—— ただしこう書くと、出すこと自体の判断が先に要る
- 同意の版を残す・版が変わったら取り直す・やめた人の交信を外す・地域の人数を3人以上だけ出す、はデータ担当の案（下の 6）がそのまま使える

## 4. 「推定」の出し方
- 今は「AIが日本語にしたもの（推定）」「聞き間違いがあります」「航法には使えません。非公式」と出していて、決めごと（予想は予想と出し、保証しない）には合っている
- 足すなら：ゴーアラウンドのタグも「（推定）」を付ける。便名は「呼び出し符号からの推定」と1行目に出す

## 5. Apple・Google の審査で問われそうな点
- **法律に触れるおそれのある内容を扱うアプリ**として、審査の人から「日本の電波法で許されている根拠」を聞かれる可能性がある（Apple のガイドライン 5.1・5「法的な要件」、Google の「違法な行為」）。根拠を答えられないと止められやすい
- **だれでも出せる内容（利用者が作るもの）**：協力者が送る文字は利用者が作る内容に当たり、通報・ブロック・運営の削除の手段を求められる（Apple 1.2）。今は確かめた交信だけ出すが、通報の入口はない
- **マイクの使い方の説明**：スマホで協力するときマイクを使う。使う理由の文（NSMicrophoneUsageDescription）と、画面を開いている間だけ使うことの説明が要る
- **PC の受信プログラムを外の GitHub に置いている**こと：アプリの外のソフトに誘う形は問われにくいが、合言葉を見せる画面は審査の人が試せないので、審査のメモに説明が要る
