# 報告：羽田の3D を自由に動かす（画面案 1版）

担当：デザイン（design）／ブランチ design/a3-free／PM の指示 11/24 22時50分（本人「3Dモデルをもっと自由に動かせるようにしたい」→4つとも選んだ）
アプリのコード（web/・src/・supabase/）は変えていない。

## 作ったもの（docs/design/a3-free/）
- 一覧：index.html（png/index-full.png）
- 00 今（全体・管制塔・機体の3つの視点）
- 案A（おすすめ）上のピルを「自由・追う・立つ・飛ぶ」の4つにする
  - A1 自由・はじめての1回の案内（指の動き4つ：回す・寄る離れる・ずらす・傾ける）／A2 寄ったところ（右上に「全体に戻す」）
  - A3a 追う・機体を選ぶシート／A3 追う（付く位置 後ろ・横・前、指で角度と距離、× で追うのをやめる）／A3b 機体が消えた（自由に戻り、下に一言と「ほかを追う」）
  - A4 立つ・場所を選ぶ（先頭に管制塔、展望デッキ、C 滑走路の南の端。3D の地面を押した所にも立てる）／A5 立つ（目の高さ 約1.6m・向きの札・場所を変える）
  - A6 飛ぶ（左のつまみで前後左右、右で上下と向き、高さは大きな数字）／A6b 1,000m の上限
- 案B 見方は下の4つのボタン（B1 自由・B5 立つ・B6 飛ぶ）
- 今の3つの視点の行き先（両案共通）：全体→自由のはじめの位置と「全体に戻す」、管制塔→立つのおすすめの先頭（高さ 約118m のまま）、機体→追う
- 「閉じる」（左上の ×）はどの見方でもいつも押せる（11/21 の決まり）
- png は 390×844（2倍）と -667（375×667）。背景は main の web/ をデモで開き、時計を昼にずらし、カメラを置いて撮った今の3D（make/capture_bg.py・cams.json）。作り方：make/capture_bg.py → make/build.py → make/shoot.py → make/make_pages.py
- 測った値：どの画面も 390／375 で 12px 未満の字 0・44px 未満の押す所 0・横のはみ出し 0・字の切れ 0

## 迷った点
- 案B は親指が届くが、飛ぶのつまみと4つのボタンが下で重なって混む（B6）。上のピルは今の形とそろうので、案A をおすすめにした
- 立つの「展望デッキ・滑走路の端」の場所の座標は作るときに決める（画面案の札の位置は目安。管制塔だけ今の座標で置いた）
- 立つで2本指は「ズーム（目の位置は動かない）」にした。歩いて動くのは「飛ぶ」か「場所を変える」
- 追うで機体の位置が届かなくなったとき（駐機場に入った・範囲の外へ出た）は自由に戻す。その時の見え方は、今の位置のまま自由にする（全体へ飛ばない）
- 夜の画面の版はまだ作っていない（形が決まったら足す）
