# 報告：新しいホーム（改善案の3版目）（チェックイン担当・11/6）

PM の指示（ホーム → 運用 → マイページの順のうちホームだけ）の仕事です。ブランチは `feat/home-v3` で、下書きのプルリクエストにしました。main と本番には入れていません。経営のコードと表は触っていません。

## 作ったもの
- **上の段を1段に**：「スタンプラリー／エアライン経営」の切り替えと「マイページ」（人の図つき）を1段に並べ、その下に図だけのロゴ（36px）を置いた。デモのときはロゴの右に「デモ中」のピルだけを出す。デモを終えるのはマイページから。経営が使えないときは、ロゴとマイページの1段だけになる
- **地図を航空図風に**：国土地理院の地図はそのまま使い、上から色を重ねた（色を落として生成りに寄せ、48pxの薄い方眼を足す）。空港・滑走路（運用の表にある15空港）・判定範囲は赤紫、いまいる所は青
- **地図の縮尺は本物の値で決める**：自分と空港が両方入る縮尺にする。80kmより遠いときは空港を中心にして、地図の端に「→ いまここ ○km」を置く。範囲の外のときは、自分と空港を点線でつなぐ。空港の名前は、地図の空いている側に置く（右の＋−と重ならない）
- **状態の出し分け**（ログインしていない ＞ 判定範囲の外 ＞ 範囲の中）
  - 範囲の中：琥珀の半券に「→ 右へ引いて印をもらう」。状態の行は「第1ターミナル ・ ● 判定範囲の中」
  - 範囲の外：灰色の半券に「範囲に入ると切れる」。状態の行は「● 判定範囲の外 ・ ここから 10.4km」。押すと位置を調べ直し、範囲に入っていれば琥珀の半券に変わる
  - ログインしていない：灰色の半券に「ログインすると使える」。数字の帯の代わりに「ログイン・登録／デモで試す」の案内を出す
- **ログインしていないときの行き先**（review-3 の指摘4）：右上は「ログイン」と出し、押すとログインの画面を開く。「エアライン経営」を押したときもログインの画面を開き、経営の画面には移らない
- **引く動きを分ける**（申し送り1）
  - シートが動くのは、つまみのところと搭乗券の外だけ
  - 半券は右へ引いたときだけ切れる。下へ引いても切れない
  - 押すだけのときは「印をもらいますか」を1回確かめてから切る
  - キーボードの Enter は、今までどおりそのままチェックインする
- **シートの止まり位置は2段**
  - 最初の位置：搭乗券と「今日の印・空港 /86・フライト」の帯がタブ帯の上に収まる。844pxの高さの画面で、地図は約495px見える
  - 引き上げた位置：数字が3枚のカードに変わり、最近の印が横に並ぶ（見出しの右に「図鑑 ›」のピル）
  - 最初の位置では、シートの中身をタブ帯の上で切るので、何もタブ帯の下にもぐらない
- **位置の見張り**：位置の許可がもうある人だけ、ホームを開いているあいだ現在地を静かに見張り、範囲の中・外をすぐに出す。許可を聞くのは、今までどおり半券を切ったときだけ。ほかの画面に移ったときと、アプリを裏に回したときは見張りを止める
- 構成（気軽に・撮る・修行）ごとにホームに出す部品は、今のまま

変えたファイル
- `src/index.html`：ホームの HTML・CSS・処理。CSS はホームの画面だけに当てた

## 見本と違うところ
- 見本の「→」は縦書きの「チェックイン」の横にあったが、review-3 の指摘5に合わせて「→ 右へ引いて印をもらう」の行の頭に置いた
- 引き上げた位置では、3枚の数字と最近の印のあいだに、今までどおりの部品（チェックインの説明・いまいる空港・3つの数字（空港・路線・飛行距離）など）が残る。構成ごとの部品を変えない決まりを守ったため
- 小さい画面（375×667）では、帯がタブ帯にもぐらないことを先にしたので、最初の位置の地図は約320pxになる（450pxは844pxの高さの画面で満たす）
- 航空図風の色は、地図の上から色を重ねたもの。見本ほど陸と海の色の差ははっきりしない

## 本人に決めてほしいこと
1. ログインしていないとき、右上の「ログイン」を押すと、マイページではなくログインの画面を開く形でよいか。ログインの画面からは「あとで」「デモで試す」も選べる
2. 引き上げた位置で、前からある「空港・路線・飛行距離」の数字のカードが、新しい3枚（今日の印・空港・フライト）の下にも残る。空港の数が2か所に出るが、このままでよいか（消すなら、構成ごとの部品の決まりを変えることになる）
3. ログインしていない人のホームの下のほうに、前からあるメールでのログイン欄が残っている（最初の位置では見えない）。消してよいか。消すときは、それを使っているテスト（t7・t43・t44・t114）も直す
