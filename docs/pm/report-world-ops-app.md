## 1. 作ったもの
- 案内板（運用タブ・案内板の見方）：国際線の便の列に、ピンの札を1つだけ（FAA の発表のうちいちばん重いもの：閉鎖 → 地上待機 → 到着の間引き → 到着の遅れ → 出発の遅れ → 除氷）。出る便は出発前、着く便は到着前だけ（実際の時刻が出た便・欠航・過ぎた便には付けない）。便の数の札は便の列に付けない。札があるときは「ピンの札は、行き先の空港全体のようすです（この便のことではありません）。押すとくわしく出ます。」の1行
- 「行き先の海外の空港のいま」の欄（海外の航空会社の上）：案内板の到着・出発の便の行き先・出発地のうち、FAA の発表があるか欠航・30分以上の遅れが1便以上の空港だけ。重いものが先。行に札（FAA の札＋便の数の札）と「○時○分まで見込み」。欄の中に太字で「運航の判断には使えません。」と、データの note。国内線のときは出さない
- くわしく（シート #dWorldAp・spsheet の形）：FAA がある空港は大きく「地上待機中」＋「FAA の発表」、わけ・いつから・終わる見込み（日本時間と現地）・遅れ・遅れの向き・発表の時刻・ほかの発表。FAA がない空港は「欠航 3便」＋「JAL・ANA の便から」と「空港の発表 ありません」。どちらも今日の JAL・ANA の便（便・欠航・遅れ）と断り書き
- 乗る便のカード（国際線）：状態の1行の下に1行。FAA は「到着地ロサンゼルスで地上待機中（FAA・15時30分まで見込み）」＋「いまの発表です。着くころには変わっていることがあります」、便の数は「到着地ソウル（仁川）：今日の欠航 3便（JAL・ANA）」＋「空港全体の数です。この便のことではありません」。到着地は着く前、出発地は出る前だけ。下の出典の文に FAA・便の数の断りを足した。押すとくわしく
- 読み込み：rpc('world_airport_ops', { p_iata:null }) を1回で全部の空港。案内板の見方で国内線以外のときと、乗る便が国際線のときだけ。2分（見方を変えたときは3分）は読み直さない（取れなかったときも）。取れない・空のときは何も出さない
- 夜（data-night="on"）と案内板の色では、重いは琥珀の縁、注意は琥珀の字（金と会社の色は使わない）
- データ担当がこれから足すもの（feed_at・note の分け方・reason の日本語）は、届けばそのまま使う形にした：feed_at（各発表か空港か全体）→「○時○分 更新」と発表の時刻、note_faa／note_counts（または空港ごとの note）→ 欄とくわしくの出典、reason_ja → わけ（下に原文）。届くまでは note は1つの文、わけは原文のまま、更新の時刻は出ない

src/index.html で足した関数：loadWorldOps・woAp・woFaa・woShow・woHM・woLocal・woFeedAt・woNote・woTag・woCountTag・woSub・woRowTag・worldOpsHTML・worldApSheet・worldRideHTML（定数 WO_KIND・WO_ORDER・WO_TREND、変数 WOPS）
変えた関数：boardHTML（札・ピンの説明・欄）・renderBoard（読み込み）・renderRideIntl（1行と出典）。足した部品：dialog#dWorldAp、CSS .wotag・.wopin・#v-ops .wobtn／.wokey／.wobox／.worow／.wonote・.ridecard .woline・dialog.wodlg
