# t180 が main でも落ちる件の直し（撮る人用担当・11/24）

## 原因（テストの作りの問題。アプリの不具合ではない）
- t180 は最後に「開き直しても遅れのまま」を確かめるため、ページを読み込み直す（reload）。
- t180 は file:// で開いていた。file:// で読み込み直すと、Chromium が直前に書いた localStorage を落とす（keepls.py に書いてある既知の問題。t165 でも「毎回落ちた」）。
- 調べると、開き直したあとは localStorage が空（soramemo.home.spTab なし・ログインなし・構成は casual）で、ホームの撮影カードそのものが隠れていた。そのため `[data-pctab="late"]` が出なかった。手元では2回とも同じ所で落ちた。
- #199 の運用の直し（遅れの bad・地図「空 ○機」・並べ替え）とはぶつかっていない。開き直す前の28項目はすべて通っていた。#199 の反映のときに通ったのは、落ちるのが確率まかせだったためと見ている。

## 作ったもの
- tests/e2e/t180.py だけを変えた：開くのを keepls.py の goto_http（手元の http の窓口 127.0.0.1）にした（ほかの読み込み直すテストと同じ形）。
- 時刻はもともと固定している（pg.clock.set_fixed_time で、その日の日本時間12時。作り物の時刻表 HRS もそれに合わせた形）。開き直したあとも固定は効いていた。
- src/index.html は変えていない（変えた関数なし）。web/ の組み立て直しもなし。
