# 報告：図鑑の飛行場・滑空場の入口（デザイン担当）

ブランチ design/zukan-airfields・画面案だけ（アプリのコードは変えていない）。11/11 18時15分の PM の指示（本人「今のまま別の図鑑で目立たせる」）。

## 作ったもの
docs/design/zukan-airfields/ に7枚（HTML・PNG は 844 と 667）と一覧 index.html。
- 01 今：main の図鑑の最初の画面・ほかの図鑑・実績・今の別冊（畳んだ行が2つだけ）
- 02 図鑑の最初の画面に入口：黒いカード（集めた空港 16／86）のすぐ下に白いカード「もう1つの図鑑　飛行場・滑空場」。大きな数 3／63、飛行場 2／30・滑空場 1／33、小さな地図（飛行場は緑・滑空場は空色の点、行った所は塗り）、「上の『集めた空港』とは別に数えます」。右上に「開く ›」
- 02b まだ1つもないとき（0／63 でも同じ大きさで出す）
- 03 飛行場・滑空場の図鑑：86空港の図鑑と同じ「ツメ＋地方の扉＋そろえた枠」。上の黒いカードに地方ごとの数と、飛行場・滑空場の数。枠は短い名前（「滑空場」「飛行場」「空港」を外す）と種類の札
- 03b 関東の扉まで送ったところ（行った枠は白、まだは薄い）
- 04・04b 夜：種類の色をやめ、点と札は灰の濃淡だけ。ツメは色なし（今の夜の図鑑と同じ）

測った値（自分が足した所）：13px 未満の字 0（単位を除く）・44px 未満の押す所 0・横のはみ出し 0・名前の切れ 0。
今のアプリのままの所（下のタブの字 10.5px、マイページ 12.5px、86空港の枠のコードの測り方）は数に入れていない。

## 迷った点
- 入口の場所：黒いカードの下（今回）か、地方の扉の最後（沖縄の下）か。目立たせる指示なので上にした。代わりに北海道の扉が約 260px 下がる
- 入口の地図：灰の小さな点で86空港の形を見せ、その上に飛行場・滑空場の点。日本の輪郭は描いていない（今の図鑑の地図の見方と同じ描き方）
- 四国には飛行場・滑空場がない：ツメは薄くして押せない、上のカードは「なし」にした
- 名前が長い（大樹町多目的航空公園・アップルポート余市・別海フライトパーク など）：8字以上は字を 14px にして3行まで
- 夜：今のアプリにはまだ夜の画面がないので、暗い配色に夜の決まり（琥珀は使わず白い字、会社の色なし）を足して近づけた。夜は飛行場と滑空場の点の色が同じになる（札の字で見分ける）

## 本人に決めてほしいこと
1. 入口の場所：黒いカードのすぐ下（おすすめ）／地方の扉の最後
2. ヘリポートの札：今の番外編のデータにヘリポートが1つもない（飛行場 30・滑空場 33）。札だけ用意しておくか、データが入るまで出さないか（近くの空港の3版の質問と同じ）
3. 「ほかの図鑑・実績」の中の飛行場・滑空場の行を残すか（今回は残す形）
4. 夜の地図で、飛行場と滑空場を形で分けるか（例：滑空場は四角）。今は同じ灰の丸

## review-1 への対応
| 指摘 | 直したこと |
|---|---|
| 1 「番外編」の言葉（大） | この画面案では「番外編」の語を使わない。説明は「自衛隊の飛行場（基地）は、今までどおり『ほかの図鑑・実績』の中にあります」。近くの空港の4版も「番外編」の語を使わない（03 は「飛行場の図鑑の印（16/86 とは別）」） |
| 2 送るとどちらの図鑑か分からない（中〜大） | 上に止まる地方の扉の右に「飛行場・滑空場」の札（緑の地）。扉の進み具合の棒はこの図鑑だけ外し（上の黒いカードにある）、地方名・数・札・∧ が1行に入るようにした（03b） |
| 3 「別に数えます」の位置と数字の大きさ（中） | 一文を大きな数字のすぐ右へ（「集めた空港とは／別に数えます」緑の字）。数字は 40px→28px（「16」より一段小さい） |
| 4 長いカタカナが語の途中で折れる（中） | カタカナを含む名前は、漢字とカタカナの境目と「エアポート・エアパーク・スカイポート」などの前でだけ折る（ホンダ／エアポート、美幌／エアパーク）。字は 14px、8字以上は 13px |
| 5 667 で入口が画面をふさぐ（小〜中） | 高さ700未満は1行の形（札・題・3／63・一文、地図と内訳は外す）。667 で北海道の扉が見える |
| 6 小さな地図の点（小） | 行った所の点を 10→12px。凡例も地図も丸 |
| 7 左の緑の帯（小） | 帯をやめ、「もう1つの図鑑」を緑の地のピルにした |

測った値（足した所）：13px 未満 0（単位を除く）・44px 未満 0・はみ出し 0・名前の切れ 0（1版で切れていた美幌エアパーク・飛騨エアパークも直った）。今のアプリのままの所（下のタブ 10.5px・マイページ 12.5px・86空港の枠のコードの測り方）は数に入れていない。

## 迷った点

- 扉の札は地方の色でなく緑の地にした（種類の色の飛行場と同じ）。夜は灰の縁
