## 迷った点
- **タブの数**：本番はタブが5つまで。全部乗せの6つ（成績を入れて）は入らないので、成績はマイページのタイルにした。「全部乗せなのに成績のタブがない」は本人に聞く
- **数え方**：全部で40こ（タブ4・見方21・かたまり15）。ホームのタブ（いつも出す）と成績（タイル）は数えない。本番の「いちばん上のカード（撮影・修行の構成のとき）」は構成がなくなるので外した
- **出すピルの色**：はじめは紺の塗りにしたが、全部出していると紺の塊が40こ並んで重い。出すほうを薄い紺にし、隠すほうは取り消し線で分けた
- **提案のピルの意味**：提案のシートでは「隠すもの」を取り消し線で見せた（表示の編集の「隠す」と同じ見た目）。✓ はどの画面でも「出す」
- **B' と案 D とのぶつかり**：3つの分け（タブ・見方・かたまり）は B' でも変えない（B' ならタブの行が「ホーム・帳面・会社」、図鑑・フライト・成績は帳面の中の見方）。かたまりは案 D のカードと同じ単位にしたので、公開のあとはかたまりのピルの列を案 D の並べ替えの一覧に置き換えるだけ
- **今ひな形を使っている人**：見え方を「隠したもの」として読みかえて始めれば、見た目は変わらない（完了の条件）。提案は出さない

## 改善担当に見てほしい点
