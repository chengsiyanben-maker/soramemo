## 作ったもの
docs/design/pin/ に 13画面＋一覧（index.html）。png は 390×844 と 667（2倍）、長い画面は -full。作り方：make/make.py → make/shoot.py（部品は design/ops-split の make.py を写した make/base_ops.py）。

- P1 運用の「機体」のはじめ：「最近見た機体」の上に「ピン止め」の段。1機1行に いまの状態（● 飛行中／駐機中／しばらく見ていない）とどこ・次の便（「予想」の札＋時刻ごろ＋区間）・最後に見た時刻。段の頭に「3 / 20機」と「並べ替え・外す」、その下に保存先の1行

- P1m 多い人：はじめは5機まで、「ピン止めをすべて見る（12）」
- P1e 1機もない人：段の代わりに小さな案内の1枚だけ
- P1x 比べる用：見方の帯に「ピン止め」を足して3つにする案
- P2o／P2 機体の1日：上の1行（戻る・登録記号のピル）の右にピンの印（44px の丸。外すと白、付けると濃い紺で塗る）。付けた直後に帯「ピン止めしました・飛び始めたとき・羽田に向かうときに知らせます｜知らせの設定」
- P3 特別塗装機の欄：行ごとの右にピンの印（行を押すと機体の1日）。海外の塗装機は「この先（予想）は出せません」
- P4 機体図鑑の1機：名前の横に「ピン止め中」のピル
- P5 すべて見る：12 / 20機の目盛り・≡ で並べ替え（上の5機がはじめに出る）・外す・知らせの ON／OFF への入口
- P5f 20機いっぱい：外す1機を選ぶシート（最後に見たのが古い順。「外しても乗った・見たの記録は残る」と書く）
- P6 知らせの設定：「飛び始めたとき」「自分の空港に向かっているとき」の2つの ON／OFF と自分の空港のピル
- P7 知らせの見本：3つ（飛び始め／向かっている（特別塗装機・ピン止め）／海外の会社の機体）と「二重にしない」の決まり

決めた形：ピンの印は線の印（絵文字は使わない）。色は濃い紺だけで、会社の色は機体の色の四角だけ。「予想です。保証しません」と出典 adsb.lol（ODbL）を画面の下に。案内板風は使わない。測った値：13px 未満の字 0・44px 未満の押す所 0（ON／OFF のスイッチは行全体を押す）・はみ出し 0。

## 迷った点
- 見方の名前：「最近見た」の中にピン止めの段を入れると名前と中身がずれる。P1（指示どおり段を足す）と P1x（見方「ピン止め」を足す）を並べた

- 二重の知らせ：空港ごとの特別塗装機の知らせと同じ機体が重なるときは、ピン止めの文面で1回だけ（札に「特別塗装機・ピン止め」）。1機1日に「飛び始め」「向かっている」それぞれ1回まで
- 海外の会社の機体は次の便の予想が出せないので、行にそう書き、知らせは「日本の空港に向かっています」の1回だけ（決定【11/16】と同じ）
- 上限：20機（指示の案のまま）。はじめに出すのは5機
- 夜の画面は今回描いていない（機体の色の四角を夜にどうするかは次の版で）

# 2版：ピン止めの中心を「空港」に（11/17 夜）

PM の追記（11/17 16時25分、本人「特別塗装機がピン止めしている空港に通知が来る設定をうまくやりたい」）を受けて作り直した。1版を作った回はこの追記を取り込めていなかった。1版（機体のピン止め P*.html）は2番目の案として残す。

## 作ったもの（docs/design/pin/*-v2.html・一覧 index.html を2版に）
- 00 今の空港ごとの知らせ：本番をデモで撮影（make/capture_now.py）。空港ごとの知らせは4つ（遅れ・ダイバート＝pushAps 12空港まで／特別塗装機＝sp_airports 14空港まで／ゴーアラウンド＝ga 主な14空港／撮影＝spot いつもの空港1つ）で、申し込む所がばらばら。近くの空港のシートには入口がない
- K1 ホーム：いちばん近い空港のカード（名前の横）と「ほかに 20km 以内」の各行にピンの印
- K2 空港ページ：名前の横に「ピン止め中」、その下に「羽田の知らせ」の1行（ON の知らせを札で）
- K3 図鑑の空港の1枚：「ピン止め」のピル（飛行場・滑空場・ヘリポートの図鑑も同じ）
- K4 ピン止めした直後のシート：何を知らせるか。はじめは「特別塗装機が向かってきたら」だけ ON
- K5 知らせ（1か所。マイページから）：ピン止めした空港の一覧（3 / 12・並べ替え）、空港ごとに ON の知らせを札で。その下に「便（乗る便）」と「機体（2番目の案）」
- K5b 比べる用：空港×知らせの表を1枚に
- K6 羽田の知らせ：4つの ON／OFF（特別塗装機・遅れ／門限ギリギリ／ダイバート・ゴーアラウンド（細かく ›）・撮影（撮影地と機体を選ぶ ›））と「ピン止めを外す」
- K6n 石垣の知らせ：主要でない空港。出せない知らせは薄くして理由を書く（門限ギリギリなし＝欠航・ダイバート・引き返しだけ、ゴーアラウンドは主な14空港だけ）
- K7 運用タブ 空港側：今の「羽田に特別塗装機が来たら通知する」ボタンを「羽田はピン止め中・特別塗装機：ON ›」の状態と入口の1行に。ピン止めしていない空港では「伊丹をピン止めして知らせを受ける」
- K8 運用の空港を選ぶシート：ピン止めした空港が先頭
- K9 今の利用者への1回の案内：申し込み済みの空港をそのままピン止めに移す（知らせの中身は変えない）
- K10 知らせの見本：文の頭を空港の名前に（「羽田にジンベエジェットが向かっています」）。同じ機体が同じ空港に向かうときは、空港と機体の両方をピン止めしていても1回

測った値：13px 未満の字 0・44px 未満の押す所 0・はみ出し 0（13画面×844／667）。作り方：make/make_v2.py（make.py を読み込む）→ make/shoot_v2.py

## 迷った点

- はじめに ON にする知らせ：本人の言葉に合わせ「特別塗装機」だけ。遅れ・ゴーアラウンド・撮影は OFF で始める

# 3版（デザイン担当・11/18）

PM の指示 11/17 21時20分（改善担当 review-1「方向は見せてよい・画面はもう1回直す」）。同じブランチ design/pin の *-v3.html 22枚。画面案だけで、アプリ（web/・src/・supabase/）は変えていない。作り方：make/make_v3.py（make.py・make_v2.py を読み込む）→ make/shoot_v3.py。

## 作ったもの（必ず直す3つ）
1. **通知を許可していない・iPhone でホーム画面に置いていないとき**：K0（最初のピン止めで端末の確認の前に1枚。許可しなくてもピン止めはできる）・K0i（iPhone の Safari：やり方の3つ。iPhone のアプリができたらいらなくなると書いた）・K4d（許可なし：上に端末の1行「許可する」、ON のスイッチは薄い紺＋「届きません」）・K5n（知らせの画面の上に iPhone の1行）。許可済みのときは「✓ この端末に届きます」の小さい1行（K4・K5・K6）
2. **ピン止めの2つの形を全画面でそろえた**：している＝紺の塗り＋塗りのピン＋「ピン止め中」（押せない札・影なし・30px）／していない＝白地＋線のピン＋「ピン止め」（押せるボタン・影つき）。行の丸も紺の塗りと白の線の輪。黒いカードの上も同じ2つ（K1・K1n）。羽田・成田・石垣はどの画面でもピン止め中（K3 の成田も直した。していない形は K3n の中部）。外すのは「○○の知らせ」の下のボタンか、行のピン（外すと「元に戻す」の帯 K4u）
3. **本番の今の形で描き直した**：K1 は白い丸をやめ、「いちばん近い」の行の右に小さな札だけ。「ほか1つ ›」と「→ 右へ引いて印をもらう」、今日の数字の行を本番どおり残した。667 はシートを本番の位置（下から 347px）で描いた。K7・K8 は上を決まった1行（空港｜機体・HND 羽田 ⌄・ⓘ・共有）、見方の帯の右端に鉛筆、「近く」なし。変えるのは特別塗装機の欄の下の「羽田はピン止め中」の1行だけ

## ほかの直し
- K9b：上限12を超える人（例 15空港）。すべてそのまま移して続け、新しくピン止めするのは11以下に減らしてから。K9 は「あとで」→「閉じる」、ゴーアラウンド・機体ごと・乗る便も「そのまま続く」と書いた
- K10：乗る便とピン止めの空港の遅れが重なるときは乗る便の知らせ1つ（11/13 の決まり）。出発・到着の両方をピン止めしても同じ便は1つ。特別塗装機とゴーアラウンドは別のできごとなので別
- K5：ON の知らせだけを紺の字の ✓ チップで出し、OFF は「ほか○つは OFF」（灰の字 4.5:1 以上）。チップは押せない見た目、押す所はカード全体と ›。「＋ 空港をピン止め」を足した。「機体ごとの知らせ 2機」の行を残した（機体のピン止めを入れなくても止め方が分かる）。入口はマイページから（戻るの字）とホームのシートの「ピン止めした空港 3」（K1o）
- K4：最初の1回だけシート、「取り消す」を足した。2回目からは帯「○○をピン止めしました｜知らせの設定」（K4t）
- 撮影の知らせは「ピン止めした空港のうち1つで ON」（K6n：ON にすると羽田から石垣に移す）。「いつもの空港を変える」はなくした。「主な8空港」は空港名で書き、ゴーアラウンドは「14空港だけ（一覧 ›）」
- 羽田は24時間なので、羽田の「遅れ・門限・ダイバート」は「0時前後に着く便・欠航・ダイバート・引き返し」と書いた（門限の知らせはない）
- 見出しを短く（「向かっている特別塗装機」＋下に「この先3時間」）。（推定）は時刻の下に「着（推定）」で切れない所へ
- K8：選んでいる空港は緑の字「選んでいる」、ピン止めは紺の丸で分けた
