# 機体のピン止め 1版（デザイン担当・11/17）

ブランチ design/pin。画面案だけで、アプリ（web/・src/・supabase/）は変えていない。PM の指示 11/17 16時20分。

## 作ったもの
docs/design/pin/ に 13画面＋一覧（index.html）。png は 390×844 と 667（2倍）、長い画面は -full。作り方：make/make.py → make/shoot.py（部品は design/ops-split の make.py を写した make/base_ops.py）。

- P1 運用の「機体」のはじめ：「最近見た機体」の上に「ピン止め」の段。1機1行に いまの状態（● 飛行中／駐機中／しばらく見ていない）とどこ・次の便（「予想」の札＋時刻ごろ＋区間）・最後に見た時刻。段の頭に「3 / 20機」と「並べ替え・外す」、その下に保存先の1行
- P1g ログインしない人：保存先の1行が「この端末だけに保存」＋「ログインして残す ›」（ログインした人は「アカウントに保存・ほかの端末でも出ます」）
- P1m 多い人：はじめは5機まで、「ピン止めをすべて見る（12）」
- P1e 1機もない人：段の代わりに小さな案内の1枚だけ
- P1x 比べる用：見方の帯に「ピン止め」を足して3つにする案
- P2o／P2 機体の1日：上の1行（戻る・登録記号のピル）の右にピンの印（44px の丸。外すと白、付けると濃い紺で塗る）。付けた直後に帯「ピン止めしました・飛び始めたとき・羽田に向かうときに知らせます｜知らせの設定」
- P3 特別塗装機の欄：行ごとの右にピンの印（行を押すと機体の1日）。海外の塗装機は「この先（予想）は出せません」
- P4 機体図鑑の1機：名前の横に「ピン止め中」のピル
- P5 すべて見る：12 / 20機の目盛り・≡ で並べ替え（上の5機がはじめに出る）・外す・知らせの ON／OFF への入口
- P5f 20機いっぱい：外す1機を選ぶシート（最後に見たのが古い順。「外しても乗った・見たの記録は残る」と書く）
- P6 知らせの設定：「飛び始めたとき」「自分の空港に向かっているとき」の2つの ON／OFF と自分の空港のピル
- P7 知らせの見本：3つ（飛び始め／向かっている（特別塗装機・ピン止め）／海外の会社の機体）と「二重にしない」の決まり

決めた形：ピンの印は線の印（絵文字は使わない）。色は濃い紺だけで、会社の色は機体の色の四角だけ。「予想です。保証しません」と出典 adsb.lol（ODbL）を画面の下に。案内板風は使わない。測った値：13px 未満の字 0・44px 未満の押す所 0（ON／OFF のスイッチは行全体を押す）・はみ出し 0。

## 迷った点
- 見方の名前：「最近見た」の中にピン止めの段を入れると名前と中身がずれる。P1（指示どおり段を足す）と P1x（見方「ピン止め」を足す）を並べた
- 却下済み「機体と運航の実績」に当たらないよう、乗った回数・見た回数・飛んだ便の履歴はピン止めの段にも図鑑の1機にも出さない。出すのは「いま」「次の便（予想）」「最後に見た時刻」だけ
- 二重の知らせ：空港ごとの特別塗装機の知らせと同じ機体が重なるときは、ピン止めの文面で1回だけ（札に「特別塗装機・ピン止め」）。1機1日に「飛び始め」「向かっている」それぞれ1回まで
- 海外の会社の機体は次の便の予想が出せないので、行にそう書き、知らせは「日本の空港に向かっています」の1回だけ（決定【11/16】と同じ）
- 上限：20機（指示の案のまま）。はじめに出すのは5機
- 夜の画面は今回描いていない（機体の色の四角を夜にどうするかは次の版で）

## 本人に決めてほしいこと
1. 置き場所：P1（「最近見た」の中に段）か P1x（見方「ピン止め」を足す）か
2. 上限 20機・はじめに出すのは5機でよいか
3. 知らせ：2つ（飛び始め／自分の空港に向かう）でよいか、二重にしない決まり（ピン止めの文面で1回）でよいか
4. ログインしない人は「この端末だけ」と出してログインの入口を置く形でよいか（ログインしたとき端末の分をアカウントへ移すかもあわせて）
