## 作ったもの
- 羽田に多い7機種（787-8／787-9（787-10 も）・777-300ER・767-300・737-800（737 MAX 8 も）・A350-900・A321neo・A320（A320neo も））を、本物に近い形にした
  - 胴：機首の丸さと下がり・尾の跳ね上がり・窓の列とドア・操縦室の窓（A350 は窓のまわりが黒い）・翼と胴のつなぎのふくらみ
  - 主翼：翼の断面（厚み）・後退角・折れ目・上反角・787 の反り。翼の先は 787／777 が斜めに切った先、737-800 が上に曲げた先、MAX 8 が上下に割れた先、A320／A321neo がシャークレット、A350 が曲がった先、767 は先なし
  - 発動機：口の縁・ふくらみ・ファンの面と中心の尖り・後ろの口と芯。787 と MAX 8 は後ろの口のぎざぎざ。737 は下の平らな形。支柱つき
  - 尾翼（垂直・水平）・フラップの覆い・脚（主脚の片側の車輪：777 は6・787／767／A350 は4・細い胴は2。車輪は黒、ホイールは灰色）
  - 寸法は FAA の Aircraft Characteristics Database の長さ・翼幅・高さ・胴の直径に合わせた（テストで翼幅と長さの割合が表どおりか確かめる）
- 色：白い胴＋尾翼だけ会社ごとの大まかな色（昼だけ。夕方と夜は会社の色を使わない＝11/9 の決まり）（便名の頭の3文字。JAL グループは赤・ANA グループは青・AIRDO・ソラシド・スターフライヤー・ピーチ・ジェットスターなど。分からない会社は白に近い灰色）。ロゴ・社名の文字・公式の塗装の絵は描かない。特別塗装機の尾翼は今までどおり昼だけ金
- 見た目：金属っぽい材質（PBR）・空と太陽の映り込み（空の球から作る）・地面への影（今の影のしくみ）・夜は窓が灯り、翼の先の灯りなどは今の灯り（#172）をそのまま付ける
- 重さ：
  - 画面で機体が 45px（古い iPhone は 80px）より大きく見えるとき、と選んだ・追う機体だけ本物に近い形。遠い機体は今の形、遠い地上の機体は今の平らな形（3段の切り替え）。戻すときは少し小さくなってから（ちらつき防止）
  - 重くて質が一番下（0）まで下がったら本物に近い形は出さない。「軽い」表示では今の簡単な形のまま
  - 1機の三角形は約8千（7,964〜8,740）。機種ごとに1回だけ作って使い回す
  - 増える量：ファイルは読まない（アプリの中で組み立てる）ので、届く量はアプリ本体の圧縮で **約5.6KB（brotli 約4.6KB）だけ**（上限 3MB）
- 変えた関数（src/index.html）：a3Mesh（今の形の部分に印を付ける）・a3Sync（3段の切り替え・脚と着陸灯を見えている形の方だけ）・a3SetLite（作り直すとき材質と映り込みも作り直す）
- 足した関数・表：A3_REAL・A3_REAL_RE・a3RealKey・A3_TAIL・a3TailCol・a3Rev・A3_FOIL・a3Loft・a3FusTex・a3Env・a3GeoR・a3RealMats・a3FinMat・a3MeshR・A3_REAL_PX
- テスト：t168 を足した（7機種の鍵・寸法の割合・三角形の数・切り替え・尾翼の色・金・材質・夜の窓・「軽い」）。比べ写真は `A3M_SHOTS=1` のときだけ撮る（ふだんは約2分）。t160（機体の色の確かめに尾翼の色を足す）と t164（同じ名前の灯りが2つあるので見えている方を見る）を新しい形に合わせた

## モデルの規約
- 改変と再配布が認められた（CC0・CC BY）機種ごとの glTF を探したが、見つかったのは TurboSquid・CGTrader などの有料や「ロイヤリティフリー」のもの（再配布を禁じる）と、機種の決まっていない CC0 の素材だけだった。規約を原文で確かめられて7機種がそろうものはなかった
- そのため、決まり（見つからない機種は手で作り FAA の表に寸法を合わせる）どおり、7機種とも手で作った。外のモデルを使っていないので、3D の角に足す出典はない
