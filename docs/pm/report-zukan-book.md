## 作ったもの
docs/design/zukan-book/ に HTML 10枚（一覧 index.html＋01〜07＋02の夜＋05b）。PNG は png/ に 390×844（2倍）・390×667、長い画面は全体（*-full.png）。
- 01 今の図鑑の見にくい所（main の web/ をデモで撮った写真に番号）
- 02 図鑑の基本（右端のツメ9地方＋地方の扉＋空港の並び）／02 の夜（夜の画面の色）
- 03 空港の並び（関東へ飛んだところ。全空港を同じ枠）
- 04 1空港の詳しい所（羽田：データ欄4つ・大きさ比べ・押した記録・‹ 前／次 ›）
- 05 凡例と索引（見方5つ・コードの ABC 順）／05b 索引の 50音順（2回目の回で足した。あ〜わの行で飛ぶ・名前の下に読み）
- 06 番外編と実績の置き場（「別冊」の棚に4冊）
- 07 今の5つの見方をどうするか（見方の帯を「図鑑・地図・行った順」の3つに）

測った値（幅390・高さ844と667）：13px 未満の字 0（単位の 12px を除く）・押す所の 44px 未満 0・字と地の差が 4.5:1 未満 0（24px 以上の太字は 3:1）・横のはみ出し 0。ツメは高さ667でもタブ帯に重ならない。

## 今の見にくい所（01）
1. 切り替えが2段（上：86空港・飛行場・番外編・特別塗装・実績／下：地図・案内標・タイル・年代記・地方）で、どれが基本か分からない。「実績」は右にはみ出して見えない
2. 見方ごとに形も大きさも違う（案内標は 86空港で 11,869px の長さ、タイルは丸い印、年代記は行った所だけ）。見比べられない
3. タイルの見方では地方を押すまで空港が出ず、ほかの地方へ移るには上まで戻る
4. まだの空港は薄い丸だけで何の空港か分からない。行った空港も印と回数だけで図鑑らしい中身がない
5. 特別塗装（機体図鑑）と実績が空港の図鑑と同じ段にあり、その一部に見える

## 借りた紙の図鑑の工夫
1. ツメ：右端に9地方（幅44・高さ44）。押すとその地方の扉へ。色は今の本番の地方の色（守り神の色 GOD_COLORS）。本番の図鑑の RG_COL は9地方とも紺なので、地方の色はこれしかなかった
2. 見せ方をそろえる：全空港を同じ枠（幅いっぱいに3つ・高さ132）。上からコード→短い名前→印と回数
3. なかまの見開き：地方ごとに扉（地方名・集めた数・進み具合・空港の場所の小さな地図）→並び
4. データ欄：コード（大きく太く）・空港名・開港・滑走路の数・押した回数・はじめて押した日
5. まだも同じ枠：薄い地・薄いコード・点線の丸・「まだ」。名前は読める濃さ
6. 凡例と索引（05）
7. 大きさ比べ：羽田の滑走路4本と、押したほかの空港のいちばん長い滑走路を同じ縮尺の線で

## 迷った点
- 地方の色：夜は光る色を2色までの決まりがあるので、夜のツメは色を使わず強い字と細い縁にした
- 案内標の「となりへ進む」楽しさは、1空港の詳しい所の「‹ 前／次 ›」（同じ地方の北から南）に移した。全国の北から順だと羽田の次が鳥取になり、分かりにくいため
- 見方の帯：11/8 の決定（見方は各画面の見方の帯から選ぶ）と ON／OFF の決定はそのまま使い、帯の中身だけ5つ→3つにした（図鑑はいつも出す）
- 別冊の背表紙の色：飛行場の緑・番外編の紺・実績の紫は今の本番の変数（--field・--mil・--secret）。機体図鑑の茶色だけ新しい
- 開港の年・滑走路の長さは見本の値。本番には空港ごとのこの表がない

## 本人に決めてほしいこと
1. 図鑑の基本を「ツメ＋地方の扉＋そろえた枠」（02・03）にしてよいか
2. 見方の帯を「図鑑・地図・行った順」の3つにし、タイル・地方・案内標をまとめてよいか（07）。年代記の名前を「行った順」に変えてよいか
3. 飛行場・番外編・特別塗装・実績を「別冊」にまとめてよいか（06）
4. 1空港のデータ欄に開港・滑走路を出すか（出すならデータ担当に出典つきの表を頼む。国土交通省の空港一覧などで、使ってよいかの確認もいる）
5. 索引に 50音順も置くか（05b。本番には空港名の読みの表がいる。画面案の読みはデザイン担当が書いたもの）
6. ツメに地方の色（守り神の色）を使ってよいか
