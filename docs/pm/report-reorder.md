# 並べ替え（checkin/reorder）

PM 11/22 22時5分「いろいろな物の順番を入れ替えられるように」（本人「あといろんなやつの順序を入れ替えられるように」）。main 1a87bfd から。

## 作ったもの
- **並べ替えの部品（1つ）**：`roGrip(id, 名前)`（≡ のつまみ）と `roBind(入れ物, { done, name })`。マウスはすぐ、指は 0.25秒押してから動かす（格子のカードは上下左右）。キーは矢印。読み上げ用に「上へ」「下へ」のボタン（焦点が来たときだけ見える）。動かすと「『遅れ』を2番目にしました（11このうち）」と読み上げる。並びを合わせる `roOrder(覚えた並び, 今ある物)`（消えた物は落とし、新しい物ははじめの並びの場所に入る）
- **運用タブの一覧のカード**：一覧の右上に「並べ替え」のピル → 編集の形（各カードの右上に ≡・カードを押しても開かない・上に「≡ を押したまま動かします」・下は「はじめの並びに戻す」）→「完了」。隠しているカードは前の場所のまま。並びは layout.order.ohub
- **ホームのシートのカード**：「ホームに出すもの」の見本の右上に「並べ替え」→ 動かせる行のスイッチが ≡ に変わる（隠している行も動かせる・「隠しています」と出す）。動かすとホームのシートもその並び。「はじめの並びに戻す」と「元に戻す」のトースト。並びは今までの layout.order.home（前から保存の形はあったが、動かす画面がなかった）
- 順番は端末（soramemo.layout）に覚え、ログインしている人は今の user_view_prefs の prefs.layout に入る（表は変えていない）。「全部乗せに戻す」で並びも戻る（確認のシートに「カードの並び 元の順に」の行）。はじめの並びに戻したときは、ほかに何も変えていなければ全部乗せのまま
- 見た目は今のカードのまま（つまみとピルが出るだけ）。図鑑・専用ページの中のピルは今回はしない（PM の 3）

## 撮る人用へ（ホームの空港のカードの切り替えのピル）
- 同じ部品を使える。ピルの並びに data-ro と roGrip を入れ、入れ物に roBind を1回。並びは roOrder で覚えた並びに合わせる。使い方は部品の上の説明（src/index.html「並べ替えの部品」）と satsuei.md に書いた
- 覚える所は layout.order.<名前>（例 `layout.order.hcard`）にすれば端末とサーバーにそろう（loEdit().order.hcard = 並び → loChanged）
