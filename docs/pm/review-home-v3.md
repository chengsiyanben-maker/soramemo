## 指摘（効き目の大きい順）

### 1. 開いたシートの中を送ってから下げると、シートが画面の外へ消えて戻らない【大】
- 画面・場所：ホームのシート（引き上げた位置）
- 何が起きるか：引き上げる → 指でシートの中を上へ送る（説明や最近の印を見るいつもの動き）→ つまみを下へ引く（または押す）。するとシートの上の端が 890〜958px（画面の高さは 844px）になり、半券・数字の帯・＋−がすべて画面の外へ消える（写真 1・2）。図鑑やマイページへ行って戻っても消えたまま。読み込み直すと戻る
- なぜ：チェックインの半券が見えなくなり、ふつうの人は戻し方が分からない。いちばん大事な操作ができなくなる
- 原因の見当：中の送った量（.sbody の scrollTop、約430〜500px）が、下げた位置にそのまま足されているように見える（下げた位置 495px＋送った量）
- どう直すとよいか：下げるときに中の送りを0に戻してから位置を決める。シートの上の端は、どの場合も最初の位置（844px の画面で 495px）より下へ行かないようにする。テストに「引き上げ → 中を送る → つまみで下げる → 半券が見える」を足す
- 効き目：大

### 2. 引き上げた位置の「図鑑 ›」が黒いカードの上でほとんど見えない【大】
- 画面・場所：引き上げた位置のいちばん下「最近の印」の見出しの右（#recentBook）
- 何が良くないか：字の色 #1f2937・地は薄いグレー（6%）で、下の黒いカード（#0b0d10）の上に乗るので、色の濃さは約 1.3:1（写真 3b）
- なぜ：決まりの 4.5:1 に届かない。図鑑へ行く入口が見えない。t116 は最初の位置だけを測っているので見つからなかった
- どう直すとよいか：見本どおり最近の印を白い地にするか、黒いカードの上では白い字＋白10%の地のピルにする。t116 の測る範囲に引き上げた位置を足す
- 効き目：大

### 3. 上の段が画面ごとに違い、切り替えが跳ぶ【中】
- 画面・場所：ホーム ⇔ 図鑑・フライト・エアライン経営
- 何が良くないか：ホームは「切り替え（幅236）＋マイページ」の1段。図鑑とフライトは前の「そらメモの字のロゴ＋マイページ」の下に「切り替え（幅350）」の2段で、切り替えが上から 10px → 75px に動く。経営は黒い帯の上（写真 4）
- なぜ：タブを押すたびに上の段が組み替わり、同じアプリの中で別の画面に来たように見える。報告の「ほかの画面は前のまま」は崩れていないという意味では正しいが、見た目はそろっていない
- どう直すとよいか：本人に見せるときに「ホームだけ新しい上の段、ほかは運用・マイページのあとにそろえる」と一言添える。そろえるまでの間に気になるなら、図鑑とフライトの上の段も同じ1段にする（作る順はホーム → 運用 → マイページという本人の決定があるので、どこまでやるかは PM の判断）
- 効き目：中

### 4. 引き上げた位置で最近の印がいちばん下、空港の数が2回【中】

- どう直すとよいか：構成ごとの部品の決まりは変えずに、並びだけ「3枚の数字 → 最近の印 → 前からの部品」にする。前からの数字のカードは、3枚と重なる「空港」だけ外せないか本人に聞く（報告の「決めてほしいこと2」に、空港が2回出ることを書いてあるのは良い）
