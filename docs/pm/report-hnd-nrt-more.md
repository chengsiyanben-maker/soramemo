## 2. 作ったもの（「よい」で、今の取り込みに足すだけのもの）
- **移行199** `20261125000199_hnd_nrt_more.sql`（RLS は ON・方針なし。利用者は読めない・書けない）
  - ground_watch（見張り。6時間・古い行は毎日消す：cron ground-watch-cleanup・上限30秒）・ground_moves（着陸・離陸ごとに1行。ずっと残す）
  - flight_changes とトリガー flight_changes_log（羽田・成田に関わる便だけ。ゲート・機材・状態・見込みの時刻は5分以上動いたとき。便の行が消えても残る）
- **_shared/ground_moves.ts**（純粋な関数）と airport-traffic の recordGround（記録の処理の中。止まっている機体は10分に1回、動いている機体は2分に1回か状態が変わったときだけ書く）
- **読むだけの SQL** docs/pm/hnd-nrt-more-check.sql（5つ）：たまり具合・地上を走った時間（滑走路別・時刻別）・ゲートと機材の変更・続けて降りる間隔
- 影響：チェックイン・経営のどちらの画面にもない。flight_schedule の書き込みに小さなトリガーが1つ増える（羽田・成田の便で値が変わったときだけ動く）
