## 作ったもの（16枚・各 844 と 667 の写真）
- 01 今のばらばらな所：main（#48 入り）・フライト（PR #65）・修行（PR #64）をデモで撮った写真8枚と、画面ごとの違い（帯・開く物・部品・いつも）
  - 開く物が3通り（図鑑・フライト・運用＝下のシート／修行＝別のページ・番号つき／ホーム＝マイページの別のページ）
  - 部品が2通り（シートとタブを選ぶは ON／OFF、表示の編集の1枚だけ ✓ のピルと取り消し線）
  - 表示の編集の1枚に修行の見方・道のりに出すものがない。フライトは古い9つのまま
  - 運用の帯は「滑走路」を選ぶと左の「案内板」が切れて見える
- 02 各画面の鉛筆のシート：図鑑・フライト（日誌 いつも・地図・年のまとめ）・OFF と元に戻す・修行（見方3つ＋道のりに出すもの4つ）・運用（7つ）・最後の1つ。全部同じ形（今のアプリの #dViews の形に合わせた）
- 03 マイページ「表示の編集」の1枚：画面ごとのカード（タブ・ホーム・図鑑・フライト・修行・運用・成績・よく見る空港）の下に ON／OFF の行。カードの見出しを押すとその画面へ。題と「‹ マイページ」は上に固定、「全部乗せに戻す」はいちばん下。鉛筆の「すべて見る」から来たときはその画面のカードまで送って縁を光らせる（03d）。「隠しているもの」で絞った形（03e）
- 04 いつも出す物の行：スイッチの代わりに「いつも」（スイッチと同じ幅）。一覧はホームのタブ・ホームの地図・半券と今日の数字・図鑑の地方別・フライトの日誌。最後の1つはスイッチを薄くして「見方は1つより減らせません」
- 05 夜：図鑑とフライトのシート、表示の編集。ON は強い字と細い縁
