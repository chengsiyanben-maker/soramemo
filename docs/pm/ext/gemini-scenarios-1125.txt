4タブ構成（ホーム／いまの空港／記録／マイページ）は、利用シーンが変わっても「同じ情報を二度入力させない」「現場では最短1〜2タップで終わらせる」ことを軸に連携させます。まずは4つの利用シナリオ全体の俯瞰です。
| シナリオ | 場所・状況 | 起点の画面 | 主な画面遷移ルート | このシナリオのゴール |
|---|---|---|---|---|
| 1. 初回起動 | 自宅・空港外 | オンボーディング | 導入 → 過去空港 → 予定/マイ空港 → 権限 → ホーム → いまの空港 | 60〜90秒で地図を色づけ、自宅でも開く理由を作る |
| 2. 空港滞在 | ターミナル・搭乗口 | ホーム（滞在モード） | ホーム → 完了カード → 便記録シート → いまの空港（→ 3D / 特塗） | 片手操作でチェックイン・便記録・遅延確認を完結させる |
| 3. 帰宅後 | 自宅（オンライン） | ホーム → 記録 | 自動同期トースト → 記録（フライト → 図鑑） → マイページ | 旅の成果を振り返り、次の小目標とシェア・バックアップへ繋ぐ |
| 4. リピーター | 自宅・ホーム空港 | マイページ / ホーム | マイページ（修行ON）→ ホーム ⇄ いまの空港 → 記録（修行・図鑑） | 再訪問・特別塗装機・上級会員計画を1つの循環で回す |
1. 初回起動シナリオ（自宅・空港外）
アカウント登録を後回しにし、「地図が真っ白・数字がすべて0」の離脱ポイントを最短で抜けるフローです。
 * 導入 → 過去の空港を一括選択（オンボーディング 1/3）
   * 専門用語を出さずに「はじめる」を1タップ。これまで行った空港をピルで複数選択すると、画面上部の制覇数（例：6 / 97 空港）が大きく太字でリアルタイムに増える。
   * ここで選んだ空港は「訪問済みメモ（淡いピン）」として記録され、現地チェックインで「現地の印（濃いピン）」に昇格する仕組みを明示する。
 * 次の予定 または マイ空港の設定（オンボーディング 2/3）
   * 予定があれば「出発・到着・日付」の3点だけ登録。予定がなければ身近な空港（例：羽田）をマイ空港として1タップ選択する。
 * 成果プレビュー → 位置情報・通知の許可（オンボーディング 3/3）
   * 「訪問した空港 6 / 97」「関東エリア 2 / 6」のカードを見せて納得感を作ったうえで、位置情報と通知の許諾を求める（拒否しても先へ進める）。
 * ホーム着地（通常モード）
   * 地図に淡いピンが並び、下部シート最上段に「次のフライトまであと14日」または「最寄り空港までの距離」が表示される（押せないチェックインボタンは出さない）。
 * 初回限定カード → 「いまの空港」を1回体験
   * シート最下部の初回限定カードから いまの空港を見てみる を1タップ。今日の便・使用滑走路・特別塗装機をのぞくことで、「空港に行かない日でも見て楽しいアプリ」という記憶を残す。
2. 空港滞在シナリオ（到着〜チェックイン〜搭乗まで）
荷物を持った片手操作、GPSブレ、機内モード、バッテリー消費を前提に、ホーム1画面をハブにしてタブ往復を最小限に抑えるフローです。
 * ホーム起動 → 空港滞在モードへ自動切替
   * 端末が内蔵の空港ポリゴンに入ると、地図が現在空港に自動ズームし、下部シート最上段に全幅ピルボタン 羽田空港にチェックイン が現れる。
   * 屋内・地下でGPSがズレた場合は、直近30分の履歴から 羽田空港の近くにいますか？ を出して再測位または予約保存へ救済する。
 * 1タップチェックイン（オフライン・パケ詰まり耐性）
   * オンライン時は即確定、機内モード・圏外・3.5秒超過の通信詰まり時はエラーを出さず自動で 送信待ち（予約保存） として端末に時刻と場所を保存する。
 * 完了カード（1.2秒モーダル）で手応えを得る
   * ホーム地図を残したまま、滑走路ライン＋3レターコード（HND）の記念カードが浮上。訪問回数と制覇数がカウントアップする（急いでいれば0.35秒以降いつでも下スワイプで即離脱可能）。
 * 完了カード直下から「今日の便」を1タップ記録
   * カード下部の 今日の便を記録する をタップすると、現在空港の直近便候補が並んだ記録シートが開く。該当便を1タップするだけで、手入力ゼロで 記録（フライト） へ登録される（オフラインでも端末保存）。
 * 搭乗待ち時間に「いまの空港」へ1ホップ
   * ホームの現場ライブ要約カード（遅れ +12分・34L/34R・特別塗装 4機）をタップして いまの空港 タブへ遷移。
   * 実用確認は 今日の便 で搭乗口・遅れを確認。余裕があれば 滑走路・3D の明示ボタン 3Dで空港を自由に見る から実機の駐機位置を探し、見つけた特別塗装機は 特別塗装機 タブから1タップで 図鑑に記録 する。
3. 帰宅後シナリオ（振り返り・図鑑確認・シェア）
移動中の慌ただしさが落ち着いた自宅で、旅の記録が「自分のコレクションと資産」に変わる瞬間を味わうフローです。
 * アプリ起動 → 送信待ちデータの自動確定
   * 空港や機内で予約保存していたチェックインとフライト記録がオンライン復帰と同時に自動送信され、画面上部に控えめな白ピルトースト 羽田空港の印が確定しました が2秒表示される。
 * 記録（フライト）で「空の上の時間」と航路を眺める
   * 増えた 空の上の時間（36px太字）と総飛行距離・搭乗回数を確認。軽量プレビュー地図から 拡大する を押し、新しく伸びた飛行ルートを全画面で眺める。
   * 記録し忘れた便があれば右上の + 記録 から「日付＋便名」の自動補完で追加する。
 * 記録（図鑑）で昇格と次の小目標を確認
   * 上部ピルを 図鑑 に切り替え、今回「訪問済みメモ」から「現地の印」に変わった空港タイルをタップして記念カードを見返す。
   * エリア別進捗（例：関東 5 / 6 ・ あと1空港でエリア達成）や、空港で記録した特別塗装機の 搭乗済み／目撃記録 カードが埋まったことを確認し、次の旅の動機が生まれる。
 * マイページで成績をシェア＋任意バックアップ
   * マイページ の成績サマリーカード（制覇空港数・総飛行距離・空の上の時間）を画像書き出ししてSNSへシェア。
   * 初回の現地チェックインを達成したこのタイミングで、マイページ上に静かに 記録をクラウドにバックアップする（ログイン・アカウント連携）を案内し、機種変更時のデータ消失を防ぐ。
4. リピーターシナリオ（常連・航空ファン・上級会員修行）
同じホーム空港を何度も利用するユーザーや、JAL・ANAの上級会員を目指すコア層が、専門機能をストレスなく使い倒す循環フローです。
 * マイページ（設定）で「修行モード」をONにする
   * 初期状態では隠れていた上級会員機能をオプトインで有効化。これにより 記録 タブ上部のピルが フライト｜図鑑｜修行 の3分割に拡張される。
 * ホームで予定登録 → 修行タブの見込みへ自動連動
   * ホーム で次の予約便を登録すると、ホームでは搭乗カウントダウンが動きつつ、記録（修行） の進捗バーにも「予約済み見込みポイント」が淡紺色で自動加算される。
 * 記録（修行）で誤差補正と試算を行う
   * 確定済み＋予約済み見込みの2トーンバーで「達成まであと何ポイント／何搭乗か」を一目で把握。
   * 運賃種別やキャンペーンで自動計算と差が出た便は、リストからタップして確定ポイントを手動上書き補正する。足りない分は シミュレーション便を追加 で実履歴を汚さずにルート試算を行う。
 * 同じ空港への再訪問（ホーム → 完了カード）
   * 羽田など通い慣れた空港でも、チェックイン完了カードに 12回目の訪問 ・ 前回から38日ぶり と積み重ねを表示。10回・20回などの節目だけ控えめなゴールド縁取りで静かに祝う。
 * いまの空港 ⇄ 図鑑（特別塗装機・飛行場）の日常回遊
   * 空港へ行く日以外でも いまの空港 で使用滑走路や特別塗装機の飛来状況を確認し、珍しい機体を見たら 図鑑に記録 へ1タップ連携。定期便空港の収集が一巡したユーザーは、図鑑 の 飛行場 ピルへ進み、より深い収集体験へ自然に移行する。
4タブ全体の画面遷移とシナリオ別ルート
下の図で4つのシナリオを切り替えると、各タブと一時シートの間をユーザーがどう行き来し、どのタイミングでデータが自動連動するかをステップごとに確認できます。
4つのシナリオを通してみると、「ホーム」がすべての出発点と現場ハブになり、「いまの空港」がリアルタイムの観察・実用を受け持ち、「記録」が蓄積と計画を一手に引き受け、「マイページ」が外向きのシェアと設定を担うという役割分担に重複がありません。これにより、初回ユーザーにはシンプルに見え、使い込むほど自然に奥行きが広がる構造になります。
