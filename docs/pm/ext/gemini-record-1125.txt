「記録」タブは、ユーザーが積み上げた「飛んだ履歴（フライト）」「集めた成果（図鑑）」「上級会員の計画（修行・オプトイン）」を1箇所に集約する画面です。
ベース背景 #F2F4F7 の上に白い角丸カード（#FFFFFF・角丸16px・枠 1px solid #DCE1E8・薄い影）を並べ、黒い区切り線は使わずに余白と太字数字で整理します。
1. 「記録」タブの共通ヘッダー構成
画面最上部にピル型セグメントタブを固定します。「修行」は設定でONにしたユーザーにだけ3つ目の選択肢として現れます。
 * 通常時（初期設定）： ( フライト )　( 図鑑 )　の2分割
 * 修行モードON時： ( フライト )　( 図鑑 )　( 修行 )　の3分割
右上に現在開いているサブタブの主アクションを1つだけ配置します（例：フライト時は + 記録 ピル、図鑑時は検索アイコン）。
2. サブタブA：「フライト」（搭乗履歴・空の上の時間・飛行ルート）

設計ポイントと理由
 * 月ごとに1枚の大きな白カードにまとめる： 1便ずつ別カードにすると余白だらけで縦に長くなり、過去履歴の一覧性が落ちます。月単位でカード化し、行間18px＋太字の区間コード（HND → CTS）と所要時間（1h 35m）をアンカーにして視認性を保ちます。
 * 地図はカード内で軽量プレビュー、タップで全画面操作： スクロール中に意図せず地図が動いてしまう誤操作を防ぐため、カード内では固定プレビューとし、拡大する タップ時のみピンチ操作・航路別タップが可能な全画面マップを開きます。
 * 手入力を減らす + 記録 シート： 右上の + 記録 を押すと、まず最上段に「最近のチェックインから自動推測した候補便」をピルで並べます。過去便を後から入れる場合も「日付＋便名（数字のみ）」を入れれば区間・時刻・所要時間・機材を自動補完し、保存1タップで完了させます。

3カテゴリの出し分けルール
 * 「空港」ビュー（定期便空港）：
   * 上図の通り、現地の印（濃い#1C4FA0）・送信待ち（小さなグレー点）・訪問済みメモ（淡い枠）・未訪問（#E8ECF2のシルエット）の4状態を印タイル上で一目で識別できるようにします。
   * タイルをタップすると、チェックイン完了時と同じ記念カード（滑走路モチーフ＋訪問履歴＋この空港を発着した自分のフライト一覧）が開きます。
 * 「飛行場」ビュー（その他飛行場・コミューター等）：
   * 定期便空港の母数に混ぜると「19 / 150」のように達成率が急に下がり一般層が萎えるため、専用ピルに分離します。構成は空港ビューと同じ地方別カードで、興味のあるユーザーだけが深く掘り下げられます。
 * 「特別塗装機」ビュー：
   * 「いまの空港」タブの特別塗装機一覧と同じカード構造を流用し、登録済み（乗った／見た）の機体には控えめなサンドゴールド（#E9C46A）のステータスピル（搭乗済み または 目撃記録）を添えます。
   * まだ登録していない機体も「現在運航中」リストとして見られるようにし、タップすると「記録を追加」または「いまの空港で本日の運航を確認」へ繋げます（※運用を集めるバッジは作りません）。

修行タブ特有のUX配慮
 * 「確定済み」と「予約済み見込み」を2トーンで分ける： 修行ユーザーが一番知りたいのは「いま予約している便を全部飛んだら、あと何ポイント足りないか」です。ホームで登録した予定便を自動で「見込み（淡紺）」に反映し、不足分を一瞬で把握できるようにします。
 * 誤差を潰す「タップで手動補正」シート： 各便をタップすると、運賃種別（積算率75%・100%等）と搭乗ボーナス（+400など）を選べるほか、確定ポイント数を直接数値入力で上書きできる欄を最下部に置きます。自動計算のズレによる不信感を防ぎます。
 * 実記録を汚さないシミュレーション便： 「羽田〜那覇をあと2往復したら届くか？」を試したいときのため、フライトタブの確定履歴には混ぜずに試算だけできる「計画便（予定ラベル）」を修行タブから直接追加・削除できます。
5. 他タブと「記録」タブのデータ連動まとめ
画面同士がバラバラにならず、ユーザーが同じ情報を二度入力しなくて済む連動ルールです。
| 起点の画面・操作 | 「記録」タブへの自動反映 | ユーザーが得られるメリット |
|---|---|---|
| ホーム：現地チェックイン完了 | 図鑑（空港）のタイルが「現地の印」に昇格し、地方進捗バーが即時更新される。 | チェックイン直後に図鑑を開けば達成感がそのまま繋がる。 |
| ホーム：次のフライト予定を登録 | フライトの最上部に予定として控え、修行の「予約済み見込み」に自動加算される。 | 旅行前に1回入力するだけで、カウントダウンと修行計画の両方が動く。 |
| いまの空港：今日の便 →「フライト記録に追加」 | 便名・区間・時刻・機材が入った状態でフライトへ追加され、修行のポイントも自動計算される。 | 移動中に手入力ゼロで記録とポイント計算が終わる。 |
| いまの空港：特別塗装機 →「図鑑に記録」 | 図鑑（特別塗装機）に日付・空港つきで即登録される。 | 空港で見かけた瞬間に1タップでコレクションに残せる。 |
