- 指示：PM 11/20 1時50分（本人「ほかの図鑑の改良で、飛行場、滑空場、ヘリポートのフィルター機能、すべてに何県か表示して」）
- 見る所：docs/design/zukan-filter/index.html（png/ に 393×852 の2倍と 667、一覧は index-full.png）

## 作ったもの
- 00 今（main をデモで撮った）
- F1 すべて（おすすめ）／F1b 関東まで送ったところ
- F2 ヘリポートに絞った（地方別）／F3 ヘリポートに絞った（地図）
- F4 案A「基地」のピルを足す／F5 案B 基地は「すべて」の中だけ
- 決めた形
  - 絞り込みは見方の帯のすぐ下に、ピルの溝の4つ「すべて・飛行場・滑空場・ヘリポート」。各ピルは名前と小さな数（75・30・33・12）だけ。選んだものは白い面と薄い影（上の「スタンプラリー｜エアライン経営」と同じ形）
  - 絞ると黒いカードが「● ヘリポート 1／12」になり、地方ごとの数・扉・ツメもその種類だけ（中身のない地方のツメは薄く押せない）。扉の「飛行場・滑空場・ヘリポート」の札は、絞ったときは外す（ピルと同じことなので）
  - 県名は枠の名前のすぐ下に 13px の薄いグレー（例「埼玉県」）。取っていない所も出す。1つの種類に絞ったときは種類の札を外し、県名だけにする
  - 地図：今のこの図鑑には地図の見方がないので、図鑑と同じ見方の帯「地方別・地図」を足した。地図でも同じピルが効く。行った所は種類の色の丸と名前、まだは灰の輪。地図のときは黒いカードを数の1行だけにし、下に「まだ」の行（名前と県名）
  - シークレット（secret）は今までどおり出さない
- 測った値（852・足した所）：13px 未満 0・44px 未満 0（見方の帯は今のアプリの 40px のまま）・はみ出し 0・名前と県名の切れ 0
- 作り方：main の web/ を http.server 8765 → make/capture_now.py → make/build.py（デモに入り inject.js で #bookAir を描き直す）→ make/shoot.py <フォルダ> → make/make_pages.py

## 迷った点
- 基地の扱い：指示は「基地のピルを足す（F4）」か「すべての中だけ（F5）」の2通り。ただ 11/18 に図鑑の名前を「基地」として別の図鑑にしたので、おすすめは今のまま別の図鑑（F1 の形・すべて＝75）。F4 はピルが5つで横に送る形になり、F5 は題（「…ヘリポートの図鑑」）と数（75→102）が変わる
- ピルに数を入れると「ヘリポート」が入りきらないので、数は名前の下の2段目にした
- 県名は北海道の枠だと「北海道」が並んでくり返しになるが、指示どおりすべてに出した
- 基地の名前（旭川駐屯地など）は今の折り方の決まりが基地向けでないので、F4・F5 では「駐屯地・基地」の前で折った（作るときに zkxBreak に足す）
