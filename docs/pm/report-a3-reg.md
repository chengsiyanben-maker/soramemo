# 報告：登録記号を決めて羽田の3D を開く（checkin/a3-reg）

11/26 定時の回。帳面の「次にやること」の「撮る人用の依頼①②」から。main（594dd3ee）から作った。

## 作ったもの
- 撮る人用の依頼①：羽田の3D を「この登録記号の機体を選んで開く」入口を、土台の関数として足した
  - `openAp3dReg(reg)`：3D を開き、位置が届いたら、その登録記号の機体を「追う」で開く（空の機体も地上の機体も）。小文字・ハイフンでも同じ機体（JA-01XJ・ja01xj → JA01XJ）
  - ボタンなら属性 `data-ap3d-reg="JA01XJ"` を付けるだけで動く（呼び出しのコードは要らない）
  - いま羽田の近く（30km・3,000m 以下と地上）にいない機体なら、全体のまま、下の一言の欄（前からある「位置が届かなくなりました」の欄）に「JA8941 はいま羽田の近くにいません。全体を出しています」と「ほかを追う」（10秒）
  - デモでは位置がないので全体のまま（前からの「デモでは機体の位置は出ません」の札）
  - ふつうの「3D」（data-ap3d）は今までどおり全体で開く
- 撮る人用の依頼②（図鑑の特別塗装機に「運航中／終了」の切り替え）は作っていない。図鑑の画面に切り替えのピルを足すことになるので、デザイン担当の画面案を待つ（PM への依頼に書いた）

## src/index.html で変えた関数
- 足した：`a3RegKey`・`openAp3dReg`・`a3WantReg`
- 変えた：`a3Poll`（最後に待っている登録記号を探す1行）・`a3Loop`（機体の形ができたあと上の札とピルを1回出し直す）・`a3Aux`（一言の欄の文を「いない」のときだけ変える）・3D を開くクリックの受け手（data-ap3d-reg）
- 撮る人用の持ち場のコード（特別塗装機の一覧・くわしく）は変えていない。「3Dで見る」のボタンは撮る人用が付ける

## 確かめた結果
- t205 を足した（属性だけで開く・小文字とハイフン・地上の機体・いない機体の一言と「ほかを追う」・ふつうの 3D は全体のまま・2.5秒たっても見失わない）：全部成功
- 3D のテスト t142・t159〜t163・t165・t166・t181・t190・t202：すべて成功（4組に分けて並べて流した。t190 は1本で約6分）
