# 報告：すべての見方の設定をアプリに作った（feat/view-settings）

PM の指示（11/11 13時5分）・本人「すべてよい」（11/11 13時）。画面案 design/view-settings の 2版（0176e46）と改善担当 review-1.md。ブランチ feat/view-settings（main 2344c44＝フライト PR #65 の入った版から）、下書きのプルリクエストで止める。main と本番の Supabase には入れていない。

## 作ったもの
- 消せない見方は案A：図鑑の地方別・フライトの日誌も OFF にでき、どの画面も最後の1つだけ残る。「いつも」はホームのタブ・ホームの地図・半券・今日の数字だけ
  - 案A の前に保存した物は前の決まりどおり（地方別・日誌を出す）。案A で保存すると layout に `vA:1` の印が付き、読むときに地方別・日誌を戻さない。サーバーの形（fmt 3・user_view_prefs）は変えていない
- 各画面の鉛筆のシート（図鑑・フライト・運用）
  - 文は「OFF で見方の帯から隠れます。最後の1つは残ります。」。全部の行に説明を1行（OFF でも残し、字を薄く）
  - 最後の1つは押せないスイッチ＋名前の横に「最後の1つ」の札＋行の下に理由
  - 見方が1つになっても、見方の帯は名前（例：滑走路）と鉛筆を残す（前は帯ごと消えていた）
- マイページの「表示の編集」の1枚（「全部を見直す」のタイルから）
  - 画面ごとに畳んだカード：タブ・ホーム・図鑑・フライト・運用・成績・よく見る空港。見出しは「フライト 2/3 隠している：年のまとめ」の形、押すとその場で開く／畳む
  - 中は全部 ON／OFF のスイッチ（✓ のピル・取り消し線・大きい「40/44」はやめた）。上は「すべて｜隠しているもの N」と小さく「32このうち」
  - タブのカードは「5/5」（ホームを入れて5つまで）。5つのときに OFF のタブを ON にすると「タブを選ぶ」を開いて入れ替えるタブを聞く
  - 開いたカードの下に行き先の字（「図鑑へ ›」「見本で編集 ›」「タブを選ぶ ›」「成績へ ›」）。数とは離した
  - 鉛筆の「表示の編集をすべて見る」から来たときは、その画面のカードだけ開いて縁を光らせ、上の固定した見出しのすぐ下まで送る
  - 「隠しているもの」で絞ると、隠しているカードだけ開いて隠した行だけ出す
  - 元に戻すの帯はいちばん下に止まる（帯のぶん中が延びるので、送れば最後の行も見える）
  - 下の文に「経営の画面はここに入りません」
- 修行のカードは修行担当の持ち場なので中身は作っていない。修行担当が `LO_EXT.sg = { groups(), toggle(id) }` を足すと1枚に修行のカードが出る形だけ用意した（足すまでは出ない）。shugyo.md に頼んだ

## 変えた関数（src/index.html）
