# 「元日の印」を外す（checkin/drop-newyear）

11/25 13時 PM の積み（本人の指示「外す」）。却下済み「季節のスタンプ」と、11/24 の季節の印を外した決定にそろえた。

## 作ったもの
- 実績の「元日の印」（ny・1月1日にチェックインする）を外した。印をもらった画面の時間の印（timeMarks）からも「元日の印」を外した（朝の印・夜の印は残す）
- 分類「時間と季節」を **「時間帯」** に改名（中身は朝の印・早起きの旅人・夜の印・夜ふかしの旅人の4つ）。指示の例は「時間」だったが、中身が朝・夜の時間帯なので「時間帯」にした
- ほかの実績の分類に季節の言葉が残っていないことを見た（残る「季節」は振り返りの春夏秋冬の回数＝数字と、経営の季節の需要だけ。どちらも触っていない）
- 計算だけなので消える記録はない。前に「元日の印」を称号にしていた人は、称号が出なくなるだけ（titleName が空）
- 変えた関数・表（src/index.html）：timeMarks・ACH（ny の行を外し、分類名を「時間帯」に）・achState（newyear の数えを外した）
- 経営の行事「年末年始ボーナス」（newyear-2027）は経営の持ち分なので触っていない

## 確かめた結果
- t192 を足した：元日の朝・夜の記録で朝の印・夜の印だけ取れる／一覧・印の画面・実績の画面に「元日の印」「時間と季節」が出ない／「時間帯」の分類が出る／前の称号が出ない／実績の数（519）が数えられる／エラーなし
- t17 の確かめる id から ny を外した
- run_all で t192・t182・t17・t141・t145・t118・t119・t124・t15・t16・t34・t37・t41・t52・t70・t47・t120 成功
