## 作ったもの
- 遅れの専用ページ（#opsLate）に、図鑑と同じピルの絞り込み
  1. 種類：すべて・遅れ・欠航（数を小さく。ほかの絞り込みを掛けた数）
  2. 向き：すべて・出発・到着（「すべて」を足した。PM の積みは出発・到着の2つ）
  3. 航空会社：一覧にいる会社だけ（便名の頭2字から。JAL・ANA・スカイマーク…。多いときは横にすべらせる）
  4. 30分以上の遅れだけ（スイッチ）。欠航は長さがないので残す（欠航を消したいときは種類で「遅れ」）
- 便ごとの行：定刻（大きく）・見込み／実際の時刻・行き先（へ／から）・便名・会社・「35分遅れ」／「欠航」の札
- 0件は「この条件の便はありません」の1枚と「絞り込みを戻す」
- 端末に覚える（soramemo.ops.lateFilter）。覚えた会社が今日いなければ「すべて」で見せる（覚えたものは消さない）
- 変えた関数（src/index.html）：新 ltLoad・ltSave・ltAirline・ltRow・ltMatch・ltListHTML・LT_KEY・LT_DEF・LT_F・[data-ltf] の押す動き／変えた opsLateHTML（'bad' があれば時間ごとの札の代わりに一覧）／CSS は .opslate の下に足した

## 大事な点：データ担当の関数が入るまでは本番の見た目は変わらない
- 今の airport_board は「1時間ごとの数」と「この3時間の便」しか返さず、今日の遅れ・欠航の便の一覧がない。表・移行はデータ担当だけが触るので、移行は作っていない
- 案：docs/pm/delay-filter-board-bad.sql（airport_board に 'bad' を足すだけ。表・列・RLS・権限は変えない）。作り物の時刻表（PGlite・t105 と同じ作り方）で、bad 以外は前と全部同じ・bad の数は hours の遅れ＋欠航と同じ（18通り）を確かめた
- 'bad' がないあいだは前の時間ごとの札のまま（t165 の5・t159 で確かめた）。どちらが先に入っても壊れない
