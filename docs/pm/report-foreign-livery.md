# 報告：海外の航空会社の特別塗装機が来るのも知らせる（データ担当・11/16）

PM の指示（11/16 10時55分）：本人「海外の塗装機が来るのも通知に出したい」（例：11/16 BA5 G-YMMU ワンワールド塗装）。まず元と規約・手間を調べて案を報告に。コード・表は変えていない。

## いまの仕組み（リポジトリを読んだ結果）
- 一覧は `supabase/functions/_shared/liveries.ts` に手で書いている。**海外の会社の機体もすでに入っている**（10/15 から）：特別塗装（kind special）13機（エバーのハローキティ・ターキッシュ・ユナイテッド・エティハドなど）と、アライアンス塗装（kind alliance）約40機
- 来るのを知らせる処理は airport-traffic の recordLiveries → notifyLivery：運用タブの空港の近くで「着陸に向かっている（arr）」と分かったとき、その空港の特別塗装機の通知を申し込んでいる人に1回（livery_notified で同じ機体・空港は6時間に1回）
- **G-YMMU が来なかった理由は2つ**：①一覧にない（BA の機体は1機もない） ②アライアンス塗装は「毎日飛んでいるので知らせない」決まり（10/15 のコミット「アライアンス塗装は通知せず、たたんだ欄に分ける」。コードの kind !== "alliance" が4か所）
- 知らせは「着陸に向かっている」＝着く数分〜十数分前だけ。「何時ごろ来るか」を早めに知らせる仕組みはない
- livery_sightings の登録記号の制約は 10/15 の移行41で海外の形に広げ済み。表を変えずに海外の機体を足せる

## 一覧の元（規約で使えるもの）
| 元 | 使い方 | 判定 |
|---|---|---|
| 航空会社の公式の発表（報道発表・公式 SNS） | 登録記号・塗装名・期間を事実として書く | 使ってよい（事実だけ。文や写真は写さない） |
| 航空専門の報道（Aviation Wire・TRAICY など） | 同上。今の一覧の出典の多く | 使ってよい（事実だけ） |
| planespotters.net のニュースの頁 | 今も使っている。記事の中の登録記号と塗装の事実 | 使ってよい（写真は使わない） |
| ウィキメディア・コモンズの分類（例「アライアンス塗装の機体」の分類） | 分類の名前と登録記号の対応（事実）。写真は使わない | 使ってよい見込み（写真は CC で条件つき。事実の拾い出しだけ） |
| 本人が手で足す表 | 撮った・見た機体を本人が足す | 使ってよい |
| Flightradar24 のブログ・画面・データ | — | **使わない**（決まり）。**今のアライアンス塗装の31機の出典が FR24 のブログ（2020年11月の一覧）になっている**。出典を公式・報道・コモンズに差し替えるか、確かめられないものは外す必要がある |

G-YMMU（BA の 777-200ER）は、航空写真の記録サイトで「ワンワールド塗装」として何度も記録されている（例：airhistory.net の G-YMMU）。公式・報道の出典をこれから探す（見つからなければ本人の目撃で足す）。

## 案
### 1. 一覧の持ち方
- **案1-A（おすすめ）表 livery_extra を作り、本人が Table Editor で足せるようにする**：列は reg・name・airline・kind（special／alliance）・src（出典の URL、空は不可）・from・until・added_by_hand。RLS は誰でも select、書くのは service_role と本人（運営）だけ。関数は liveries.ts と合わせて読む（同じ登録記号は表を優先）。移行1つ（170）とテスト（t109）。影響はチェックイン（運用タブ・特別塗装機の欄）と撮る人用（注目の機体）、経営なし
- 案1-B 今のまま liveries.ts に足す：表を作らない。足すたびにコードの変更と反映が要る

### 2. 来るのを見つける
- **案2-A（おすすめ・外への問い合わせを増やさない）**：今の adsb.lol の円（日本のまわり）で一覧の海外の機体が見えたら、adsb.im の経路（airport-foreign で使っている routeset）で行き先を見て、日本の空港行きなら「○○が△△に向かっています（推定）。着くのは○時○分ごろ（推定）」と1回知らせる。着く見込みは残りの距離と対地速度から。二重にしないのは今の livery_notified（機体・空港・6時間）に合わせる。円に入るのは着く1〜2時間前が多い見込み
- 案2-B もっと早く（離陸したとき）：一覧の海外の機体（約50機）を adsb.lol の登録記号の問い合わせ（/v2/reg/）で10分ごとに見る。1日約7,200回ふえるので、**adsb.lol の作者に上限を確かめてから**（前からの「本番で使っている連絡」と一緒に）
- 便名でも：時刻表のない海外の便（BA5 など）の到着の見込みは、別の報告（report-foreign-carriers.md の案A）と同じ仕組みで出せる

### 3. アライアンス塗装を知らせるか（本人に決めてほしい）
今は「毎日飛んでいるので知らせない」。G-YMMU のように海外の会社のアライアンス塗装は日本に来る回数が少ないので、
- **案3-A（おすすめ）海外の会社のアライアンス塗装だけ知らせる**（JAL・ANA など国内の会社のアライアンス塗装は今までどおり知らせない）
- 案3-B 全部知らせる／案3-C 今のまま知らせない（一覧に足すだけ）

## 撮る人用担当への依頼（案が決まったら）
「つぎに来る注目の機体」と特別塗装機の欄に、海外の会社の塗装機の「来る見込み（推定）」を出すなら、spot_push.ts の kind !== "alliance" の扱いを案3に合わせてほしい。データ側は来る見込みの時刻（eta）と出典の文を返す形を用意する。

### 案1-A 表 livery_extra（移行184）
- 列：reg（主キー。adsb.lol の書き方）・name・airline・kind（special／alliance、既定 special）・src（**必須・https・Flightradar24 は入らない**）・from_day・until_day・note・added_at
- 本人が Supabase の **Table Editor で1行足すだけ**で、5分以内（関数が5分ためる）に運用タブ・空港のいま・特別塗装機の知らせに出る。コードの変更と反映は要らない。同じ登録記号がコードの一覧にあれば表のほうを使う（名前の直し・終わる日の書き足しにも使える）
- 終わった塗装は消さずに until_day を入れる
- RLS：誰でも select（塗装の名前・会社・出典の事実だけ）。anon・authenticated は書けない。書くのは service_role と Table Editor
- 影響：チェックイン（運用タブ・空港のいまの特別塗装機に表の機体も出る。返す形は同じ）・撮る人用（注目の機体に表の機体も入る）。経営は使わない

### 案2-A 日本のまわりで見えたら行き先と着く見込みを1回（airport-traffic の記録の回）
- 対象：海外の会社の塗装機（特別塗装と、海外の会社のアライアンス塗装）で、便名があり 5,000ft より上、まだ空港の近くで「着陸に向かっている」と分かっていないもの
- 行き先：①**ふだん着く空港**（foreign_usual。前の8週の実績。外への問い合わせなし。livery_inbound_usual、service_role だけ）②なければ **adsb.im の経路のデータ**（airport-foreign と同じ問い合わせ先。その回の対象をまとめて1回）。機体の進む向きがその空港へ向いている（ずれ60度まで）・1,500km 以内のときだけ決める
- 着く見込み：残りの距離 ÷ 対地速度 ＋ 降りる分（80km より遠ければ12分）。ふだんの着く時刻と40分以内ならふだんの時刻を使う
- 文：「○○（会社・便名）が羽田に向かっています（推定）。着くのは10:42ごろの見込みです（推定）。」送る相手は今の空港の特別塗装機の知らせ（sp_airports）を申し込んでいる人
- 二重にしない：同じ便（機体・便名）は12時間に1回だけ調べる（行き先が分からなければ15分後にもう一度）。知らせたら livery_notified の（機体・空港）にも入れるので、着陸の数分前の知らせ（6時間に1回）は出ない＝**1回だけ**
- 外への問い合わせ：塗装機が見えて行き先がふだんの実績から分からないときだけ。1日に数回の見込み

### 案3-A アライアンス塗装は海外の会社のものだけ知らせる
- 国内の会社（登録記号 JA）のアライアンス塗装は今までどおり知らせない。海外の会社のもの（G-YMMR など）は着陸の数分前の知らせと 案2-A の早めの知らせを出す
- 撮影の知らせ（spot_push、撮る人用担当のコード）はアライアンス塗装を出さないので、アライアンス塗装のときは撮影の知らせを選んでいる人にも空港の知らせを送るようにした（前は撮影の知らせに任せて送っていなかった）
- odpt-status の「〇〇で運航いたします」の予定（国内の会社の名前だけ）はそのまま。livery_extra も読まない（国内の会社の塗装はコードの一覧にある）
