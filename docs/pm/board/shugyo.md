# 修行モード担当の帳面（チェックイン担当の下、11/6 新設）

## 持ち場
- 修行モードの画面とロジック（src/・web/ のうち修行の部分）：ホームの修行のカード（renderShugyoCard）、修行のタブ、フライトの見方「修行」、成績の「修行のまとめ」、計画を作る（自動・手動）、運賃の選び方、案をくらべる、年末までの道のり、実績の確認
- 計算のルールは Project の文書「修行の計算ルール（2026年10月に確認）」が正
- 触らないもの：ホーム・運用・マイページ・下のタブ帯・共通の見た目（CSS の共通部品）はチェックイン担当。変えたいときはチェックイン担当の帳面の「下の担当からの依頼」に書く
- 表・移行・RLS・時刻表の取り込み（timetable-sync）はデータ担当。経営のコードには触らない
- 関数と画面の一覧は docs/pm/report-shugyo-inventory.md（PR #26）

## 守る決定
- 実績・予定・計画は必ず分ける（実績＝記録した便だけ・黒、予定＝うすい金色、計画＝うすい青）。同じ数字・棒・グラフにまぜない。予定や計画からの結論は「推定」の一文で
- 金額の表示は最小限のまま（11/4 本人の決定。SG_MONEY で隠している。便の記録の金額の入力は残す）
- 運賃は利用者の入力だけ。ANA・JAL の運賃表は許可が出るまで入れない。さくらトラベルは使わない
- 乗り継ぎは JAL・ANA の決まりの時間より短い便を組まない

## ブランチの名前
- リモートに古い `shugyo` ブランチ（10/21）があるので、`shugyo/<名前>` は push できない（ref がぶつかる）。`shugyo-<名前>` で作る
