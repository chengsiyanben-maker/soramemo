# 担当の引き継ぎ帳（PM が管理）

このブランチ pm/board は、担当ごとの「引き継ぎ帳」を置く場所です。アプリのコードは入れません。main にも入れません。

- 担当は6つ：checkin（チェックイン）・keiei（経営ゲーム）・data（データ）・design（デザイン）・kaizen（改善）・ads（広告）
- チェックインの下に3つ：shugyo（修行モード）・satsuei（撮る人用）・yosoku（運用予想）
- 各担当は、仕事の始めに自分の帳面 `docs/pm/board/<担当>.md` を読み、終わりに書き足して、このブランチに push する
- 帳面に書くこと：いま持っている仕事・使っているブランチ・本人や PM の決定・次にやること・ほかの担当への依頼
- PM からの新しい指示は、各担当の決まった作業（スケジュール済みタスク）を動かすときに一緒に渡す
