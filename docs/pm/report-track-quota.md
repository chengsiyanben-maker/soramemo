## 作ったもの（src/index.html）
- `airport_tracks` を読むとき、ログインしているときはログインの鍵（session の access_token）を Authorization に付ける。ログインしていない・デモは今までどおり anon の鍵
- `cold-tracks`（400日より前）にも同じ鍵。401 は login_required、429 は rate_limited（返り値の retry_after_min か Retry-After から分）として扱う
- 返り値が配列でないとき：login_required は「8日より前の空の道すじはログインすると見られます。」、rate_limited は「たくさん読んだので、○分ほどあとでまた見られます。」を、空の道の日付の下に小さな注の字（fwnote）で1行。読めなかった結果は覚えず、次に開いたとき読み直す
- ログインしていない人・デモは、日付の選び方を今日と前の7日まで（◀ と日付の欄の下限）。7日前の端まで来たときだけ、同じ「ログインすると見られます」の1行を出す（◀ が押せないわけが分かるように）
- 「あの日の空」（乗った日・はじめての空港の日）で8日より前の日を開いたときも、航跡がない行の文をその一文にした
- 空の道の下の注「記録を始めた2026年10月18日から、どの日でも見られます」に「（8日より前はログインした人だけ）」を足した
- 変えた関数：loadArt・renderArt・renderThatDay（足した：ART_FREE_DAYS・artLoggedIn・artMinDay・artToken・artErrOf・artErrText）。rpcPost は変えていない（ほかの読み出しはそのまま）
- テストの偽のサーバー tests/e2e/fake_sb.js のログインに access_token を足した（ほかのテストには影響なし）
