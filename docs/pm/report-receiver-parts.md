# 報告：受信機の機材の案と置き場所（受信機担当・11/6）

## 作ったもの
- docs/pm/receiver-parts.md：受信機1台に要るもの、機材の3案（窓際で試す・屋外アンテナ・手持ちのパソコン）、アンテナの置き場所の比べ（屋根・ベランダ・窓際）、ケーブルの損失、送り先（adsb.lol・Flightradar24）の条件

## 確かめた結果
- 値段はお店のページを 2026-11-06 に開いて確かめた（Raspberry Pi 4 2GB ¥14,630 在庫あり、Pro Stick Plus £52.50 在庫あり／US$45.99 売り切れ、AirNav の装置＋屋外アンテナのセット US$99.95 など）。国内の通販（Amazon.co.jp など）はページを開けず未確認
- Raspberry Pi 5 は値上がりと売り切れが多く、Pi 4 2GB がいちばん手ごろ
- 地球の丸みは問題にならず、低い高度を取れるかは周りの建物とアンテナの高さで決まる
- ケーブルは 10m 以内（5D-FB で約2.3dB）を目安
- adsb.lol は「将来 API に鍵が要り、送っている人はもらえる」と書いている → 目的1に合う
- Flightradar24 は、ほかにも送るなら MLAT を切るように書いている → 手順に入れる
- 帳面・文書に住所・座標・識別番号は書いていない（grep で確かめた）

## 本人に決めてほしいこと
1. アンテナを置ける場所：屋根（屋上）・ベランダ・窓際のどれか。ベランダならどちら向きか（南西＝羽田、東＝成田）。細かい場所はここに書かず、向きだけ教えてほしい
2. 機材の案：案B（屋外アンテナ・約3.5万円＋送料）でよいか。まず案A（窓際・約3万円）で試すか
3. パソコン：Raspberry Pi 4 2GB を買うか、家のパソコンで動かすか（案C）
