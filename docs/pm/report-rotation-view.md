## 今の画面で読みにくかった所（要点）
1. 飛んだ便と予想の便が同じ形の灰色の札で、境目がない。予想の割合「64%」が何の割合か分からない
2. 運用の特別塗装機で開くと「いまの便」が古い（一覧では JAL599 で飛んでいるのに「いまの便：JL148」で、予想の1便目が今飛んでいる JL599）。別の時刻には機体の1日でも、飛行中の JL599 が予想の1便目にもう1回出た
3. 運用の特別塗装機の「この先の便（推定）」のピルがカードの右からはみ出す
4. 予想が出ないとき機体の1日では何も書かない
5. 特別塗装機のくわしくには予想が出ない。「これから飛ぶ予定」は出発済みの便と、これからの便が混ざり、並びも時刻順でない
6. 機体の1日の地図の名札が重なる（広島・高松）
