## 作ったもの
docs/design/near-airfields/ に7枚（index.html が一覧。png/ に 844（2倍）と 667）。

- 01 今のホーム：main の web/ をデモで開いて撮った3つ（判定範囲の外で何も出ない／5km 以内だけ半券の中に1行／飛行場の中でも見出しが「いちばん近い空港」）
- 02 判定範囲の外・近くに飛行場（牛久のあたり。成田 30.5km）：半券の下に「近くの飛行場」のカード。行は「種類の札・名前・距離・›」。20km 以内を近い順に2つまで。押すとその飛行場の図鑑のページ。地図に民間空港より小さい印（白抜きの丸と名前）。霞ヶ浦駐屯地（基地 7.7km）は出さない
- 03 飛行場の判定範囲の中（竜ヶ崎飛行場）：半券はその飛行場。見出しを「判定範囲の中の飛行場」にし、名前の横に種類の札。パタパタは出さない。カードは「近くの飛行場と空港」で、次に近い飛行場と、いちばん近い民間空港（札「空港」）
- 04 近くに出せる飛行場がない（東京駅。羽田 14.7km）：カードごと出さない。今と同じ見た目
- 05 ホームの鉛筆のシート：見方の設定2版（案A）の「ホームに出すもの」に「近くの飛行場」を半券の次に1行（はじめ ON）。05b は OFF にしたとき（カードも地図の印も消える）
- 夜：02 の夜。距離の数字だけ緑に光らせ、札は色なし、地図の印は薄いグレー

決めた形
- いちばん近い民間空港は今のまま主。パタパタも民間空港のまま（案内板風は2か所だけの決まり）
- 半券の中の「近くに○○（飛行場・3.3km）」の1行（今の5km の決まり）はやめて、カードに移す
- 高さ700未満の画面（667）はカードを1行に詰める（見出しを外し、1行目に「ほか1つ」の札）。地図の飛行場の印は名前を出さず点だけ（成田の名前とぶつかるため）
- 測った値（幅390・844）：13px 未満 0（単位の 12px を除く）・44px 未満 0・はみ出し 0・切れ 0

作り方：make/capture.py（web/ を http://localhost:8765/ で開き、デモに入って位置を入れ、ホームの地図だけを撮る）→ make/make_near.py → make/shoot.py <フォルダの絶対パス>

## 迷った点
- 地図の高さ：カードを足すと 844 で地図が約 140px 狭くなる（約500→約250px の見える所）。667 は詰めても地図は約120px。シートを引き上げたときに3つ目まで出す形も考えたが、今回は描いていない
- 03 で民間空港を「近く」のカードに入れたのは、飛行場の中にいるとパタパタも民間空港も見えなくなるため。カードの名前が場面で変わるのは迷った
- 指示にあったヘリポートは、今の番外編のデータ（XA）に種類がない（基地・滑空場・飛行場・秘境の4つ）。画面は「飛行場・滑空場」の札だけで描いた

## 本人に決めてほしいこと
1. 基地（自衛隊の飛行場）と秘境（一般の人が行けない飛行場）を「近くの飛行場」に出すか。おすすめ：出さない（今の nearest と同じ）
2. 距離は 20km・数は2つまで（低い画面は1つ）でよいか
3. 飛行場の判定範囲の中のとき、いちばん近い民間空港をカードに入れるか（03）。おすすめ：入れる
4. ヘリポートを入れるか。入れるなら番外編のデータに足すところから（データ担当・出典と利用条件の確認から）
