## 投稿1　11月10日（火）20:00　フィード（カルーセル5枚）

**画像**：`post1-1.png`〜`post1-5.png`

| 枚 | 見出し | 見せるもの |
|---|---|---|
| 1 | 空港に着いたら、印を押そう。 | 航空図風の地図と、丸い印（HND）。「アーリーアクセス中」のピル |
| 2 | 空港の円の中で「チェックイン」 | ホームの再現：判定範囲の円、いちばん近い空港のコード（パタパタ）と、引いて切るチェックインの券 |
| 3 | 国内86の空港と、羽田・成田の各ターミナル。 | 図鑑の再現：行った空港 16/86、地方ごとのマス。離島は金色の印 |
| 4 | 出発と到着で押すと、フライトが地図に残る。 | フライトの再現：フライト・路線・km の数字と、OKA → ISG のカード |
| 5 | 次の空港で、最初の印を。 | まとめ。プロフィールのリンクから登録／非公式アプリであること |

**本文**

```
空港に着いたら、印を押そう。

そらメモは、空港にチェックインして印を集めるアプリです。
個人で作っている非公式アプリで、いまアーリーアクセス中です。

・空港の円の中で「チェックイン」を押すと、その空港の印
・国内86の空港と、羽田・成田は各ターミナルにも印
・出発と到着の空港で押すと、そのあいだのフライトを記録（24時間以内なら乗り継ぎでも）
・集めた印は図鑑に、飛んだ路線は地図に

位置情報は、空港にいるかの判定にだけ使います。

登録はプロフィールのリンク（soramemo.jp）から。
次の旅で、最初の印を押してみてください。

※そらメモは非公式アプリです。航空会社・空港の公式アプリではありません。
※画像の画面は見本で、数字は実際の記録ではありません。

#そらメモ #空港 #空港巡り #空港めぐり #飛行機好き #飛行機旅 #スタンプラリー #位置情報ゲーム #国内旅行 #旅の記録 #離島旅
```

**投稿のとき**
- 代替テキスト（詳しい設定）に「空港チェックインアプリ そらメモの画面の見本」と入れる
- 位置情報のタグは付けない（特定の空港の公式の投稿と思われないように）

## 投稿3　11月14日（土）10:00　フィード（カルーセル5枚）

**画像**：`post3-1.png`〜`post3-5.png`

| 枚 | 見出し | 見せるもの |
|---|---|---|
| 1 | 乗った区間だけが、あなたの会社の路線になる。 | 紺の地に、空港を結ぶ点線（路線の絵） |
| 2 | 実際に飛んだ区間が、自社路線に。 | 自社路線の一覧の再現（新千歳⇄那覇 など、1日の収益）。乗っていない区間は路線にできない |
| 3 | 会社の機体は、自分が乗った機体から。 | 機体の画面の再現（持っている／買う、登録記号は `JA＊＊＊＊` と伏せる） |
| 4 | 本物の空の1日で、収益が上下する。 | 会社のカードの再現（資金・1日の収益・維持費・実際の空 −8%） |
| 5 | 印を集めた旅が、そのまま会社の歴史になる。 | まとめ。ホームの上の「エアライン経営」から始める／非公式アプリであること |

**本文**

```
乗った区間だけが、あなたの会社の路線になる。

空港スタンプラリーのアプリ「そらメモ」には、印集めとは別に「エアライン経営」があります。

・路線になるのは、自分が実際に飛んだ区間だけ
・会社の機体は、自分が乗った機体から（便名を入れたフライトから登録記号が分かります。分からないときは、時刻表の機種で代わりの機体を1機）
・前の日の実際の便の数と欠航で、国内線の収益が最大±20%上下します

旅に出るほど、路線と機体が増えていきます。
ホームの上の「エアライン経営」から始められます。

飛行機好きの友だちに送ってみてください。

登録はプロフィールのリンク（soramemo.jp）から。

※そらメモは非公式アプリです。航空会社・空港の公式アプリではありません。航空会社の名前は、乗った便の記録としてだけ表示します。
※画像の画面は見本で、数字・会社名は実際の記録ではありません。

#そらメモ #エアライン経営 #経営ゲーム #飛行機好き #空港
```

**投稿のとき**
- 1枚目だけ見た人にも伝わるよう、1枚目の見出しはそのまま本文の1行目にした
- コメントで「どうやって機体を買うの？」などと聞かれたら、今の画面どおりに答える（最初の1機は半額、など）。まだない機能は「今はありません」と答える
