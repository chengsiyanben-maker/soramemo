# リールの台本（週1本）

11/12 本人「リールもジャンジャン出そう」で、リールの上限はなくなった。まずは週1本（金曜 20:00 が基本）。日付は [plan-4weeks.md](plan-4weeks.md) が正。

## どのリールにも共通の撮り方

- **本番（soramemo.jp）を「デモで試す」で開いて画面収録する**（入り方は [shoot-guide.md](shoot-guide.md)）。デモは「いる空港（デモ）」を選べるので、家にいても旅先の空港として撮れて、自宅の近くの空港が映らない。本人の記録も映らない
  - 前の決まり（11/5）は「本人の画面収録は旅先の空港で」。デモで撮るのはその代わりの案なので、本人に決めてもらう（報告の「決めてほしいこと」）。旅先で撮れたときは本物の記録で撮ってもよい
- 上の「デモモード中」の帯は、Instagram の編集で上を少し切るか、帯の上に文字を置いて隠す。キャプションには「画面はデモ」と書く
- 収録の前に：おやすみモード／通知を切る／画面の明るさを最大／縦向き固定
- 指はゆっくり。1つの画面で2〜3秒止める（字を読む間）
- 文字は Instagram の編集で足す。音は Instagram の中の音源から選ぶ（外の音源は使わない）
- 画面の文字の最後に、どのリールも「非公式アプリ」を2秒以上
- 「フィードにも表示」をオン。位置情報のタグは付けない
- ロゴ・制服・他人の写真は映さない。外の景色を足すなら、ロゴ・人の顔が映らないところだけ（足さなくてよい）

## リールA　修行の道のり（20秒）　11/15（日）10:00

ねらい：修行のカルーセル（11/13）を見なかった人にも、動きで「今年の道のりが一目で分かる」を届ける。

**撮り方**：デモで修行タブを開く。デモには見本の便が入っているので、道のりの数字が出る（11/12 に main で見た値：クリスタルまで 14,116 FOP・あと 15,884 FOP／あと16回）

| 秒 | 映すもの | 画面に足す文字 |
|---|---|---|
| 0〜3 | 下のタブ帯の「修行」を押す → 道のりの1枚。大きな数字 | 今年の修行、どこまで来た？ |
| 3〜7 | 「あと ○」の2つの箱にゆっくり寄る（指で少し下へ） | あと何ポイント／あと何回 |
| 7〜12 | 見方の帯で「1便ごと」→ 1便を押して内訳 | 1便ずつ、数え方まで |
| 12〜16 | 見方の帯で「月ごと」→ 12月31日の残り（推定） | 年末までの残り（推定） |
| 16〜20 | 「入れたら届くか」で予定の便を入れる → 届くかの一文 | 予定を入れて、届くかを推定／非公式アプリ・プロフィールのリンクから |

**本文**

```
今年の修行、どこまで来た？

そらメモの「修行」タブは、記録した便から今年の道のりを数えます。
・今のポイントと「あと何ポイント／あと何回」
・1便ずつの数え方（区間マイル × 積算率 × 2 ＋ 搭乗ボーナス）
・12月31日までの残り（推定）
・予定の便を入れると、届くかを推定

ポイントは各社の公開情報（2026年10月に確認）からの目安で、キャンペーンのボーナスは含みません。届くことを保証するものではありません。

登録はプロフィールのリンク（soramemo.jp）から。

※そらメモは個人で作っている非公式アプリです。航空会社の公式アプリではありません。
※画面はデモで、数字は見本です。

#そらメモ #修行 #ステイタス修行 #マイル修行 #飛行機好き #飛行機旅 #搭乗記録 #フライトログ
```

- 届くかの字は必ず「推定」が映るように。「届く」と言い切る文字を足さない
- 制度の名前（JGC・Life Status など）は、アプリの画面に出ている名前どおり。制度の解説はしない
- 表紙：道のりの1枚の大きな数字のところ（Instagram で動画の中から選ぶ）。または `images/png/shugyo-1.png`

## リールC　エアライン経営（20〜25秒）　11/27（金）20:00

ねらい：経営を知らない人に「乗った区間が路線になる」を動きで見せる。11/14 の投稿3の続き。

**撮り方**：デモでホームの上の切り替えを「エアライン経営」にする。下のタブ帯が 会社・路線・機体・守り神 に変わる

| 秒 | 映すもの | 画面に足す文字 |
|---|---|---|
| 0〜3 | 上の切り替え「スタンプラリー」→「エアライン経営」 | 乗った区間で、会社を作る |
| 3〜8 | 「路線」タブ：自社路線の一覧 | 実際に飛んだ区間だけが路線に |
| 8〜13 | 「機体」タブ：持っている／買う | 機体は、自分が乗った機体から |
| 13〜18 | 「会社」タブ：「収益を受け取る」を押す | 本物の空の1日で、収益が上下 |
| 18〜22 | 会社のカードで止める | 旅に出るほど、路線が増える／非公式アプリ |

**本文**

```
乗った区間で、会社を作る。

そらメモの「エアライン経営」は、自分が実際に飛んだ区間だけが会社の路線になるゲームです。
・機体は、自分が乗った機体から
・前の日の実際の便の数と欠航で、収益が上下します

登録はプロフィールのリンク（soramemo.jp）から。

※そらメモは個人で作っている非公式アプリです。航空会社の公式アプリではありません。
※画面はデモで、数字は見本です。

#そらメモ #エアライン経営 #経営ゲーム #飛行機好き #飛行機旅 #空港 #旅の記録
```

- 撮る前に本番で、機体の画面に「見た機体」「小型機」があるか見る。あれば「乗った機体と、見た機体から」と文字を直してよい（経営の新しい形はスイッチで出し分けているので、本番で出ているものだけを書く）
- 会社名・数字はデモの見本。実在の航空会社の名前を会社名にしない

**撮り方**：デモでいくつかの空港でチェックインしてから（いる空港を変えて押す）図鑑を開く
