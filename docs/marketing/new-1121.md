## 11/29（日）10:00　リールK「空港をピン止めして、知らせを選ぶ」（15〜18秒）

表紙：`images/png/reelK-cover.png`（ピン止めのシート。時間に関係ない画面なのでこのまま使える）

**撮り方**：デモで、昼の便が多い時間に（夜は運用のカードが「—」ばかりになる。11/21 1時半に確かめた）。デモでは知らせは届かないので、通知は映さない

**台本**

| 秒 | 映すもの | 画面に足す文字 |
|---|---|---|
| 0〜3 | ホームのシートの「ピン止め」を押す | よく行く空港を、ピン止め |
| 3〜7 | 「何を知らせますか」のスイッチを1つ ON → 完了 | 知らせを選ぶ（推定） |
| 7〜10 | ホームの「ピン止めした空港」の行 | ホームからすぐ |
| 10〜14 | 運用タブのカードの一覧 → 地図のカードを押して専用ページ | 運用はカード。押すと専用ページ |
| 14〜17 | 表紙 | 非公式アプリ・知らせは推定 |

**本文**

```
よく行く空港を、ピン止め。

空港スタンプラリーのアプリ「そらメモ」で、空港をピン止めできるようになりました。
・空港のページかホームの「ピン止め」から。ホームに「ピン止めした空港」が出ます
・その空港の何を知らせるか（特別塗装機・遅れや欠航など）をスイッチで選べます
・運用タブはカードの一覧に。地図のカードには、いま飛んでいる機体の印。押すとその空港の専用ページが開きます

知らせは機体の位置（adsb.lol・ODbL）と運航情報（公共交通オープンデータセンター）からの推定で、届くことを保証しません。iPhone はホーム画面に追加したそらメモで使えます。
個人で作っている非公式アプリです。
いつも同じ空港で撮っている仲間に送ってみてください。

#空港 #羽田 #飛行機撮影 #ヒコーキ #特別塗装機
```
