本文：
```
特別塗装機、次はどこを飛ぶ？

撮影の予定を一緒に立てる人に送ってみてください。

#特別塗装機 #飛行機撮影 #空港 #そらメモ #非公式アプリ

## 4. リールG 遅れたら、1件だけ届く　11/28（土）19:00

送る相手：一緒に旅行する人・迎えに来てくれる人（「遅れたら教えて」と言う相手）

**版a（本物の通知が撮れたとき）**：本人が実際に乗る便で「この便に乗る」を押し、遅れて通知が届いたら画面収録。届いた通知は本物のまま使う（作った通知の画像は使わない）。便名・時刻が映ってよいかは本人が決める。自宅に近い空港が映らないように（11/5 の決まり）

| 秒 | 画面 | 画面の文字 |
|---|---|---|
| 0〜2 | ロック画面に「そらメモ：便名」の通知 | 乗る便が遅れたら |
| 2〜6 | 通知を押す → そらメモが開く（運用タブ） | 押すとそのまま開く |
| 6〜10 | 同じ通知が【更新】で上書きされたところ（撮れたら） | あとから分かったことは同じ通知に |
| 10〜15 | 終わりの1枚 | 15分の遅れから（推定）／そらメモ（非公式アプリ） |

**版b（通知が撮れなかったとき）**：本番のデモで、乗る便のカードの「この便に乗る」→ 出る文「遅れたり、ほかの空港へ向かったりしたら、この端末に通知します（推定）」まで。通知そのものは映さず、字幕の1枚で「出発・到着・運航情報が出ても、1つの便は1件」と説明する（デモで「この便に乗る」まで出るかは撮る前に確かめる。出なければ本人の端末の画面収録）

本文：
```
乗る便が遅れたら、通知は1件だけ。
空港で印を集めるそらメモ（非公式アプリ）の遅れの通知を、1つの便につき1件にまとめました。

「この便に乗る」で選んだ便が15分以上遅れたら、この端末に知らせます。欠航・ダイバート・引き返しも。
出発の遅れ・到着の遅れ・航空会社の運航情報があとから出ても、同じ通知を【更新】で上書きします。

遅れの分は推定を含み、届くことや時刻を保証するものではありません。iPhone はホーム画面に追加したそらメモで使えます。
迎えに来てくれる人に送ってみてください。
アプリはプロフィールのリンクから（soramemo.jp）

#空港 #飛行機 #遅延 #そらメモ #非公式アプリ
```

トライアルの冒頭（11/28 14:00 に版2・版3）：版1「乗る便が遅れたら、通知は1件だけ」／版2「迎えの人に送って。遅れたら届く」／版3「遅れの通知、何回来てた？」

## 5. 12/5（土）10:00 フィード：年末年始の移動の前に（カルーセル6枚）

本文：
```
年末年始、空港へ行く前に。
空港スタンプラリーのそらメモ（非公式アプリ）でできることを5枚にまとめました。

・出発と到着の空港で押すだけ。乗り継ぎは24時間以内
・電波がなくても、つながったら送ります（24時間以内のもの）
・「この便に乗る」で選んだ便が15分以上遅れたら通知（1つの便につき1件）

遅れ・止まり具合は推定や公開情報で、運航の判断には使えません。航空会社の案内を確かめてください。
帰省や旅行に一緒に行く人に送ってみてください。

#空港 #帰省 #年末年始 #空港スタンプラリー #非公式アプリ
