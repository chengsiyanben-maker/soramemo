## 投稿6　11月21日（土）10:00　フィード（カルーセル5枚）

**画像**：`post6-1.png`〜`post6-5.png`

| 枚 | 見出し | 見せるもの |
|---|---|---|
| 1 | 乗った便を、見返せる形で残す。 | 4つの残し方の目次 |
| 2 | 2つの空港でチェックインするだけ。 | 出発と到着の判定範囲と、そのあいだの点線。電波がないときは保留して、あとで送る（24時間以内） |
| 3 | フライトを押して、航空会社と便名を。 | 便を記録する画面の再現（便名は任意・`＊＊＊` と伏せる） |
| 4 | バーコードを読むと、便名と座席が付く。 | 読み取りの枠。スクリーンショットからも読める。名前と予約番号は保存しない |
| 5 | 飛んだ路線を、1枚の地図に。 | 共有画像の地図の再現。写真に印を押せる（写真は端末の中だけで処理）／非公式アプリ |

**本文**

```
乗った便を、見返せる形で残す。

搭乗記録・フライトログをつけたい人へ。そらメモのフライトの残し方を4つまとめました。旅の前に保存しておくと便利です。

1. 出発と到着の空港でチェックインするだけで、あいだのフライトを記録（24時間以内なら乗り継ぎでも）。電波がないときは端末に保留して、つながったら送ります
2. フライトを押すと、乗った航空会社と便名を記録できます（便名は任意）
3. 搭乗券のバーコードを読むと、便名・航空会社・座席が付きます。スクリーンショットからも読めます。名前と予約番号は保存しません
4. 飛んだ路線を1枚の地図にして共有。撮った写真に、その空港の印を押すこともできます（写真は端末の中だけで処理します）

旅の前に、一緒に乗る人にも送っておくと便利です。

登録はプロフィールのリンク（soramemo.jp）から。

※そらメモは非公式アプリです。航空会社・空港の公式アプリではありません。航空会社の名前は、乗った便の記録としてだけ表示します。
※画像の画面は見本で、数字・便名は実際の記録ではありません。

#そらメモ #空港 #フライトログ #搭乗記録 #飛行機好き
```
