# 投稿の前に見る決まり

毎回、投稿する前にこの表を上から確かめる。

## かならず入れる
- 「非公式アプリ」の文字（本文と画像の両方。画像は全部の枚の下に入れてある）
- 画面の見本を使うときは「画面は見本」「数字は見本」
- 「予想」「推定」「目安」が出てくる機能に触れるときは「当たることを保証するものではありません」

## 書かない・使わない
- 「無料」「公式」「提携」の言葉
- 有料プラン（そらメモ＋）の話。課金で有利になる、と読める書き方
- 航空会社のロゴ・会社の色を主役にした絵・制服・機体のデザイン、空港の公式キャラ
- 航空会社名をハッシュタグや見出しに使うこと（会社名は「乗った便の記録」として本文で触れるだけ）
- ほかの人が撮った写真・動画（自分で撮るときも、ロゴや制服、人の顔が大きく映らないようにする）
- ほかのアカウントの投稿の見た目・文面のまね
- まだ本番にない機能を、できているように書くこと（新規登録の新しい画面は、本番に入るまで紹介しない）

## 売りにしない（触れない）
天気の印／運用（北風運用など）のバッジ／窓側の席ガイド／空のカレンダー／今日のお題／季節のスタンプ／案内板風の全体デザイン／新造機の製造の進み具合／航空ニュース

※ 今のアプリの印には「春の訪問」のような季節の札が付くことがあるが、画像や文面では見せない。

## 登録が一度に集まりすぎないように
- ログインのコードのメールには1日の上限がある（`plans/そらメモ_新規登録の準備（11-04）.md` では Gmail で1日およそ500通、計画は1日100人ずつ）
- リンクを強く押し出す投稿（ストーリーズのリンクのスタンプなど）は、1日に1回まで
- 1日の登録が80人を超えた日は、その日のうちはリンクのスタンプを足さない
