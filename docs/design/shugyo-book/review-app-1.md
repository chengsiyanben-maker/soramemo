## 指摘（効き目の大きい順）

### 1. 車などにした便が数えられてしまう（大）
- 何が：道のりのいちばん下に「車などの移動は便ではないので数えません」とあるが、sgYear が使う statusRows は S.flights を全部入れる。フライトの作り直し（feat/flight-book）の「車などの移動」で ANA の便を車などにしても、statusSummary の数は変わらなかった（前も後も同じ。flight-book のブランチで試した）。このブランチにはまだ車などの印（isCar）がない
- なぜ：2つが main に入ると、フライトでは便から消えた移動が、修行の FOP・PP と回数、JGC の＋5 に入る。画面の一文と食い違う
- どう直す：statusRows で isCar(f) の便を飛ばす（フライトの指摘1と同じ1か所）。後から main に入れるほうが取り込むときに直し、t125 に「車などにした便は入らない」を足す

### 2. 道のりの大きな数字が、全部推定の運賃でも「実績」とだけ出る（中）
- 何が：デモでは14便すべて運賃が分からない（推定の運賃で数えた）のに、大きな数字の札は「実績」、1便ごとの行は「JAL・セイバー」とだけ
- なぜ：1便の内訳を開くまで、運賃を推定していることが分からない。本当の運賃が違うと数字は変わる
- どう直す：大きな数字の下に「運賃を推定した便 14」（押すと1便ごとへ）。1便ごとの行は「セイバー（推定）」

### 3. 667 で2つの道の箱が見えない（小）

### 4. 13px より小さい字がある（小）
