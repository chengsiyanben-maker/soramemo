## 指摘（効き目の大きい順）

### 1. E1j の「そのあとの便 100」が、記録した便ぜんぶと同じ数（効き目：中）
- 画面・場所：E1j の JGC の行「入れた数 1,240 ＋ そのあとの便 100」→ 1,340
- 何が良くないか：E1 では記録した20便ぜんぶで 100。E1j も「そのあとの便」が 100 なので、今年の便がぜんぶ入れた日のあと＝入れた数 1,240 に今年の便が入っていない、という珍しい場合になる。ふつうは今日の数を入れるので、入れた数にはもう今年の便が入っている
- なぜ：作る人も見る人も「1,240 に記録した便を足している＝二重に数えている」と読みやすい。メモには「入れた日より前の記録は二重に数えない」とあるが、画面からは分からない
- どう直すとよいか：入れた日を出す（「10/1 に入れた 1,240 ＋ そのあとの便 6便 30」のように）。見本は入れた日のあとの便だけの数にする

### 2. 月ごとの年末の残りで「回数 あと」と数が2行に分かれる（効き目：中）
- 画面・場所：E3・N3 のいちばん上のカード、3行の右「回数 あと／10」「回数 あと／8」「回数 あと／2」
- 何が良くないか：「回数 あと」で折れて、数だけが次の行の右端に1つ浮く。FOP の大きな数の行と高さがずれ、どの数がどの行のものか追いにくい
- なぜ：数字は大きく太く、補足は小さく、の決まりの形が崩れて見える。回数の道は review-2 の4で足したもので、ここがいちばん読みにくい
- どう直すとよいか：左の補足の下に「回数 あと 10回」を1行で出すか、カードの上に「FOP｜回数」の小さい見出しを置いて数だけを2列で並べる

### 3. 見方を選ぶで JGC が OFF なのに、後ろの道のりに JGC が出ている（効き目：小）
- 画面・場所：07 見方を選ぶ（「JGC（Life Status）生涯 1,500 まで」が OFF）と、その後ろの E1
- 何が良くないか：OFF にしたものが後ろで見えている。はじめから ON か OFF かも分からない
- どう直すとよいか：見本では JGC を ON にする（または後ろの E1 から JGC の行を外す）。はじめの値（JAL を選んだ人は ON など）をメモに書く

### 4. JGC の札「推定」が、数え方の意味と少しずれる（効き目：小）
- 画面・場所：E1・N1・E1b の JGC の行の札「推定」
- 何が良くないか：100 は記録した便を数えた数で、見込みではない。足りないのは前の年や JAL カードの分で、本当の数はこれより多い
- どう直すとよいか：札を「記録分」にするか、「推定」のままなら数の横に「以上」を付ける（「100 以上」）。予想・推定の札の使い方は運用や経営と同じ意味でそろえる

### 5. 夜の月ごとで、予定と計画のカードの縁がほかのカードとほとんど同じ（効き目：小）
- 画面・場所：N3 の「11月 予定」（点線の縁）と「12月 計画」（細い実線の縁）
- 何が良くないか：夜はふつうの月のカードにも薄い縁があるので、計画のカードは字の「計画」を読まないと分からない
- どう直すとよいか：今のままでも字の札で読めるので急がない。夜の画面を作るとき、計画の縁を少し明るくするか、地を1段明るくする（色は増やさない）
