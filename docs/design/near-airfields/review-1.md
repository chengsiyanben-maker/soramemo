# 近くの空港に飛行場も（design/near-airfields・a589ac2）への指摘 1回目（改善担当）

見たもの：png/ の 02〜05b と夜（844 と 667）、01 の今の3枚、report-near-airfields.md、make/make_near.py。
html を幅390・高さ844／667 で開き直して測った（13px 未満は単位12pxだけ・はみ出し0・枠の中の切れ0）。
距離は src/index.html の番外編（EXTRA_RAW）から計算し直し、牛久 11.3／15.3km・竜ヶ崎から大利根 5.2km・東京駅で20km 以内の飛行場なしは合っている。

## 良い点（直さなくてよい）
- いちばん近い民間空港を主のまま、パタパタも民間空港だけ。案内板風の決まりを守っている
- 20km 以内がないときはカードごと出さない（04）。今の見た目に戻るだけで迷わない
- 行が「種類の札・名前・大きい距離・›」の1形で、押す所が行ぜんぶ（高さ48）。基地を出さないのは今の nearest と同じ
- 半券の中の押せない1行（今の 5km の案内）をやめてカードに移したのはよい
- 夜は札を色なしにし、光る色は緑だけ

## 指摘（効き目の大きい順）

### 1. 「空港」と「飛行場」の言葉がぶつかる（大）
- 場所：02・03 の半券の見出し「いちばん近い空港」とカードの札
- 何が：番外編の飛行場（field）30のうち12は名前が「〜空港」（八尾・岡南・福井・礼文・波照間・笠岡ふれあい空港など）。大阪駅では半券が「いちばん近い空港 伊丹 10.6km」で、下に「［飛行場］八尾空港 15.3km」が出る。牛久でも、半券は 30.5km の成田なのに 11.3km の竜ヶ崎が下にあり、「いちばん近い」が本当にいちばん近くない
- なぜ：分かりにくい。はじめての人は「空港」と「飛行場」の差（図鑑の 86 に入るか）を知らない
- どう直す：半券の見出しを「いちばん近い空港（86空港）」など図鑑の数と結ぶ言い方に、カードの見出しを「近くの番外編」か「図鑑の番外編から」に。名前が「空港」で終わる場所（八尾）の場面を1枚足して確かめる
- 効き目：大

### 2. 地図が狭くなり、場所によってシートが 141px 跳ねる（大）
- 場所：02・03（カードあり）と 04（なし）
- 何が：シートの上の端が 844 で 499px→358px、667 で 322px→262px。844 で地図の見える所は約500→約360px（上の段を除くと約300px）。車や電車で20km の境をまたぐたびにシートが上下し、地図の中心もずれる
- なぜ：決まり「ホームは地図とシート」の地図が主でなくなる。動く画面は読みにくい
- どう直す：開いたときの位置は高さに関係なくいつも1行（667 の形）にして、2つ目からはシートを引き上げた位置に。出たり消えたりするときは高さを変えずに行の中身だけ替える形も考える
- 効き目：大

### 3. 667 の「ほか1つ」が出ていない・03 の 667 で成田が消える（大）
- 場所：02・03・05 の 667
- 何が：報告は「1行目に『ほか1つ』の札」と書くが、png にも html にも出ていない（CSS の `.nr .o{display:none}` が高さの条件のあとにあり、上書きしている。測ると display:none）。03 の 667 は大利根だけで、報告が成田を入れた理由（飛行場の中ではパタパタも民間空港も見えない）が 667 では消える
- なぜ：決めてほしいこと2（2つまで・低い画面は1つ）が、実際の形を見ないまま決まってしまう
- どう直す：札を出して撮り直す。03 の 667 は空港の行を残すか、どちらを残すかを決める
- 効き目：大

### 4. 地図の飛行場の印が民間空港と同じ色・同じ形で、控えめでない（中）
- 場所：02 の地図（844）
- 何が：竜ヶ崎・大利根の印が成田と同じ紫の輪、名前も同じ太さ・同じ大きさ。今のアプリは番外編を飛行場＝緑（--field #3D7A4E）・滑空場＝空色（--glider）で描いている（図鑑の地図・共有画像）
- なぜ：PM の指示「民間空港より控えめ」と食い違う。図鑑と地図で同じ場所の色が違う
- どう直す：アプリの番外編の色の小さい点、名前は 13px・細め・薄い色に。カードの札の色もそろえる
- 効き目：中

### 5. 03 で同じ言葉が2回ずつ（中）
- 場所：03 の半券と地図
- 何が：「竜ヶ崎飛行場［飛行場］」、地図は「飛行場 竜ヶ崎飛行場」。見出し「判定範囲の中の飛行場」の下に「● 判定範囲の中」。半券の暗い所はパタパタがない分 約70px 空いている
- なぜ：読みにくい・情報がない所が大きい
- どう直す：名前に種類の語が入っているときは札を出さない（滑空場・「〜空港」の番外編だけ札）。見出しは「いま判定範囲の中」1つに。空いた所に図鑑の番外編の数（例：番外編 3/55）など1行
- 効き目：中
