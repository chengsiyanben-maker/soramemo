## 指摘（効き目の大きい順）

### 1. 667・740 で、引き上げても「すべて」と民間空港の行が帯の下（大）
- 場所：07b・02b の 667（740 も同じ）
- 何が：引き上げた直後に見える最後の物が、半分隠れた「すべて」の上の端か、薄い影にかかった小見出し。押したい「すべて」がタブ帯の下にある
- なぜ：はじめての人は「引き上げたのに続きが見えない」と感じ、送れることにも気づきにくい（下の影は合図として弱い。2も参照）。iPhone SE など 667 の人がいちばん困る
- どう直す：高さ 760 未満は一覧を1行＋「すべて 6つ ›」にする。または「すべて」を一覧の見出しの右（「20km 以内 6つ　すべて ›」）へ上げ、送らなくても押せるようにする。02b は「ほか1つ」なので、民間空港の行まで含めて帯の上に入る高さで描き直す
- 報告の「667 は帯の上に入る」は直して書く

### 2. 下の「送れる合図」が2本目のつまみに見える（中〜大）
- 場所：07b・02b・07d（844／667）。タブ帯のすぐ上の灰色の短い棒（.fade4 i）
- 何が：シートの上のつまみと同じ形の棒が、シートの下の端にもう1本ある
- なぜ：つまみ＝ここを持って動かす、と覚えた人は、下の棒も引けると思う。押しても何も起きないと壊れて見える。合図の意味（中を送れる）は伝わらない
- どう直す：棒をやめ、薄い影だけにする（または最後の行を半分だけ見せる高さにして、切れていることで送れると分からせる）

### 3. 「いまここ」が「地図：国土地理院」の札の下にもぐる（中）
- 場所：07 の 844（青い点の下半分）・09 の 667（点がほぼ全部隠れる）
- 何が：地図を寄せた結果、自分の位置の点が左下の出典の札に重なる
- なぜ：ホームでいちばん大事な「自分はどこか」が見えない。出典の札は動かせないので、地図の寄せ方の問題
- どう直す：地図を寄せるときの余白に、右のズーム（4版で足した60px）と同じく左下の出典の札の高さ（約30px）も足す

### 4. ピル「民間空港 ›」が種類の札に見える（中）
- 場所：09 川越（06b 八尾の近くも同じ形）
- 何が：半券の札「飛行場」の右に、同じ大きさの丸いピル「民間空港 ›」が並ぶ
- なぜ：「民間空港」は4版で札の言葉になったので、ピルが「この場所は民間空港でもある」や「民間空港だけに絞る」に読める。押すと一覧が開く、とは分かりにくい
- どう直す：「近くの民間空港 ›」か「民間空港を見る ›」と動きの分かる字にする

### 5. 引き上げた位置で、半券のピルが「ほか6つ ›」のまま（小〜中）

- 何が：一覧がもう開いているのに、ピルは「開く」の字のまま
- なぜ：押すと何が起きるか（閉じる？全部の一覧？）分からない。報告の迷った点にもある
- どう直す：引き上げた位置では「すべて 6つ ›」と同じ行き先にするか、ピルを「閉じる ⌄」にする。どちらかを画面案で決めて描く

### 6. 引き上げた地図に名前のない点が残る（小〜中）
- 場所：07b（844／667・夜も）右と左の青い点
- 何が：一覧を開いたときだけ点を出す形になったが、点に名前がなく、一覧のどの行かが分からない（右の点は端で切れている）
- どう直す：一覧の上の3つだけに番号（1・2・3）を振り、行の頭にも同じ番号。または点を出さず先頭だけにする

### 7. 03 の文が図鑑の題と合わない（小）
