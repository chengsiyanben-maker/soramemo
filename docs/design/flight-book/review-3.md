## 指摘（効き目の大きい順）

### 1. 座席を ON にすると、長い機種名で「そらメモ（非公式アプリ）」が折れる（効き目：大）
- 画面・場所：A2s2 画像で共有、券の下の行「B787-9・JA866J・25K席　そらメモ（非公式アプリ）」
- 何が良くないか：機種名を「B777-300ER・JA751A」にして撮ると、左が2行に折れ、右も「そらメモ（非公式アプ／リ）」と折れた。見本の B787-9 では1行に収まっているので気づきにくい
- なぜ：共有画像は外に出るもので、「非公式アプリ」は必ず読める形で出す決まり（広告・共有画像の案）。折れて「アプ／リ」になると読みにくく、券の形も崩れる
- どう直すとよいか：券の下を2行に分ける（1行目 機種・登録記号・座席、2行目 そらメモ（非公式アプリ）と関係ありませんの一文）。いちばん長い機種名（B777-300ER・A350-1000 など）と3けたの座席で撮った1枚を足す

### 2. 日誌が「続けて送る」のか「年ごとに切り替わる」のかが2通りに読める（効き目：中）
- 画面・場所：A1y（下へ送ると2025年に入り、上の年も変わる・下に「さらに送ると10月より前が続けて出ます」と「2024年へ」）と A1p（「年を選ぶと日誌・地図・年のまとめがその年に変わります」）
- 何が良くないか：A1y では日誌は年をまたいで1本につながっているのに、A1p は年ごとに中身が入れ替わる言い方。いちばん下の「2024年へ」は、2025年の10月より前がまだ続くのに2024年へ飛ぶボタンに読める
- なぜ：作る人がどちらで作るか決められず、使う人は「2025年を選んだら2026年の便は消えるのか」が分からない
- どう直すとよいか：日誌は1本につながる形にそろえ、年を選ぶ＝その年の頭へ飛ぶ、と A1p の文を直す（地図・年のまとめは年ごとに入れ替わる、と分けて書く）。「2024年へ」は2025年の終わり（1月の便のあと）に置くか、なくす

### 3. 「航路なし」「車など」「ほかの移動」の3つの名前（効き目：中）
- 画面・場所：R1（題「航路なし」・札「車など」・案2 の数字の下と月の見出し「ほかの移動 1」・地図の凡例「航路なし（点線）」）
- 何が良くないか：同じものに3つの名前がある
- なぜ：はじめての人は、月の見出しの「ほかの移動」と日誌の行の「車など」が同じものだと結びつけにくい
- どう直すとよいか：画面に出す名前を1つにする（札も見出しも「車など」に、または「ほかの移動」に）。「航路なし」は作る人の言葉としてだけ使う

### 4. 年の切り替えの場所が日誌と年のまとめで違う（効き目：小）
