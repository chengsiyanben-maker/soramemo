マイページを「タイル」に

ブランチ design/mypage-tiles・画面案だけ（アプリには入れない）。PM の指示 11/24 14時30分（アプリ全体の見直し A の4番）。390×844 と 375×667 で撮った。

両方の案で同じこと

  • 数字は車などを外して数える（デモで 30便・24,017km。見直し A の1番とそろえる）。頭の札から「○空港・○フライト」を外し、数はタイルへ
  • タイルは白い角丸カード＋薄い影。名前は小さい灰、数字は大きく太く、単位は小さい灰。右上に ›
  • 「知らせ」はタイルの名前だけにし、見出しと重ねない
  • 見出し「データ」を「データとバックアップ」にし、先頭に「記録はサーバーに保存・機種を変えても戻る・無料」の箱（文は PM が決める）
  • 補足の字の色は 4.5:1 以上（今の 2.5:1 の薄いグレーをやめる）。押す所はすべて 44 以上（JAL・ANA の切り替えと色の丸も）
  • エアライン経営の行は非表示中なので出していない
00 今タイルは成績1枚だけ・設定の行が縦に並ぶ低い画面（375×667）：png/00-now-667.png・全体：png/00-now-full.png
A1 案A：6枚のタイル＋設定はカードで並べる頭の下に2列×3（成績・図鑑・フライト・修行・運用・知らせ）。下に「表示の編集」（3つの小さいタイル）・「データとバックアップ」・表示と色・詳しい設定のカード。今の行は畳まずに並べる低い画面（375×667）：png/A1-tiles6-667.png・全体：png/A1-tiles6-full.png
B1 案B：成績を横長に＋設定は1枚の目次成績は横長の1枚に3つの数（空港・便・距離）と車などの1行。修行と知らせの2枚。タブにある画面はタイルにせず、外した画面だけ増える。設定は5行の目次で、押すと1枚のページ低い画面（375×667）：png/B1-wide-667.png・全体：png/B1-wide-full.png
B2 案B：目次から開いた「データとバックアップ」バックアップの説明を先頭の箱に。書き出しは「手元の控え」低い画面（375×667）：png/B2-data-667.png・全体：png/B2-data-full.png
