「いまの空港」の今日の便の一覧だけを、空港の出発・到着の時刻表のように列をそろえた案です。列は 定刻（変更後）・便名・行き先（経由）・機材・ゲート・状況。数字は等幅で大きく太く、パタパタは状況が変わったセルだけ（動きを減らす設定では字が変わるだけ）。便・機材・ゲートはすべて見本で、実在の今日の便ではありません。

決まりとの食い違い：デザインの原則「出発案内板風は近い空港のコードと最近の印だけ」と、却下済み「アプリ全体を出発案内板風にする案」に触れるため、PM が本人に確認中です。この画面案は本人の OK まで入れません。案A も紺の地は今日の便のカードの中だけにとどめ、上の頭・ピル・タブは今のままです。
