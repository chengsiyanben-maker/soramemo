# 夜の画面の色の決め方（チェックイン担当へ渡す形・1版）

本体は `tokens.css`。今の `src/index.html` の色の変数の上に重ねるだけで、画面ごとの CSS は書きかえない前提。

## つけ方
- 夜のとき `<html data-night="on">` を付ける。昼は外す（`data-palette` はそのまま残す）
- 夜になる条件：設定が「自動」で、いる場所の日の入り〜日の出のあいだ／設定が「いつも夜」。「いつも昼」なら付けない
- 日の入り・日の出は端末の中で計算（位置は送らない）。位置がないときは最後に近かった空港、それもなければ東京
- 切りかわるときは色を 0.6秒かけて変える。`prefers-reduced-motion` の人はすぐ
- 設定はサーバーに保存（表示の隠す設定と同じ所。ログインなしは端末）。表と RLS はデータ担当

## 使い方の決まり（夜だけ）
1. 本文・見出し・ボタンの字はふだんの書体（`--gothic`）。等幅の計器の字は数字だけ（`.n-num`）
2. 光らせる（`.n-lit` 緑・`.n-here` 琥珀）のは1画面に主役の数字1〜2つ、多くても3つ。ほかの数字は等幅の `--n-strong` で光らせない
3. 光る色は緑と琥珀の2色だけ。金（特別塗装機）は琥珀に、JAL赤・ANA青は字の色（`--n-strong`）に読みかえる。会社は便名の字（JL・NH）で分かる
4. 出す・隠すなどの状態は色だけにしない。「入／切」の札、塗り（実績）と縞（計画）などの形でも分ける
5. 角丸カード＋薄い影・ピル型・黒い区切り線なしは昼と同じ。外すのは「画面全体を黒にしない」だけ
6. 空港コードのパタパタ（近い空港）はふだんの細長い書体のまま、光らせない

## 読みかえる今の変数
`tokens.css` の 2.（`:root[data-night="on"]` の一覧）と 3.（要素に直接書いてある変数：`dialog.mypage`・`.boardzone`・`#dSpecial`・`#dLayout`・`.fwc`）。今のコードで色をじかに書いている所（例：`.darkcard{background:#1F2329}`・`#v-log .lbtn` など）は変数に置きかえてから重ねる必要がある。どこまであるかはチェックイン担当が数えてほしい。
