# 夜の画面の色の決め方（チェックイン担当へ渡す形・2版）

本体は `tokens.css`。今の `src/index.html` の色の変数の上に重ねるだけで、画面ごとの CSS は書きかえない前提。

## つけ方
- 夜のとき `<html data-night="on">` を付ける。昼は外す（`data-palette` はそのまま残す）
- 夜になる条件：設定が「自動」で、いる場所の日の入り〜日の出のあいだ／設定が「いつも夜」。「いつも昼」なら付けない
- 日の入り・日の出は端末の中で計算（位置は送らない）。位置がないときは最後に近かった空港、それもなければ東京
- 切りかわるときは色を 0.6秒かけて変える。`prefers-reduced-motion` の人はすぐ
- 設定はサーバーに保存（表示の隠す設定と同じ所。ログインなしは端末）。表と RLS はデータ担当

## 使い方の決まり（夜だけ）
1. 本文・見出し・ボタンの字はふだんの書体（`--gothic`）。等幅の計器の字は数字だけ（`.n-num`）
2. 光らせる（`.n-lit` 緑・`.n-here` 琥珀）のは1画面に主役の数字1〜2つ、多くても3つ。ほかの数字は等幅の `--n-strong` で光らせない
3. 光る色は緑と琥珀の2色だけ。琥珀は「いま・次」だけ。金（特別塗装機）は琥珀にせず、★／☆ の形と強い字（`--n-strong`）に。JAL赤・ANA青も字の色に読みかえる。会社は便名の字（JL・NH）で分かる
3b. 選んでいるピル・いまのタブ・選んでいる設定は色を使わず、強い字＋細い縁（`--n-sel-ring`）。主ボタンは塗らず、地に琥珀の字と縁（大きい光る面を作らない）。風・注意は光らせない
4. 出す・隠すなどの状態は色だけにしない。部品は昼と同じ（タブを選ぶは「−」と「＋ 出す」と ≡）。夜だけ別の部品（入／切の札など）にしない。修行は塗り（実績）と縞（計画）
5. 角丸カード＋薄い影・ピル型・黒い区切り線なしは昼と同じ。外すのは「画面全体を黒にしない」だけ
6. 空港コードのパタパタ（近い空港）はふだんの細長い書体のまま、光らせない

## 読みかえる今の変数
`tokens.css` の 2.（`:root[data-night="on"]` の一覧）と 3.（要素に直接書いてある変数：`dialog.mypage`・`.boardzone`・`#dSpecial`・`#dLayout`・`.fwc`）。今のコードで色をじかに書いている所（例：`.darkcard{background:#1F2329}`・`#v-log .lbtn` など）は変数に置きかえてから重ねる必要がある。どこまであるかはチェックイン担当が数えてほしい。

## 2版で足した決まり
- **自動で一度変えたら、次の日の出（または日の入り）まで戻さない**。日の入り・日の出の計算に使う場所は、その日最初に分かった場所で固定する（日の入りのころに東西へ移動しても、昼と夜が何度も入れかわらない）
- 「今夜は昼の画面にする」（はじめての夜のカード）は、設定を「自動」のまま次の日の入りまで昼にする。いつも昼にしたい人はマイページで選ぶ
- 1画面で光らせる（緑・琥珀）のは3つまで。確認コードのように数字が並ぶ所は光らせない

## 本番で別に要る所（変数だけでは変わらない）
- 地図の絵（国土地理院の淡色地図）は夜にそのまま出すと上半分がいちばん明るくなる。案は2つ：①夜だけ地図の絵に `filter`（反転＋暗く。tokens.css の 6.）をかける ②陸と海を描いた夜用の地図に替える。どちらでも出典「地図：国土地理院」は残す（4版の画面案では方位の丸の下＝地図の左上に置き、はじめての夜のカードやシートに隠れないようにした）。加工したときに「地図：国土地理院（加工）」と書くかは、データ担当に国土地理院の利用規約で確かめてもらう
- 字や地の色を直接書いている所（例：`color:#4b5563`、`background:rgba(255,255,255,.88)`、`.darkcard{background:#1F2329}`）と、図や印の svg に色を直接書いている所は変数に置き換えてから重ねる
- 今の `--shu`（朱）を塗りに使っている所（選んでいる印・主ボタンの地）は、夜は 5. の `.n-sel`・`.n-pri` の形（枠と字）に置き換える。変数だけ重ねると強い字の色の大きな面になる（出典：night-c の tokens.md の書き出しを取り入れた）

## 4版で足した決まり（ON／OFF のスイッチ・タブ帯）
- スイッチの色の変数（昼と夜で同じ部品。値だけ変わる）。OFF の縁とつまみの縁は、まわりの地と 3:1 以上
  | 変数 | 昼 | 夜 |
  |---|---|---|
  | --sw-on-bg | #16233A | rgba(220,227,234,.16) |
  | --sw-on-ring | #16233A | rgba(220,227,234,.72) |
  | --sw-on-ink / --sw-on-knob | #FFFFFF | #DCE3EA |
  | --sw-off-bg | #E5E8EE | transparent |
  | --sw-off-ring | **#768090**（前は #C7CDD6） | **#66778C**（前は rgba(150,170,195,.30)） |
  | --sw-off-knob-ring | **#768090**（前は #B8C0CB） | **#66778C**（前は rgba(150,170,195,.35)） |
  | --sw-off-ink | #4B5563 | **#AEB9C6**（前は #8996A7） |
  | --sw-off-knob | #FFFFFF | #3A4654 |
- 測った値：昼の OFF の縁は白と 4.0:1・行の薄い地 #F7F8FA と 3.8:1・スイッチの地 #E5E8EE と 3.2:1。夜の OFF の縁は #0D1218 と 4.1:1・#141B24 と 3.8:1
- OFF の行は字と地を薄くしてよいが、スイッチの濃さ（縁・つまみ・札の字）は落とさない
- タブ帯の地は夜は透けない #0D1218（下のカードの字がタブの字と重なって見えないように）
