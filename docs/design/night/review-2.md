## 指摘（効き目の大きい順）

### 1. ON／OFF のタブ：OFF にすると行がいちばん下へ飛び、ホームに出すものとふるまいが違う ── 効き目：大
- **何が**：報告に「OFF の行は番号と ≡ を出さず、タブは一覧のいちばん下、ホームのかたまりは見本の同じ場所に縁だけで残す」。同じ見た目のスイッチなのに、タブの画面だけ押した行が指の下から消える
- **なぜ**：スイッチは「押した所で状態が変わる」部品なので、押した行が動くと、押し間違えたときに同じ所をもう一度押して戻せない（行はもう下にある）。2つの画面で同じ部品が違う動きをすると、どちらかで必ず迷う
- **どう直す**：タブも押した場所に OFF のまま残す（番号は消して薄くする）。並びを詰めるのは「完了」を押したときか、次に開いたとき。報告の「本人に決めてほしいこと3」は、両方「同じ場所に残す」を勧める

### 2. 本人が見比べる写真が、実装と本番の見た目とそろっていない ── 効き目：大
- **何が**：
  - 画面案はスイッチの左に ≡、実装（feat/all-in-tabs の 15）はスイッチの右に ≡。実装は OFF の「成績」にも ≡ があり、説明の文（「5つまで」「マイページから開けます」）や「全部乗せに戻す」（画面案はボタン、実装は右の薄い字）も違う
  - タブ帯の絵が本番と違う。本番は図鑑＝本・フライト＝飛行機・運用＝的・修行＝階段、画面案は図鑑＝四角2つ・運用＝塔・修行＝ストップウォッチ。これは 01・02・04 など夜の画面すべてで同じ
- **なぜ**：本人は「4枚の写真を並べて」ON／OFF を決める。写真と実装で ≡ とスイッチの位置が逆だと、決めた形と入る形が違ってしまう。夜の画面は「色だけ変える」約束なのに、絵が変わると本人は別のアプリに見える（review-1 の 1 と同じ種類）
- **どう直す**：ON／OFF の並び（≡ とスイッチの左右・OFF の行に ≡ を出すか）を、デザイン担当とチェックイン担当でどちらかにそろえてから本人に見せる（PM から両方へ）。押す所がいちばん右の端にあるほうが親指で届くので、**スイッチを右端・≡ をその左**（今の画面案）を勧める（→ 同じ日の追記：アプリの「≡ を右端」もスマホの並べ替えのつまみと同じ位置でよい。どちらかにそろえることが大事。all-in-filter-alt/review-c3.md の 6）。タブ帯の絵は本番の絵のまま色だけ夜にする

### 3. OFF のスイッチの輪郭が薄く、行ごと「押せない」に見える ── 効き目：中
- **何が**：変数から測ると、OFF の輪郭と地の差は昼 1.6:1（#C7CDD6 と白）・地の灰色は 1.2:1、夜は輪郭 1.8:1・つまみ 2.0:1。ON の夜の地も 1.5:1。部品の形の差の目安 3:1 に届かない。OFF の行は字も薄く、地のない細い縁だけ
- **なぜ**：「OFF」の字は読めるが、輪郭が見えないと、スイッチではなく札（ただの表示）に見える。行全体が薄いので「使えない機能」と受け取られ、ON に戻せると気づかない人が出る。いちばん戻したいのが OFF の行なのに、いちばん見えにくい
- **どう直す**：OFF の輪郭とつまみの縁を 3:1 以上に（昼は #8A94A3 前後、夜は rgba(150,170,195,.6) 前後で測り直す）。行の字は薄くしても、スイッチだけは濃さを落とさない

### 4. 5/5 のときに「成績」を ON にするとどうなるかが見えない ── 効き目：中
- **何が**：タブは 5/5 でいっぱい。成績の OFF のスイッチは ON にできそうに見えるが、報告では「入れ替えを聞く（描いていない）」
- **なぜ**：スイッチは押せばすぐ切り替わるものと思われる。押すと別の画面（入れ替えの質問）が出るのは予想外で、断るとスイッチが OFF に戻る。はじめての人は「壊れた」と感じやすい
- **どう直す**：5/5 のときは OFF の行の下に小さく「ON にすると、外すタブを選びます」と出す。入れ替えの画面（2版の T3 の ON／OFF 版）も1枚描いて、本人に見せる写真に入れる

### 5. 04b：北風の着陸（34L）が「城南島の頭の上を通る」は向きが合わない ── 効き目：中
- **何が**：「34L への着陸機が頭の上を通ります」。34 は 340° の向きに降りるので、着陸機は羽田の**南**から入ってくる。城南島海浜公園は羽田の**北**にある
- **なぜ**：撮る人の見方の一番上の答えが向きと逆だと、行ったのに撮れない。見本の文でも、本人はこの画面で「撮る人の見方」の中身を判断する。ほかの見本（次に来る機体の「34L に着陸の見込み」）も同じ前提に乗っている
- **どう直す**：北風の夜なら、着陸機が頭上を通る南側の場所か、城南島なら「34R・05 からの離陸機が見える」のように向きに合う文にする。実装のときの決め方も「着陸機は滑走路の手前（数字の向きと逆の側）から来る」で確かめる（運用予想の担当へ）

### 6. 04：離陸に「05」とあるのに、図に 05 の滑走路がない ── 効き目：中

### 7. 10：はじめての夜のカードが、地図の出典と ＋ − を隠す ── 効き目：中

### 8. 667 の ON／OFF のタブ：戻したい OFF の行と「全部乗せに戻す」がタブ帯の下 ── 効き目：中
