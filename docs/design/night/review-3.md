## 指摘（効き目の大きい順）

### 1. 4版がアプリの今の形とまた違う（大）
- 画面・場所：07-tabs-v4-onoff・07c・day-C1・day-C3 の全体
- 何が：アプリ（写真15・16・18・21）には、題の横の数「4/5 5つまで」、1行の説明「OFF で隠れます。≡ で並べ替え。」、送っても残る題と「完了」、OFF の行の2行目「マイページから開けます」（1行）、画面の下に浮くトーストがある。4版は数がなく、説明が2行、題が送ると消え、OFF の行は「滑走路と便を見る／マイページのタイルから」の3行
- なぜ：報告は「アプリと同じ」と書いているが、そろえた相手が古い写真。本人が写真を並べると、別の画面を2つ見比べることになり、「ON／OFF にするか」の問いがぼやける
- どう直す：アプリの 2e57613 の形に合わせ直す。あるいは、昼の ON／OFF は**アプリの写真をそのまま本人に見せ**、画面案は夜の2枚（07・07c）だけアプリの形の夜の色にする（アプリにはまだ夜がないため）。こちらのほうが早い

### 2. 夜の運用で「予想」と出していない・言葉が昼と違う（大・決まりと食い違う）
- 画面・場所：04「いま使っている滑走路（見込み）」、04b「次の離陸 7分後」「34R から離陸の見込み」と下の注意書き
- 何が：夜の画面案の運用は「見込み」が7回、「推定」0回、「予想」は2回だけ。本番（main）は推定137・見込み23・予想14。04b の大きい琥珀の「7 分後」と次に来る機体の滑走路は運用の予想なのに、札は「見込み」
- なぜ：決定事項は「運航予想と運用予想は画面では『予想』と出し、保証しないと書く」。夜は色だけを変える画面なのに、昼と言葉が変わると、同じものか分からない
- どう直す：いまの滑走路は昼と同じ「推定」、次の離陸・次の機体の滑走路は「予想」。いちばん目立つ「7 分後」の上の札を「次の離陸（予想）」に。注意書きは昼の文をそのまま使う

### 3. 送ると題と「完了」が消える（大）
- 画面・場所：07c・day-C3（844 でも題が画面の外）、07-tabs-v4 の 667 を送った形
- 何が：入れ替えの帯までシートを送る形にしたので、選んだあと「完了」が見えない。閉じるには上まで戻すか、下に引くしかない
- なぜ：review-c3 の①と同じ。アプリは題と完了を固定して直した（写真21）。画面案だけ戻っている
- どう直す：題・数・完了をシートの上に固定し、送るのはリストだけ（アプリの形）

### 4. OFF の行だけ3行で、絵の場所もずれる（中）
- 画面・場所：タブを選ぶの「運用」「成績」の行（昼夜）
- 何が：OFF にすると行が 60→75px に伸び、番号の欄が消えて絵が左へ寄る。押した場所に残す形にしたのに、行の形が変わるので「同じ場所に残った」と感じにくい
- なぜ：報告は「番号の欄を空けると2行目が割れる」と書くが、アプリは2行目を「マイページから開けます」の短い1行にして、番号の欄を空けたまま収めている
- どう直す：番号の欄は空けたまま、絵の位置は ON の行と同じ。2行目は「マイページから開けます」だけ（説明の「滑走路と便を見る」は外す）

### 5. 入れ替えの一言「ON で外すタブを選びます」が逆に読める（中）

### 6. ホームに出すもののスイッチが行の右端に貼り付く（中）
