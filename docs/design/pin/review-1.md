## 指摘（効き目の大きい順）

### 1. 通知を許可していない・iPhone でホーム画面に置いていないときの形がない（大）
- 画面・場所：K4 ピン止めした直後のシート、K5 知らせ、K6 羽田の知らせ
- 何が良くないか：どの画面もスイッチが ON で「どれもこの端末に届きます」と書くが、通知の許可がまだ・断った・iPhone の Safari でホーム画面に追加していない（この場合は Web の通知が届かない）ときの見え方がない
- なぜ：はじめての人がいちばん多く出会う状態。ON に見えるのに何も届かず、「特別塗装機が来たのに知らせがない」と思われる。今回の目的「通知が来る設定をうまくやりたい」の中心
- どう直すとよいか：K4 の上と K5 の頭に、端末の状態の1行を足す（「この端末は通知が許可されていません｜許可する ›」「iPhone はホーム画面に追加すると届きます｜やり方 ›」）。許可がないあいだはスイッチを ON にしても札に「届きません」を付ける。最初のピン止めで OS の許可を聞く流れ（K4 の前の1枚）も描く
- 効き目：大

### 2. ピン止めしているかどうかが見分けにくく、画面ごとに食い違う（大）
- 画面・場所：K1 のピンの丸、K2・K6・K6n の「ピン止め中」、K3 の「ピン止め」、K8 の行の丸
- 何が良くないか：
  - 同じ成田が K1・K5・K8 ではピン止め中（紺の丸）、K3 の図鑑では「ピン止め」（していない形）
  - 状態の見分けが丸の塗り（紺／薄い灰）だけ。K1 のいちばん近いカードでは黒い地に白い丸で、ピン止め中なのかどうかが読めない（していないときの形は描かれていない）
  - K6・K6n は上の「ピン止め中」と下の「羽田のピン止めを外す」の2つがある。上を押すと外れるのか、ただの札なのかが分からない
- なぜ：付けた・外したの結果が見えないと、同じ所を何度も押したり、知らない間に外したりする。外すと知らせが全部止まる（K6 の注意）ので、取り違えると困る
- どう直すとよいか：どの画面も「紺の塗り＋塗りのピン＋字『ピン止め中』」と「白＋線のピン＋字『ピン止め』」の2つにそろえる（行の丸も字のない所は塗りと線の形でも分ける）。黒いカードの上でも同じ2つの形を描く。K6・K6n の上は押せない札にして、外すのは下のボタンだけにする。成田の状態を全画面でそろえる
- 効き目：大

### 3. 運用タブ（K7）の上の段が、決まった1行の形と違う（大・決まりと食い違う）
- 画面・場所：K7・K8 の上の段
- 何が良くないか：「空港｜機体」と「HND 羽田 近く ⌄」が2段に分かれ、空港のピルに「近く」がある。見方の帯の右に鉛筆がなく、「撮る人」は x=412 で画面の外
- なぜ：【11/16】の決定「運用タブは上を『空港｜機体』の切り替えと空港のピルの1行にする」と食い違う。本番（review-1-shots/ops-844）はもう1行（空港・機体・HND 羽田・ⓘ・共有）で、鉛筆は帯の右端 x=330 に固定、「近く」もない。古い形で描くと、本人は今の画面との違い（ボタンを状態の1行に変えたこと）を見比べられない
- どう直すとよいか：K7・K8 を本番の今の上の段（PR #112 の形）で描き直す。変えるのは特別塗装機の欄の下の「羽田はピン止め中」の1行だけにする
- 効き目：大

### 4. ホームのいちばん近いカードの白い丸が、チェックインと張り合い、本番の「ほか1つ」と「右へ引いて印をもらう」が消えた（大）
- 画面・場所：K1 のいちばん近いカード
- 何が良くないか：44px の白い丸のピンが空港名のすぐ右にあり、黒いカードの中でチェックインの次に目立つ。本番（home-844）にある「ほか1つ ›」のピルと、チェックインの「→ 右へ引いて印をもらう」がなくなっている
- なぜ：ホームのいちばん大事な操作は印をもらうこと。はじめての人は「白い丸を押すと何か起きる」とまず思い、引いて印をもらう案内も消えている。長い空港名（「大館能代空港」「但馬飛行場」など）は丸に押されて切れやすい
- どう直すとよいか：カードの中のピンはやめるか、空港コードの横の小さな線のピン（白い丸なし）にする。ピン止めの入口は「ほかに 20km 以内」の各行と空港ページ（K2）を主にする。「ほか1つ」と引いての案内は本番のまま残して描く
- 効き目：大

### 5. 「この機体が飛んだら」の知らせ（機体ごと）の行き先がない（中）
- 画面・場所：K5・K9（00 の表の5行目）
- 何が良くないか：00 の表には「この機体が飛んだら（特別塗装機のくわしく・機体ごと）」があるが、2版では「機体（2番目の案）」に回され、機体のピン止めを入れないと決めたときにどこに残るかが描かれていない。K9 の移す案内にも出てこない
- なぜ：本人が「機体のピン止めはあと」と決めると、今これを申し込んでいる人の知らせが画面から見えなくなる（止め方が分からない）
- どう直すとよいか：機体のピン止めがない場合の K5 の形（「機体ごとの知らせ ○機 ›」の行を残す）と、K9 で機体ごとの申し込みも「そのまま続きます」と書く1行を足す
- 効き目：中

### 6. K5 のチップで、どの知らせが ON か一目で分からない（中）
- 画面・場所：K5 の各空港のカードのチップ
- 何が良くないか：ON は薄い灰の塗り・OFF は灰の縁取りで、どちらも灰色。OFF の字は #8A919C で白地に 3.18:1。チップは押せそうに見えるが、押すと何が起きるか（切り替わるのか、カードが開くのか）も分からない
- なぜ：この画面の役目は「どこで何が ON か」を見渡すこと。灰と灰の違いでは見渡せない。字の濃さ 4.5:1 の決まりにも届かない
- どう直すとよいか：ON の知らせだけをチップで出し（紺の字か ✓ つき）、OFF はまとめて「ほか2つは OFF」と薄い字1つにする。チップは押せない見た目（影なし）にして、押す所はカード全体と › にそろえる
- 効き目：中

### 7. 知らせの画面（K5）から空港を足せない（中）
- 画面・場所：K5 の「ピン止めした空港 3 / 12」
- 何が良くないか：「並べ替え」はあるが「空港を足す」がない。足すにはホーム・空港ページ・図鑑へ行き、その空港を開いてピンを押す
- なぜ：知らせの設定をしに来た人は、ここで「伊丹も足したい」と思う。遠くの空港（ホームの 20km の外）は空港ページを探して開くまで手順が多い
- どう直すとよいか：一覧の下に「＋ 空港をピン止め」を置き、K8 と同じ探す欄のシートを開く。12 に届いたら押せない形にして「12空港まで」と書く
- 効き目：中

### 8. 間違えて付けた・外したときに戻せない。直後のシートが毎回出る（中）
- 画面・場所：K1・K8 の行のピン、K4 のシート
- 何が良くないか：K1・K8 の行の丸を押すと、確かめずに外れるように見える（外すと知らせが全部止まる）。K4 は「完了」だけで、付けたのを取り消せない。K4 がピン止めのたびに出るのかも分からない
- なぜ：行の丸は行を押す所（空港を開く）のすぐ右で、指がずれやすい。毎回シートが出ると、3つ4つ続けて付けるときに操作が増える
- どう直すとよいか：外したときは下に「羽田のピン止めを外しました｜元に戻す」を数秒出す（知らせの設定も戻す）。K4 は最初の1回だけシートにし、2回目からは「ピン止めしました｜知らせの設定 ›」の帯にする。K4 に「取り消す」を足す
- 効き目：中

### 9. 「ピン止め」と「いつもの空港」、「主な8空港」と「主な14空港」が並んで分かりにくい（中）
- 画面・場所：K6n の撮影・ゴーアラウンド・欠航の行、K4 の撮影の行
- 何が良くないか：空港の選び方が「ピン止め（12まで）」と「いつもの空港（撮影は1つ）」の2つになる。K6n では「主な8空港でないので」と「主な14空港だけです」が続けて出て、どの空港が「主な」なのかが分からない
- なぜ：はじめての人には「ピン止めしたのに撮影の知らせが使えない」理由が伝わりにくい。せっかく1か所にまとめたのに、決め方が2つ残る
- どう直すとよいか：撮影の知らせは「ピン止めした空港のうち1つで ON」にし、別の空港で ON にしたら「撮影の知らせを羽田から石垣に移します」と1行で聞く（「いつもの空港を変える ›」はなくす）。「主な」は空港名で書く（「羽田・成田・関西など8空港だけ」「14空港だけ（一覧 ›）」）
- 効き目：中

### 10. 字の切れで「（推定）」が消える、見出しの変な折り返し、667 で一覧がタブ帯の下（小）
- 画面・場所：K7・K1・K2・K6
- 何が良くないか：K7 の2行目「B-58201・BR 192 台北から（…」で（推定）が切れる。K1 は「東京ヘリポ…」「いちばん近い民間空港…」。K2・K7 は見出し「この空港に向かっている特別塗装／機」「3時間のう／ち」、K6 は「ダイバー／ト」で折れる。K1 の 667 では「ほかに 20km 以内」の2行がタブ帯の下にもぐる
- なぜ：推定・予想は画面に出す決まり（決定事項）。切れると実績のように読める。1字だけの折り返しは読みにくい
- どう直すとよいか：推定の札は行の頭か時刻の横に置き、切れない所へ。見出しは短く（「向かっている特別塗装機」）、右の補足は見出しの下へ。K6 の題は「遅れ・門限・ダイバート」に。667 の K1 は本番のシートの位置で描き、一覧はシートの中で送れる形に
- 効き目：小
