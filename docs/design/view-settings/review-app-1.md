## 指摘（効き目の大きい順）

### 1. 表示の編集の上の3つが 44px より低い（中）
- 場所：表示の編集の「‹ マイページ」（109×38）・鉛筆から来たときの「閉じる」（83×38）・「すべて」（68×40）・「隠しているもの N」（133×40）
- なぜ：押しにくい。画面案 v2 は「すべて／隠しているもの」とも 44px
- どう直す：高さ 44px に（画面案どおり）
- 効き目：中

### 2. タブのカードが「全部出しています」なのに、開くと成績が OFF（小）
- 場所：表示の編集のタブのカード
- 何が：成績を隠しているものに数えない決め方（報告の決めてほしいこと2）なので、見出しは「全部出しています 5/5」。開くと成績の行が OFF で並ぶ
- なぜ：見出しと中身が食い違って見える
- どう直す：数はそのままで、見出しの補足を「成績はマイページのタイルにあります」にする
- 効き目：小

### 3. デモで隠した見方が、デモを終えたあとも残る（小）
- 場所：図鑑の見方
- 何が：デモで地方別と地図を OFF にして開き直すと、デモは終わってログインの前の画面になるのに、図鑑は「行った順」だけのまま。デモの帯は「記録は本番と別・終えると消えます」と言っている。保存先が同じ（LO_KEY・soramemo.view.*）ためと思われる。本番 main でも同じかは確かめられていない
- どう直す：デモの間の表示の設定は別に持つか、デモを終えるときに戻す
- 効き目：小

### 4. 修行のカードがない（小・報告どおり）
- 場所：表示の編集の1枚
- 何が：画面案 v2 の修行のカード（7/7）がない。修行担当が LO_EXT.sg を足すまで出ない
- どう直す：反映の前に修行担当の分が入るか、入らないなら1枚の下の文に「修行の見方は修行の画面の鉛筆から」と1行
- 効き目：小
