空港の3D（羽田）

ブランチ design/airport-3d・画面案だけ（アプリには入れない・構想段階）。4版は改善担当 review-2 を入れた版（見本の機体は約3分の所・全体は北から見る形）。3版は改善担当 review-1 を入れた版（02 は本物の羽田の空港ページに入口を描いた写真）。2版はデータ担当の調べ（report-airport-3d-data.md）を足した版。11/11 本人「取り入れて」。空港の形は仮のおおまかな配置、便名・登録記号は見本。

決めた形

  • 入口は羽田の空港ページの「空港の今」のカードの中。止まった見本の絵＋「3Dで見る ›」。3Dは押したときだけ読み込む
  • 3版：空の札・受信中の札は上のピルの下（左上）、出典は右下だけ。選んだ機体はカードの上の残りの真ん中に寄せる。入口の見つけるきっかけとして数字のカードの下に小さな「3Dで見る ›」（02b）
  • 開いた画面は全画面。上に閉じる・題（約1分遅れを常に書く）・設定、その下に視点のピル3つ、下に見えている機体のシート
  • 視点：全体（ななめ上から）／管制塔（塔の高さ、左右に回す）／機体（選んだ機体のうしろ）。機体は選ぶまで押せない
  • 空：昼・夕方・夜・雲や霧の4つ。観測と日の出入りで自動。出す字は「夕方・日の入り」「遠くがかすんで見えます」くらいで、天気の数字は出さない。印や実績にはしない
  • 低いポリゴンは私たちの色（白い建物・灰の滑走路・航空図風の淡い地面）。会社の色は機体に塗らない。特別塗装機だけ尾翼を金（夜は灰）
  • 夜の画面では光る色は緑と琥珀（琥珀は「いま」の状態と窓）。滑走路の灯りは白い点
