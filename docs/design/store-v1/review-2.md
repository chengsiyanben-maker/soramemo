## 指摘（効き目の大きい順）

### 1. 04・06b 書き出しと取り込みの説明が、本番の動きと違う（効き目：大）
- 何が：04 は「記録を JSON か CSV で書き出しておくと、あとで取り込めます（無料）」、06b は「印・乗った便・会社を、JSON か CSV で書き出せます（無料）」。本番（main の web/index.html）では、
  - 取り込み（まとめて取り込む）は**そらメモ＋の機能**（「一括取り込みは そらメモ＋ の機能です」）。v1 にはそらメモ＋を出さないので、ストアのアプリでは取り込めない
  - 取り込めるのは CSV の形だけで、JSON を取り込む所はない
  - 書き出しの中身はチェックイン・フライト（記録帳・国際線）で、**エアライン経営の会社は入っていない**
- なぜ：削除の直前にいちばん頼りにされる文が事実と違う。「書き出したから消しても大丈夫」と思って消した人が、あとで戻せない（取り返しがつかない）。会社は書き出しに入らないので「会社」と書くのも違う。さらに、取り込みが有料のままだと**決定事項「バックアップは有料機能にしない」と食い違うおそれ**がある（書き出しだけ無料で、戻すのが有料）
- どう直す：
  - 文を今の事実に合わせる：「チェックインと乗った便を JSON か CSV で書き出せます（無料）。エアライン経営の会社は書き出しに入りません」。「あとで取り込めます」は、取り込みを無料にすると決まるまで書かない
  - 取り込み（CSV）を v1 から無料にするか、本人に聞く問いとして報告に足す（PM へ。作るのはチェックイン担当）
- 効き目：大

### 2. S1 紹介画像：いちばん見せたい半券が白いぼかしで消え、断り書きが端末の枠に重なる（効き目：中〜大）
- 何が：端末の絵の下半分に白いぼかしがかかり、半券の「チェックイン 右へ引く →」が薄れて読みにくい。「非公式アプリ　航空会社や空港とは関係ありません」の行が端末の枠の下の端に重なっている
- なぜ：1枚目の言葉は「空港に着いたら、印をもらう」なのに、印をもらう操作（右へ引く）が見えない。断り書きは枠と重なると絵の一部に見え、縮めると約8pt でさらに読みにくい。ぼかしの上の字は濃さも測れない
- どう直す：端末の絵を上へ上げるか小さくし、半券を全部見せる（ぼかしは半券より下だけ）。断り書きは枠の外、下に余白をとって置く。幅360ほどに縮めた見え方も並べる（共有画像の案と同じ確かめ方）
- 効き目：中〜大

### 3. 06 マイページ：今のマイページのどこに入るのかが描かれていない（効き目：中）
- 何が：06 は「印・乗った便・会社・通知」の4枚と、その下に「設定」の小さいタイル2つだけの見本。今の本番のマイページは節が「アカウント・そらメモ＋・構成・表示・データ・詳しい設定」で、アカウントは**いちばん上**にある。改善案 v4 のマイページのタイルとも並びが違う。報告の「迷った点」にも「見本」とある
- なぜ：作るチェックイン担当が、今の「アカウント」の節（上）と新しい「アカウント」のタイル（下）のどちらを残すのか、構成・表示・詳しい設定・データ（書き出し）はどこへ行くのかを決められない。名前が2か所に出ると、指摘2（1回目）で直した「名前を1つに」がまた崩れる
- どう直す：今のマイページ（または v4 のタイル）の上に、2つのタイルを置いた1枚を描く。今の節がどこへ行くか（データの書き出しは「アカウント」の中・構成と表示は今のまま、など）を1行ずつメモに書く
- 効き目：中

### 4. 03 送信待ち：24時間を過ぎたらどうなるかがない・言い方（効き目：中）
- 何が：「11/6 18:42 に引きました。電波が戻ったら自動で送ります（24時間以内）。送れたら印になります」。24時間を過ぎたらどうなるかが書いていない。「引きました」は操作の名前で、はじめての人には何をしたのか分かりにくい。「送信待ち」が半券の右と黄色いピルで2回
- なぜ：分かりにくい・不安になる。機内モードのまま長く移動する人は、24時間を過ぎると印が消えるのかを知りたい
- どう直す：本番の動きを確かめて1文足す（例「24時間のうちに送れないときは、預かりを消してお知らせします」）。「18:42 に受け付けました」に。半券の右は「電波が戻ったら」だけにして「送信待ち」はピルの1回に
- 効き目：中

### 5. 01 許可の前の画面に「‹ 戻る」と「2 / 3」が残る（効き目：小〜中）
