# そらメモを根本から見直す：使う人の目的（2026-11-06・デザイン担当）

本人の言葉（11/6）「もっと抜本的なデザインの見直し、仕組みをそもそも変えてもよい」を受けて、画面を少し直す前に、使う人が何をしたいかから並べ直す。
今の画面は main の web/ を手元で開き、デモで実際に触って確かめた（スマホ幅390。撮った画面は now/ に置いた）。

## 1. 3つの使い方の人が、いつ何をしたいか

| | 空港に行く前 | 空港で | 飛行機の中 | 帰ってから |
|---|---|---|---|---|
| **撮る人** | 今日の滑走路の使い方（予想）、特別塗装機が来るか・何時ごろか、どの撮影地がよいか（光・距離） | 次に来る機体と時刻、いまの滑走路、撮影地、ついでに印 | （乗るときは）乗った機体の登録記号を残す | 撮った・見た機体を残す、特別塗装機の図鑑に「撮った」 |
| **修行する人** | 時刻表から行程を作る・予定に入れる、ポイントの残り | 印、次に乗る便の遅れ・機材、乗り継ぎの時間 | 乗った便が記録されたか、この便で何ポイントか | 実績（記録した便だけ）・1ポイントあたり・目標までの残り |
| **気軽な人** | まだ行っていない空港、行く空港の「いま」 | 印をもらう（いちばんうれしい瞬間）、共有する | 何もしない（記録は自動でいてほしい） | 印と路線の地図を眺める、共有画像、会社に収益が入る |
| **経営（3人とも）** | — | 守り神（チェックインした日の数で育つ）が増える | 乗った区間が路線になる（はず） | 収益を受け取る・路線と機体を見る（毎日の習慣） |

まとめると、どの人も **「空港に入った瞬間」と「乗った便が記録された瞬間」** の2つが山場。行く前と帰ってからは、人によって見たいものが大きく違う（撮る＝空、修行＝予定と実績、気軽＝帳面）。

## 2. 今のアプリで遠回りなところ（触って確かめたこと）

1. **はじめて開くと3つの層が重なる**：使い方の案内（3枚）→ ログインの画面 →「デモで試す」を押しても、もう一度ログインの画面（あとで）が出る（now/2-demo-login-again.png）。半券を切るまでに4回押す（とばす・デモで試す・あとで・半券）
2. **フライトを記録する入口が2つ**：チェックインの窓に「次の空港でチェックインすると、ここからのフライトが記録されます」とあり、2つの空港で印をもらってはじめてフライトになる。便名や登録記号は別の「フライト」タブの＋かスクリーンショットから入れる。経営の機体（乗った登録記号）につながるのは後者だけ
3. **スタンプラリーと経営が別のアプリ**：上の切り替えで経営にすると、下のタブが「会社・路線・機体・守り神」にまるごと入れ替わる（now/8-game.png）。「飛んだ区間が路線になる」つながりが画面のどこにも見えない。経営の画面は資金などの字が明朝体に見える（手元で字の読み込みが効いていないだけかもしれない）
4. **地図が2つ**：ホームの地図（判定範囲）とフライトの地図（路線）が別々にある
5. **使い方ごとの画面がマイページの奥**：構成「気軽に」では運用・修行・成績はマイページの「◯◯を開く」から（2回押す）。マイページは設定と画面の入口が混ざって縦に長い
6. **デモの帯が上に2行**で、地図と見出しの場所を取る
7. （確認したいこと）チェックインの窓に「春の訪問」という札が付いた。却下済みの「季節のスタンプ」に当たらないか、PM に確かめてほしい（この見直しの案には入れていない）

## 3. 見直しで守ること
- 3案とも、今あるデータだけで作る：86空港と番外編、ODPT の便と時刻表、全機の位置と航跡（adsb.lol）、運用の推定（14空港）と運航予想、特別塗装機の一覧（92件）、修行の計算ルール、経営の会社・路線・機体・守り神
- 却下済みのもの（天気の印・運用の印やバッジ・窓側の席・機体と運航の実績・空のカレンダー・今日のお題・季節のスタンプ・案内板風の全体・新造機・ニュース）は、仕組みを変えても出さない
- 決定事項と食い違うところは、案ごとに「変える決定事項」に書き、変えるかは本人が決める
