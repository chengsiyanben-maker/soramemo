メモ（本番には出ません）
  • 入り方：ホームの「✎ ホームのカードを編集」か、カードの長押し。長押しで入ったときは、そのカードを持ち上げた状態で開く
  • 並べ替え：左の ≡ を長押しして動かす（図は「次に来る特別塗装機」を持ち上げて、点線の所へ置くところ）。半券は鍵の印で「固定」、動かせない・外せない
  • 大きさ：名前の下の小・中・大のピル（各 44px）。そのカードにない大きさは薄い字で押せない
  • 外す：右の −。外したカードは「カードを足す」の一覧に戻るだけで、記録は消えない
  • はじめに戻す：アンケートで選んだひな形に戻す（今の本番の「はじめに戻す」と同じ）
  • 右上の完了でホームへ。設定はその場で端末に保存（今の soramemo.layout を広げる）
