# D（選べるホーム）カードの一覧（2026-11-06・デザイン担当）

本人の言葉（11/6 14:21）「ユーザーが欲しい情報をカスタマイズできる機能にしたい」を受けた PM の指示による。土台は B'（ホームは地図とシート、タブはホーム・帳面・会社・マイページ）。シートの中身をカードの組み合わせにし、使う人が足す・外す・並べ替える・大きさを変える。3つの使い方（気軽に・撮る・修行）は、はじめのカードの組み合わせ（ひな形）。今の本番の「表示を編集（タブ・見方・出すもの）」（LO_BLOCKS の home・opsb、端末の soramemo.layout）を広げる形。

## 大きさ
- **小**：シートの幅の半分（2枚で1段）。数字1つ＋補足1行
- **中**：シートの幅いっぱい・低め（高さ 約120px）。数字か一覧を3行まで
- **大**：シートの幅いっぱい・高め（高さ 約220px）。小さい地図や一覧5行まで
- 大きさはカードごとに選べるものだけ選べる（下の表の「選べる大きさ」）

## 決まり（どのカードにも）
- 半券（近い空港と半券）は**外せない・いちばん上**。並べ替えでも動かない
- 予想のカードは黄色の札「予想」を付け、カードの下に1行「予想です。保証しません。」（シートの中で予想のカードが続くときは、まとめて1回）
- 推定のカードは札「推定」と「推定です。実際と違うことがあります。」
- 実績と予定は別のカードに分ける。予定は「予定」と出し、着いて「乗りましたか？」に答えたものだけ実績のカードに入る
- 字は13px以上（単位だけ12px）・押せる所は44px以上・角丸＋薄い影・ボタンはピル型
- 課金でしか足せないカードは作らない（課金要素は稼ぎやランキングに効かせない決まりに合わせ、カードはどれも無料）

## 保存先の案

- データ担当への依頼文（表の変更なので、移行と RLS をセットで）：
  > user_home_layout という表を足してほしい。列は user_id（auth.users の id・主キー）、template（casual / spot / shugyo）、cards（jsonb：並び・大きさ・カードごとの設定）、updated_at。RLS は本人の行だけ読む・足す・直す・消すことができ、ほかの人の行は見えない。cards の大きさは 16KB まで。退会したときは本人の記録として消す。

### 動きの決まり（2版・どちらの案でも同じ）
- **開いたときの位置**は新しいホーム（feat/home-v3）と同じ（地図を広く、シートは半券と、2枚目のカードの「ひと目の1行」）。2枚目はどのカードでも1行の形を持つ
- **ホームでの長押しはやめた**。編集の入口は「✎ ホームのカードを編集」とマイページだけ
- **並べ替え**は ≡ を押すとメニュー（いちばん上へ〔半券の下〕・1つ上へ・1つ下へ・いちばん下へ）。≡ を押したまま引いても動かせる
- **外す**と下に数秒「○○を外しました　元に戻す」。外したカードの設定は端末に覚えておき、足し直すと戻る
- **はじめに戻す**は確かめを1回。カードごとの設定と記録は消さない
- **遅れが出てもカードは動かさない**（自分で決めた並びを勝手に変えない）。次に乗る便のカードと1行で知らせる
- **大きさ**はそのカードにあるものだけピルで出す。1つだけのカードは「小だけ」と札で書く
- **小が1枚だけ**になったときは、ホームでは横いっぱい（高さは小のまま）。編集では続いた小2枚を枠でつないで横に並べる
