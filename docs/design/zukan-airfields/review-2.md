## 指摘（効き目の大きい順）

### 1. 小さな地図で、行った3つが1つの丸に重なり、行っていない輪のほうが目立つ（中）
- 場所：02 の 844（入口のカードの右の地図）
- 何が：63か所の輪（まだ）が太い線で描かれ、行った3つ（竜ヶ崎・ホンダ・加須）は関東で1つの大きな緑の丸に重なる。青（滑空場）の行った所は見えない。凡例は「● 飛行場 2/30・● 滑空場 1/33」で、色の説明だけ
- なぜ：はじめての人には、輪がたくさん＝たくさん集めた、に見える。「3」と地図の見え方が合わない
- どう直す：まだの所は輪でなく薄い灰の小さな点にし、行った所だけ色の丸にする。関東に重なるときは丸を少し小さく（8px）して重ねる順を滑空場を上に。凡例に「● 行った所」を1つ足す

### 2. 844 の入口のカードで、題と数字のあいだが大きく空く（小〜中）
- 場所：02 の 844（「飛行場・滑空場」と「3 /63」のあいだ約60px）
- 何が：地図の高さに合わせてカードが伸び、左の字が上と下に分かれる
- なぜ：題と数字がつながって見えず、「3」が何の数か一瞬迷う
- どう直す：左の字の段を上に詰め（題のすぐ下に 3/63 と一文）、内訳2行はその下。余りは下にまとめる

### 3. 近くの空港の画面と図鑑の呼び名がそろっていない（小〜中）
- 場所：近くの空港 4版の 03「飛行場の図鑑の印（16/86 とは別）」と、この画面案の題「飛行場・滑空場」
- 何が：同じ図鑑を、ホームでは「飛行場の図鑑」、図鑑では「飛行場・滑空場」と呼ぶ。加須（滑空場）で印をもらったときに「飛行場の図鑑」と出ると食い違う
- どう直す：呼び名は「飛行場・滑空場の図鑑」に決め、両方の画面案でそろえる（近くの空港 review-4 の7と同じ）

### 4. 扉の札「飛行場・滑空場」が、枠の種類の札「飛行場」と同じ見た目（小）
- 場所：03・03b の上に止まる扉（緑の地の札）
- 何が：図鑑の名前の札と、1空港の枠の種類の札「飛行場」（緑の地）が同じ色・同じ形
- なぜ：扉の札が「この地方の飛行場だけに絞っている」と読める（滑空場の枠が青い札なので特に）
- どう直す：扉の札は種類の色を使わず、白地に濃いグレーの縁（「もう1つの図鑑」のピルと同じ扱い）にする。報告の迷った点への答え

### 5. 03 の黒いカードが86空港のカードとほぼ同じ（小）

- 何が：「集めた飛行場・滑空場 3 /63　まだ 60」と9地方の並びが、86空港のカードと同じ形
- なぜ：上の題と説明を読まずに送った人は、86空港の図鑑と見分けにくい（扉は2で直ったので軽い）
- どう直す：黒いカードの左上に「もう1つの図鑑」のピルを小さく置く、くらいでよい

### 6. 夜の 04b で関東の棒が地方の色（小）
