# 夜の画面の色（チェックイン担当へ渡す形）

画面案：design/night-c（docs/design/night-c/・比べる用。本命は design/night の PR #49）。CSS は `tokens.css` にそのまま使える形で置いた。

## 使い方
1. `tokens.css` の中身を、アプリの CSS の**いちばん最後**に足す
2. 夜のときだけ `<html data-night="1">` を付ける（自動：いる場所の日の入り〜日の出／いつも昼／いつも夜。設定は表示の設定と同じ所にサーバー保存）
3. セレクタは `:root[data-night="1"]:not(#_)`。今の `[data-palette=board][data-focus=JAL]` などより強くするためで、`:not(#_)` に意味はない
4. 夜でも `data-palette`（あかしろ・そら・案内板）は消さない。朝になったら元の色に戻る
5. 数字を光らせるのは `.num` のような数字の所だけ：`font-family:var(--num); color:var(--n-g); text-shadow:var(--n-glow)`。見出し・本文・ボタンの字は光らせない

## 元の色（新しく足す変数）

| 変数 | 色 | 使う所 | 地 #0D131B との差 |
|---|---|---|---|
| --n-bg | #05080D | 画面の地 | ― |
| --n-panel | #0D131B | カード（1px の内側のふち付き） | ― |
| --n-panel2 | #141C26 | ボタン・入力欄・シート | ― |
| --n-bezel | #232E3B | カードのふち（影のかわり） | ― |
| --n-ink | #D3DBE4 | 本文（真っ白にしない） | 13.3:1 |
| --n-strong | #E6ECF2 | 見出し | 15.7:1 |
| --n-sub | #93A0B0 | 補足・単位 | 7.0:1 |
| --n-g | #5EDB94 | **光る色1 緑**：計器の数字・選んでいるタブや見方・実績・特別塗装機 | 10.7:1 |
| --n-a | #F0AE4E | **光る色2 琥珀**：押してほしいボタン（完了・ログイン）・判定範囲・予定・閉まる時刻 | 9.7:1 |
| --n-jal / --n-ana | #E37A86 / #86A8E6 | 会社の印（便の行の左の細い線だけ・光らせない） | 6.6 / 7.8:1 |
| --n-stop | #E37A86 | 欠航（字と一緒にだけ） | 6.6:1 |

光る色は緑と琥珀の2つだけ。昼の金（特別塗装機・集めた）は、夜は緑にまとめる。

## 今の変数に重ねるもの（主なもの）
- 地と字：`--sky --paper --ink --sumi --line --hero`
- 朱と金：`--shu --shu-text --shu-wash --on-shu --gold --gold-text --gold-badge --on-gold`（どれも琥珀へ）
- ホーム：`--h3-*`・`--hm-*`（影は `--n-frame`＝1px の内側のふち）
- 経営・図鑑：`--a-*`・`--bk-*`
- 押してほしいボタン：`--cta-hi --cta-lo` を暗い地、`--cta-text` を琥珀。塗りつぶしの明るいボタンは夜に出さない
- タブ帯：`--nav-acc --nav-on` を緑、`--nav-glass` をほぼ黒
- 半券：`--stub` を琥珀の薄い地、`--stub-text` を琥珀
- 地図：`--c-* --chart-*`（陸 #0C1219・海 #070C12・海岸線 #2C3846・方眼 7%）

## 本番で別に要る所（変数だけでは変わらない）
- 地図の地図画像（国土地理院の淡色地図）は夜にそのまま出すと明るい。夜だけ CSS の `filter`（反転＋暗く）をかけるか、陸と海を描いた自前の夜の地図に替える。どちらにするかはチェックイン担当と相談
- 字の色を直接書いている所（例：`color:#4b5563`、`background:rgba(255,255,255,.88)`）は変数に置き換える必要がある
- 図や印の svg に色を直接書いている所も同じ
