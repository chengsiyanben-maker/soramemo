いつも昼夜も、ふだんの明るい画面のまま
いつも夜昼も、夜の画面にします
今日の切り替え（羽田の近く）

→
昼の画面（あす）6:12

位置を使っていないときは、端末の時刻と東京の日の入り・日の出で切り替えます。

メモ（本番には出ません）
  • 決定どおり「自動／いつも昼／いつも夜」の3つ。はじめは自動。選んだものはサーバーの表示の設定（隠した設定と同じ所）に保存する想定
  • 左の小さな見本で、昼・夜・半分ずつ（自動）を見せる。選んでいるものは緑のふちと丸
  • 今日の切り替え時刻は、いる場所の日の入り・日の出（計器の数字）。位置を使っていない人は東京の時刻で決める（報告の3で本人に聞く）
