## 指摘（効き目の大きい順）

### 1. ホーム：画面案のシートの最初の位置が上から固定（490px）なので、低い画面で半券がタブ帯の下にもぐる（効き目：中）
- 何が：01-home-v5 のシートは `margin-top:490px`。高さ844ならちょうど収まるが、高さ667では半券の上の端が約520px、タブ帯の上の端が 589px で、「東京国際空港（羽田）」「判定範囲の中」「→ 右へ引いて 印をもらう」がタブ帯の後ろに入る（review-5-shots/01-home-v5-h667.png）。高さ740 でも数字の行が全部もぐる
- 本番では：main の今のホーム（feat/home-v3 が入ったもの）を高さ667で開くと、シートは**下から**決まっていて、半券と「ログインが要ります」の段がタブ帯の上に全部収まった（review-5-shots/now-main-home-guest-h667.png）。つまり本番は正しく、食い違っているのは画面案の作り方だけ
- なぜ：そらメモは web なので、iPhone の Safari では上と下の字の段のぶん、見える高さが 844 より 150〜180px ほど低い（iPhone 15 でも約660〜750px）。いちばん大事な操作（右へ引いて印をもらう）が、いちばん多い使い方で見えなくなる。review-4 の指摘1と同じ問題が、高さ844でだけ直った形
- それでも直す理由：画面案が「上から490px」のままだと、この案を見本に作り直すとき（数字の行を足す・半券を2行にする）に本番の決め方が上からに変わるおそれがある。デザイン担当の「重なり0」も高さ844でしか測っていないので、低い画面での見え方を誰も見ていない
- どう直す：画面案のシートの最初の位置を**画面の下から**決める（タブ帯の上の端 − 数字の行 − 半券 − つまみ。高さ844で今と同じ位置になる）。地図はその残りの高さ。高さ667でも半券と数字の行が全部見えることを、デザイン担当の測る項目に入れる（844・740・667 の3つ）。チェックイン担当へ渡すときの申し送りにも「下から決める」と1行
- 効き目：中（本番は正しいので大ではない）

### 2. 運用の「おすすめ」：推定の運用から出しているのに札がない（効き目：中）
- 何が：見に行くの上の行「おすすめ　いまの着陸34R が正面に見える」と、第2ターミナルの「おすすめ」のピル。もとの「着陸 34R」は上の濃いカードで「時間帯からの推定」と言っている値
- なぜ：決まりと食い違う（運用予想は実績と分けて「予想」と出す）。上で「推定です」と言っていても、下の段だけを読むと「いまの着陸34R」が事実に読める。D（選べるホーム）の review-1 でも同じ点（撮影地のおすすめに推定の札）を指摘し、D の2版では直っている。ここだけ残っている
- どう直す：「いまの着陸34R（推定）が正面に見える」、またはピルを「おすすめ（推定）」に。風の情報が届いて推定でなくなったときだけ札を外す
- 効き目：中

### 3. 01c「範囲に入る と切れる」：言い方が2通りに読める（効き目：小）
- 何が：範囲の外の半券の右側が「範囲に入る／と切れる」
- なぜ：分かりにくい。「切れる」は「半券を切れる」のつもりだが、「通信が切れる」「期限が切れる」とも読める。範囲の中の「右へ引いて 印をもらう」と言葉もそろっていない
- どう直す：「範囲に入ると／引ける」か「範囲に入ると／印をもらえる」。2行の形は今のままで高さは変わらない
- 効き目：小

### 4. 01e：3つの大きいボタンが同じ幅で縦に並ぶ（効き目：小）
- 何が：「ログイン・登録」（紺）・「デモで試す」（灰）・「閉じる」（灰）が同じ大きさ
- なぜ：操作が多く見える。「閉じる」はシートを下げても外を押しても同じなので、主の2つと同じ重さはいらない
- どう直す：「閉じる」は字だけ（またはシートの右上の ×）。「デモで試す」は灰色のピルのまま
- 効き目：小

### 5. 運用：22:41 の「深夜によく使う組み合わせ」と「運用時間 24時間」（効き目：小）
- 何が：濃いカードの「22:41 時点 ・ 深夜によく使う組み合わせ」。22時台を「深夜」と言っている
- なぜ：分かりにくい。羽田の深夜の使い方（23時〜6時ごろ）とずれて見え、推定の根拠への信頼が下がる
- どう直す：「夜によく使う組み合わせ」、または推定に使った時間帯をそのまま「22時台によく使う組み合わせ」
- 効き目：小
