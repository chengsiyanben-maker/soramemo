## 良い点（直さなくてよい）
- 押した回数と同じ角丸カードで、数字は大きく単位は小さく（決まりどおり）
- 年のない空港は年の欄ごと出さず、滑走路を横いっぱいにした
- 会社管理の空港で空のカードを並べない

## 指摘（効き目の大きい順）

### 1. データ欄が自分の記録の間に割り込む（効き目：中）
- 場所：空港ページ。押した回数・はじめて押した日 → **供用開始・滑走路・滑走路ごとの行・出典** → 季節の札・称号・押した記録
- 何が良くないか：自分の記録（回数・季節・称号・押した記録）が2つに分かれ、羽田では間に約300px 入る。667 では押した記録が最初の画面から消える
- なぜ：この画面でいちばん見たいのは自分の記録。空港の事実は「読みもの」で、毎回は見ない
- どう直すとよいか：データ欄と出典を押した記録（とターミナル）の下、前／次の空港の上へ移す。または滑走路ごとの行を「滑走路 4本」のカードの中に小さく入れて、高さを半分にする

### 2. 出典の1行が12px、リンクの押せる高さが17px（効き目：小）
- 場所：データ欄の下の「出典：国土交通省『空港一覧』を加工して作成」
- 何が良くないか：測る決まり（13px 未満は単位だけ・押す所 44px）から外れる。出典は利用条件で必ず出すもので、読めることが大事
- どう直すとよいか：13px にし、リンクの上下に余白を足して押せる高さ 44px にする（見た目の字はそのまま）

### 3. 福岡のヘリポートが滑走路の一覧に並ぶ（効き目：小）
- 場所：福岡の滑走路の行 C・D「35m×30m 奈多地区（ヘリポート）」
- 何が良くないか：「滑走路 2本」の下に4行あり、はじめての人は数が合わないと感じる
- どう直すとよいか：A・B だけを並べ、下に「ほかにヘリポート 2（奈多地区）」の小さい1行にする

### 4. 滑走路が1本の空港で、1行だけのカードが続く（効き目：小）
- 場所：稚内「滑走路 1本」のカードの下に「2,200m×45m」だけのカード
- どう直すとよいか：1本のときは「滑走路 1本」のカードの中に長さ×幅を小さく入れて、カードを1つ減らす

### 5. （案の外・main と同じ）図鑑の上で、ツメが「ほかの図鑑・実績」のボタンにかぶる（効き目：中）
- 場所：図鑑の最初の画面。ボタンは横 230〜370px、ツメ「北海道」は 338px から。「実績」の字がツメの下に隠れる。main でも同じ（この PR のせいではない）
- どう直すとよいか：ボタンの右の端をツメの左（約330px）で止める（「ほかの図鑑」だけにする、または索引と2つで幅を分ける）。チェックイン担当へ

## 次の版で必ず直すもの3つ
1. データ欄と出典を自分の記録の下へ移す（または高さを半分に）
2. 出典の字を13px・リンクの押せる高さを44px に
3. 図鑑の上の「ほかの図鑑・実績」をツメにかぶらない幅に（main と同じ問題）
