## 指摘（効き目の大きい順）

### 1. 02 図鑑の最初の画面：空港の枠がほとんど見えず、9地方の進み具合も一目で見えなくなる
- 何が：844 でも空港の枠は1段（3つ）しか見えず、2段目はタブ帯の下。667 では枠が1つも全部は見えない。上から「集めた空港」のカード（約100px）と北海道の扉（約175px）が続くため。さらに、今の本番のタイルの見方は「北海道 3/12・東北 1/9 …」と9地方の数が1画面で見えるが、新しい案ではツメに数がなく、ほかの地方の進み具合は1つずつ扉まで行かないと分からない
- なぜ：図鑑のタブを開いた人が最初に見たいのは「集めた・残っている空港」。それが2回送らないと出ない。今の良い点（9地方の数が一目）を失う
- どう直す：「集めた空港」のカードに9地方の小さな数（またはごく細い進み具合の帯9本）を入れ、扉は1行に縮める（地方名・3/12・細い進み具合。小さな地図は 03 のように地方へ飛んだときだけ）。目安は 667 で枠が1段全部見えること
- 効き目：大

### 2. 「見方」と「図鑑」の言葉が、それぞれ2つ以上の意味で使われている
- 何が：「見方」は ①見方の帯（図鑑・地図・行った順。07 の題も「見方の帯」）と ②記号の意味の説明（04 右上の「見方」、05 の「見方と索引」の「見方」のピル）の2つ。「図鑑」は 02 の1画面に題・帯の1つ目のピル・下のタブ帯の3回出る
- なぜ：04 で「見方」を押した人は見方の帯（地図に変える）だと思うのに、記号の説明が出る。帯の「図鑑」ピルは、今どこが選ばれているのか、押すと何が変わるのか分かりにくい
- どう直す：記号の説明は「記号の意味」（または「凡例」）に名前を変え、04 の右上もその名前に。帯の1つ目は中身を言う名前（例「地方別」）にして、「図鑑」は題とタブ帯だけにする
- 効き目：大

### 3. 02 の「索引」に虫眼鏡があるのに、05 に字で探す欄がない。05 は選ぶ段が3つ重なる
- 何が：虫眼鏡の絵は「名前を打って探せる」と読める。押した先の 05 は、上の「見方｜索引」→「ABC順｜50音順」→ 文字のピル（A〜Y・あ〜わ）とピルの段が3つで、打って探す欄はない。また 05 は「見方」を選んだ状態でも下に索引が出ていて、05b の「索引」を選んだ状態とふるまいが違う
- なぜ：「三沢ってどこ？」と探したい人は、行の頭の字を選び、さらに縦に送る必要がある。虫眼鏡で期待した操作と違う。ピルの段が多いと、どれを先に押すか迷う
- どう直す：索引の画面のいちばん上に1行の入力欄（空港名・コード・読みのどれでも当たる）を置き、ABC／50音は字を打たない人のための2番目に。記号の意味は索引と別の画面（2 の「記号の意味」）に分け、「見方｜索引」のピルをなくす。入力欄を置かないなら虫眼鏡の絵を外す
- 効き目：大

### 4. 04 1空港の詳しい所：自分の記録が、見本の値の大きさ比べより下にある
- 何が：上から印・データ欄4つ・大きさ比べ（約360px）・押した記録。844 で「押した記録」はタブ帯の下に隠れる。大きさ比べと開港の年は今の本番に表がなく、データ担当の出典つきの表と利用条件の確認が要る（報告にも書いてある）
- なぜ：この画面に来た人がまず見たいのは自分が押した日と回数（集める図鑑の中身）。表がまだない数字が自分の記録より上にあると、表が作れなかったとき画面の形が崩れる
- どう直す：「押した記録」をデータ欄のすぐ下へ。大きさ比べはその下にし、表ができるまでは出さない形も描いておく。下の「‹ 調布」と「大島 OIM ›」は書き方がそろっていないので、両方「名前＋コード」（コードのない空港は名前だけ）にそろえる
- 効き目：中

### 5. 03 コードのない空港（調布・新島・神津島）は同じ名前が大小2回並ぶ
- 何が：コードの場所に「調布」、その下にも「調布」。3つとも同じ
- なぜ：ほかの枠は「コード＋名前」の2つの情報なので、同じ字が2回だと誤りに見える。見比べる形をそろえた良さが崩れる
- どう直す：大きな字に名前を1回だけ出し、下の段は小さな薄い字で「コードなし」（または都道府県名）。05 の凡例の「コードのない空港は名前を同じ位置に」の1行もそれに合わせる
- 効き目：中

### 6. 02 の夜：「色の帯＝地方」が夜は成り立たず、行った・まだの差も弱い
- 何が：夜のツメと枠の上の帯から地方の色を外した（光る色2色の決まりのため。これ自体は正しい）。ところが 05 の凡例は「色の帯…右端のツメ・扉・枠の上の帯が同じ色」のまま。夜の枠は行った AKJ もまだの MMB も同じ暗い地で、違いはコードの明るさと小さな ✓ だけ（AKJ の ✓ はタブ帯に隠れて見えない）
- なぜ：夜にいちばん大事な「どれを押したか」が見分けにくい。凡例が夜の画面と食い違う
- どう直す：夜は行った枠だけ少し明るい地＋✓ の丸を緑（緑は「集めた・入」の意味なので2色の決まりの中）。凡例は夜のとき「色の帯」の行を出さない（または「夜は色を使いません」と書く）
- 効き目：中

### 7. 06 別冊：ボタンの名前が中身を言わず、色が1画面に多い
- 何が：02 の「別冊」のボタンからは、飛行場・番外編・実績・特別塗装機が入っていると分からない。実績は図鑑（冊）ではないので「別冊」に入れると探しにくい。今は上のピルを1回押せば行けた所が、別冊 → 本の2回になる。06 には背表紙の4色（緑・紺・紫・茶）、02 にはツメの9色があり、図鑑のタブだけで13色
- なぜ：名前から中身が想像できないと押されない。色の数は決まりの「アクセントは控えめ」から離れていく
- どう直す：ボタン名を「ほかの図鑑・実績」（短くするなら「ほかの図鑑」）にし、別冊の画面の背表紙は薄い地＋色は細い線1本だけに。実績は別冊の中に置くなら、いちばん上に出す
- 効き目：中

### 8. 07 見方の帯のシート：「まとめた見方」の説明がずっと残る
- 何が：シートの下半分が「タイル → 図鑑そのもの」「地方 → 各地方の扉」「案内標 → 1空港の‹前／次›」の説明。題の横の「3つ」も
- なぜ：今の人には1回知らせれば十分で、新しく始めた人には「タイル」「案内標」が何か分からず、読むだけの行になる。「3つ」は ON／OFF の5つまでの数と違い、選ぶときに役立たない
- どう直す：「まとめた見方」はシートから外し、今使っている人が次に図鑑を開いたとき1回だけのお知らせ（閉じたら出ない）に。「3つ」も外す
- 効き目：小

### 9. 02・03 の枠：高さ132のうち名前と「まだ」の間が空いて、1段が高い
- 何が：コード・名前のあと約50px 何もなく、下に「まだ」。関東9空港で3段＋ターミナル1段になり、地方の扉から次の地方まで長い
- なぜ：見比べる良さはそのままで、1画面に見える空港の数を増やせる（1 の効き目も上がる）
- どう直す：高さを 104 前後にし、「まだ／28回」を名前の下にすぐ続ける。押す所の44px は十分に保てる
- 効き目：小

### 10. 05 凡例の「扉の地図の ●○」の絵が橙の丸で、説明の「● 集めた」（紺）と色が違う
- 何が：見本の絵は関東の色（橙）の丸1つ、説明の丸は紺。02 の北海道の扉では集めた丸は青
- なぜ：凡例は形と色を覚えるためのもの。絵と説明で色が違うと、色に意味があるのか迷う
- どう直す：凡例の絵を「塗った丸と白い丸を並べた形」にして、説明に「色は地方の色」と1言足す
- 効き目：小
