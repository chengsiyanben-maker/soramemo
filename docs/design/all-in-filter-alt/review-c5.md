# タブから選ぶ（PR #48）の main 取り込み直しの確かめ（改善担当・c5）

見たもの：feat/all-in-tabs の cf47306（図鑑の入った main を取り込み直した版）。ブランチの web/ を偽のサーバーで開き、ログインして幅390・高さ 844／667 で指の操作（長押し・押す）をした。t118・t119・t120 も流して全部通った（失敗0・エラー0）。PM の指示（11/10 19時）。

## ぶつかっていないか
| 点 | 結果 |
|---|---|
| タブを選ぶ（長押し） | 図鑑の画面でフライトのタブを長押し → 「タブを選ぶ」が開き、画面は図鑑のまま。題と完了は上に固定、5/5 で成績を ON にすると入れ替えの帯（図鑑・フライト・運用・修行・やめる）。667 でも題・完了・帯が見える |
| ON／OFF | 行の中（番号・絵・名前・スイッチ・≡）は c4 と同じ。図鑑の行はふつうに ON |
| 図鑑の見方の帯 | 「地方別・地図・行った順」の3つ（横 22〜188px）と右の鉛筆（290〜326px）。右の端のツメ（約338px から）とは重ならない。タブ帯（上の端 758px）とも重ならない |
| 数 | 表示の編集は 38/38（図鑑の見方が3つになった分）。提案の数もテストどおり |
| はじめの1回の案内 | 「長押しで、出すタブと順番を選べます」がタブ帯の上に出る。図鑑の1段目の枠に重なるが、触ると消える1回だけのもの |

**取り込み直しでぶつかった所はない。**

## 気づいた点（効き目の大きい順）

### 1. 図鑑の鉛筆で開く「表示の編集」が、見方の所まで送られて開き、題と閉じるが見えない・タブが ✓ のピル（効き目：中）
- 場所：図鑑の見方の帯の右の鉛筆（「図鑑の表示を編集」）→ dLayout
- 何が良くないか：開くと「図鑑の見方」の所まで送られた位置で、いちばん上の「表示の編集」の題と「閉じる」が画面の外。上に残るのは「すべて／隠しているもの」のピルだけ。さらにこの1枚では、タブも見方も ✓ のピルで出す・隠す。「タブを選ぶ」は ON／OFF のスイッチなので、同じタブの設定が2つの違う部品で出ている
- なぜ：11/9 の決定は「出す・隠すは ON／OFF（昼夜同じ部品）」。案3 では見方は「各画面の見方の帯から」。鉛筆から案1 の1枚に飛ぶと、どこにいて、どう閉じるかが分からない
- どう直すとよいか：鉛筆はその画面の見方だけの小さいシート（「図鑑の見方」の3行を ON／OFF、題と完了を固定）を開く。1枚の表示の編集を残すなら、題と閉じるを上に固定し、部品を ON／OFF にそろえる（公開の前に）

### 2. 鉛筆の押せる大きさが 36×40（効き目：小）
- 場所：図鑑・フライト・運用の見方の帯の右の鉛筆
- どう直すとよいか：見た目はそのまま、押せる所を 44×44 に

### 3. （案の外・main と同じ）図鑑の上の「ほかの図鑑・実績」にツメがかぶる（効き目：中）
- 場所：図鑑の最初の画面。ボタンは 230〜370px、ツメは 338px から。「実績」が隠れる。main でも同じなので取り込み直しのせいではない
- どう直すとよいか：ボタンをツメの左で止める。チェックイン担当へ（review-facts-1 にも書いた）

## 判定
**本人に見せてよい（作ってよい）**。取り込み直しでタブを選ぶ・ON／OFF・図鑑の見方の帯はぶつかっていない。1 は1月の公開の前に直す。
