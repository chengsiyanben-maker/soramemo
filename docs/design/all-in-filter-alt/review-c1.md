## 作るときに必ず直したほうがよい所（5つ）

### 1. 長押しを、提案のない人にも1回だけ教える【大】
- いま：C4 の最後の一行「あとからタブを長押しして変えられます」だけ。「あとで決める」の人と提案を断った人のあと、長押しを知る場所がない
- 作るとき：
  - はじめてタブ帯が出たとき（提案の有無にかかわらず）に、タブ帯のすぐ上へ小さな吹き出し「長押しで、出すタブと順番を選べます」を1回。タップで消え、二度と出さない（見たことは表示の設定と一緒に保存）
  - マイページに「タブを選ぶ」の行（またはタイル）を置き、同じシート（C1）を開く。長押しを知らなくても届く道を必ず1つ
  - 本番のタブ帯は `<button>` の中に字（span）があり、字の選択を止める指定がない。`user-select:none`・`-webkit-touch-callout:none` と、長押し中の `contextmenu` を止める。長押しは約0.5秒、始まったらすぐ金の縁にして震え（使えれば）で知らせる。指が動いたら（約10px）長押しをやめてふつうのタップにも戻さない
  - iPhone の Safari（ホーム画面に置いた形も）で確かめる

### 2. タブを外した直後に、行き先をその場で見せる【大】
- いま：C1 で外すと「タブにないもの」へ移るだけ。シートの一行「外した画面はマイページから開けます」は外す前に読む文
- 作るとき：
  - 外した瞬間にトースト「運用はマイページから開けます」＋「元に戻す」
  - 「タブにないもの」の各行の下に小さく「マイページから」と書く（成績の行も）
  - いま開いている画面のタブを外したときは、完了でホームへ移り、トーストで行き先を言う（どのタブも選ばれていない帯にしない。review-4 で見た形）
  - マイページのタイルの名前は C1 のタブの名前とそろえる（運用・修行・成績）

### 3. 外すのは見える「−」（または「外す」）、戻すのは「＋ 出す」にそろえる【大】
- いま：C1 は「左へはらう」だけで外すボタンがない。C2 は × で外し ＋ のピルで戻す。C1 の戻すは行の中の「＋ 出す」ボタンで、C2 の ＋ ピルと形が違う
- なぜ：はらう動きは見えず、≡ の縦の動きとまざり、マウスでもできない。本番では × は「閉じる」（aria-label="閉じる" が3か所）なので、ホームの見本の × を「このカードを今だけ閉じる」と読む人が出る
- 作るとき：
  - C1 と C2 の両方で、外すのは行の右の丸い「−」（読み上げは「○○を外す」）。≡ はその左。はらうはおまけで残してよい
  - 戻すのはどちらも「＋ 出す」（C2 の「＋ これから乗る便」と同じピル）
  - 見方の帯（画面案なし）でも同じ「−」と「＋」を使う。最後の1つは「−」を出さない

### 4. ホームの見本だと一目で分かるようにする【中】
- いま：C2 の見本は本物と同じ白いカードと紺の半券を並べたもので、「ホームのシートの見本です」という説明の一文しか違いがない。ホームの下の行から来た人は本物のホームの続きに見える
- 作るとき：
  - 見本全体を薄い灰色の地の枠に入れ、左上に小さく「見本」の札。カードの中の数（印・空港など）は出さず名前だけ（本物と混ざらない）
  - 本物のホームのカードには「−」も × も出さない（外すのは見本の上だけ、を守る）
  - 見本の並びは本物の並びと同じにする。いま見本にある「今日の数字」は本番の LO_BLOCKS のホームにない（本番は これから乗る便・イベントのお知らせ・これまでの記録・最近の印＋いちばん上のカード）。外せるようにするならかたまりが1つ増える（16こ）ので保存の中身をデータ担当と合わせる。しないなら「いつも」に
  - 左上の戻るは「‹ 戻る」で来た所へ（ホームから来たらホームへ）

### 5. 「全部乗せに戻す」はページの外の場所へ・元に戻せるように【中】
- いま：C2「ホームに出すもの」のページに紺の「戻す」があり、押すとタブ・ほかの画面の見方まで戻る（C3）。戻したあと元に戻せず、並べた順番も消えるのか決まっていない。高さ667では C2 のトーストがこのボタンの上にかぶる
- 作るとき：
  - 「全部乗せに戻す」はマイページ（表示の編集）と C1 のシートのいちばん下に置き、ボタンは白。ホームのページには「ホームを全部出す」だけ
  - C3 の確かめに「タブの順番：元の順に」を足す。戻したあと、トーストで「元に戻す」（前の設定を1つだけ覚える）
  - トーストは1行で「外しました」と短く、ページの下にトースト1つぶんの余白を空ける。高さ667で重ならないことをテストに入れる

## 作ったあとに確かめてほしいこと（テストの目安）
- はじめての人：吹き出しが1回だけ出て、2回目は出ない（提案あり・なし・あとで決めるの3通り）
- タブ帯の長押しでシートが開き、字が選ばれない・メニューが出ない。ふつうのタップは今までどおり
- C1 で「−」を押すと「タブにないもの」へ移り、トーストに行き先と元に戻す。今いる画面のタブを外すとホームへ
- マイページから外したタブが開ける。C1 の名前とマイページのタイルの名前が同じ
- 見本の「−」「＋」で本物のホームが同じ順で変わる。本物のホームに「−」は出ない
- 全部乗せに戻す → 元に戻すで、隠したもの・タブ・順番が前の形に戻る
