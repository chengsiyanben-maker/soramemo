# 「決まりなし」の案を、Instagram で知らない人に見せたら（広告担当・2026-11-08）

PM の指示（11/8 20時15分、本人「たくさん案を出して」）。デザイン担当の8案を、**フィードを流し見している知らない人が指を止めるか**の目で見た。見たのはホーム（a1〜h1）と表示の編集（a2〜h2）の PNG。投稿はしない。

前提として、ここでの「強さ」は、4:5に切られて縮んだ1枚目で、①何かが読める ②ほかの投稿と色や形が違う ③空港か飛行機のアプリだと分かる、の3つで決めた。

## 8案：投稿の1枚目にしたときの強さ

| 案 | 強さ | 理由（1行） |
|---|---|---|
| A 搭乗券と手帳 | 中 | 紙と赤い「未押印」の判は温かいが、縮むと明朝の細い字と罫線がつぶれ、ベージュの地がほかの投稿に埋もれる（「しまう」の判は2枚目向き） |
| B 夜の操縦席 | 強 | 黒い地に光る桃色の HND と扇形のレーダーは、明るい投稿の多いフィードでいちばん目立つ。ただし何のアプリかは見出しで補う必要がある |
| C 大きな字のポスター | 強 | 120px の「HND」と「羽田まで、あと12.4km。」がサムネでも読め、1枚目の見出しにそのままなる。白黒なので、文字だけの投稿と似やすいのが弱み |
| D 航法図が主役 | 中 | 航空図の地とマゼンタの円は空港らしいが、注記の四角が多く、縮むとごちゃついて何を見ればいいか分からない。2枚目以降の「地図のアプリ」の説明向き |

| G 空のグラデーションと雲 | 弱 | 柔らかく好かれるが、細い数字と淡い色はサムネで溶ける。指を止める力が弱いので、ストーリーズの背景向き |

- 表示の編集（a2〜h2）は、どの案も1枚目には向かない（設定の画面は、知らない人には意味が分からない）。2枚目以降に「要らないものは隠せる」を見せるなら、**F の「掲載・休載」**と**H の「はがした跡」**が言葉だけで伝わって強い
- 注意：8案はアプリに入っていない実験。画面として投稿すると「ない機能を書かない」に反する。使うなら、**アプリの画面ではなく告知の絵柄として**使い、画面の見本は今の main の見た目にする（下の10案は、どれもその前提）

## 宣伝したくなる「決まりなし」の見た目の案（14案）

どの案も、全部の枚に「非公式アプリ」を入れる。航空会社のロゴ・会社の色を主役にした絵・空港の公式キャラ・他人の写真は使わない（写真は1枚も使わず、絵と文字だけ）。数字は見本と書く。却下済みのもの（出発案内板風の全面・天気や季節の印・今日のお題・空のカレンダーなど）は使わない。

## 先に試すなら

1. **1 切れる半券**：カルーセルならではの仕掛けで、アプリの一番の動き（半券を切る）がそのまま伝わる
2. **2 85の空白**：説明がなくても「埋めたい」が伝わる。図鑑の投稿（11/23）の1枚目に差し替えられる
3. **7 数字ひとつ**か**8 夜の計器でリール**：1枚目の強さを、今の見た目の投稿と保存・リーチで比べる（`docs/marketing/metrics.md` の記録表に「見た目」の列を足して見る）
