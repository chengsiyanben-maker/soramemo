# 共有画像の「非公式アプリ」案（share-unofficial）への指摘 1回目（2026-11-05・改善担当）

見たもの：01〜07 の画面案（スマホ幅390で開き、白黒・赤白・空を切り替えた）、png/image-*-now・a・b.png（1080×1350 と写真 1600×1200）、報告 report-design-share-unofficial.md。
見る人を「SNS で流れてきた画像をスマホで一瞬見る、アプリを知らない人」として判断した。

## 良い点（直さなくてよい）
- 置き場所を cardBase と photoStamp にまとめ、全部の画像に同じ形で入る。直す所が少なく、入れ忘れが出にくい
- 写真に押した印（案A）の左上「そらメモ　非公式アプリ」の半透明の黒いピルは、写真の上でもはっきり読める。いちばん良い形
- 称号が長いときに称号の字を小さくして、ピルと重ねない決まりを先に作ってある
- JAL赤・ANA青を使わず、どの色でも浮かない薄いグレーにした。ロゴや公式キャラを使っていない
- 送る文を「#そらメモ（非公式アプリ）」＋URL にするのは、文が付く送り先では確実に伝わる

## 指摘（効き目の大きい順）

### 1. 印・地図・まとめの画像では「非公式アプリ」が小さすぎて読めない（効き目：大）
- 画面・場所：01・02・03・05 の案A、見出し「そらメモ」の右のピル（字 24px／画像の幅 1080px）
- 何が良くないか：画像はスマホの画面では幅 約360〜390px に縮むので、ピルの字は 約8〜9px、枠も細い薄いグレー。画面案の 01-stamp を390幅で開くと、プレビューの中のピルはほぼ読めない（空の色でも同じ）。インスタのグリッドでは見えない
- なぜ：読みにくい・依頼の目的（「非公式アプリ」を毎回明記する）が画像だけでは果たせない
- どう直すとよいか：写真の印（04）と同じく、字を 32〜36px 以上・濃いめのグレー（色の sumi を 75% 以上）にする。枠だけのピルより、薄い地の色を敷いたピルのほうが縮めても形が残る。あわせて「縮めたときの見え方」（幅 360px に縮めた PNG）を案に足し、読めるかを本人が確かめられるようにする

### 2. 案A と案B を「どちらか」にせず、ピル＋下の端の断り書きの両方にする案も比べたい（効き目：中）
- 画面・場所：07-compare
- 何が良くないか：案A は名前の横で切り取りに強いが一言だけ、案B（下の端「非公式アプリ・航空会社や空港とは関係ありません」）は意味がはっきりするが小さい。どちらも1つでは足りない場面がある。特に JAL・ANA の名前や便名（JL917）が入る地図・写真・まとめの画像では、「関係ありません」まで書いてあるほうが誤解されにくい
- なぜ：決まり（航空会社名は事実の記録としてだけ）とのつながりが、画像の中で説明されていない
- どう直すとよいか：「案A のピル＋航空会社名が入る画像だけ下の端に案B の一文」を案C として1枚足す

### 3. 空港の数が画像（97）とアプリ（86）で違う（効き目：中）
- 画面・場所：01・02・03 の数字の列「23　空港 / 97」
- 何が良くないか：ホームは「16/86」、使い方は「国内86の空港」。共有画像だけ 97 になっている（今の描き方を写したためで、今の本番の画像も同じ食い違いの可能性が高い）
- なぜ：見た人に「どちらが本当？」と思わせる・数字の信用が下がる
- どう直すとよいか：分母を 86（空港の数）にそろえるか、97 がターミナルを含む数なら「印 / 97」と名前を変える。どちらにするかはチェックイン担当とそろえる

### 4. 日付が2回、形を変えて出る（効き目：小）
- 画面・場所：01・02 の印の中「2026/11/03」と、空港名の下「東京都　2026/11/3」
- 何が良くないか：同じ日付が2回、0 のある・なしで違う形
- なぜ：読みにくい・余白を使う
- どう直すとよいか：空港名の下は日付を外して「東京都」だけにするか、形をそろえる。空いた所をピルの拡大（指摘1）に回せる

### 5. soramemo.jp が小さく薄い（効き目：小）
- 画面・場所：印・地図の下の端（字 約26px・薄いグレー）
- 何が良くないか：縮めると 約9px で、探す手がかりとしては弱い
- なぜ：読みにくい
- どう直すとよいか：28〜30px・濃いグレーに。「#そらメモ」がある画像と同じ並び（「#そらメモ　soramemo.jp」）に全部そろえると覚えやすい

### 6. 「非公式アプリ」のピルが、何かの「認定」や「ラベル」に見えるおそれ（効き目：小）
- 画面・場所：案A の細い枠のピル
- 何が良くないか：枠だけのピルは「公式」「認定」のバッジと形が似ていて、小さいと中の字を読まずに「何かのマーク」として流される
- なぜ：分かりにくい（指摘1と同じ根）
- どう直すとよいか：指摘1の直し（字を大きく・地の色を敷く）で足りる。形は今のピルのままでよい

### 7. まとめの画像の棒グラフに凡例がない（効き目：小・案の外）
- 画面・場所：05-year の月ごとの棒（黒と薄いグレーの2色）
- 何が良くないか：黒が何でグレーが何かが画像の中に書いていない（新しい空港と全部？）
- なぜ：分かりにくい（今の画像から変わらない部分なので、今回の案の外）
- どう直すとよいか：棒の上に「■ 新しい空港　■ フライト」のような小さな凡例を1行。今回の範囲外なら次の機会に
